# 生命图谱1 - 规格文档

## 1. 业务目标

作为「产品生命周期」列表页「生命图谱」的**并列**数据展现形式，以全新的**线性时间线**形态呈现产品生命周期。与「生命图谱」（流程图 + 变更回路 + 撤销分支）不同，本页严格按时间先后顺序线性排列流程节点，仅展示已经实际执行过的步骤，未进行的步骤一律不显示，且不存在任何支线 / 分支 / 回路，形成单一时间序列。

## 2. 入口与定位

- 入口：列表页操作列「生命图谱1」按钮（仅列表**第一条数据**展示），跳转至独立整页 `/prototypes/product-lifecycle-graph1.html`，不再以弹窗形式展示。
- 参数传递：跳转时携带当前数据产品标识码，URL 形如 `?code=DP43010020260001`；页面依据该参数从演示数据中定位记录并加载，支持直接访问与刷新（刷新后参数保留，数据可复现）。
- 返回：页面顶部提供「返回产品生命周期」入口，返回列表页；亦可通过左侧菜单「产品生命周期」返回。
- 页面标题：「生命图谱1」；面包屑：`首页 / 产品生命周期`（左侧菜单高亮「产品生命周期」）；顶部工具条中部展示当前产品标识码、名称与「当前阶段」。

## 3. 线性时间线形态（核心规则）

- **视觉形式与「生命图谱」保持一致**：节点采用相同的圆角矩形卡片样式，含左上角编号、阶段名称、分类标签；节点之间以带箭头直线连接；分类配色与图例与「生命图谱」完全一致（前置阶段蓝、核心流转绿、变更循环橙、终止环节红）。
- **严格按时间线顺序**：流程节点依时间先后依次排列，形成单一时间序列，例如：上架节点之后接续变更节点，再接续下架节点，最后接续上架节点。
- **仅展示已执行步骤**：未进行的步骤一律不显示；时间线由记录当前阶段回溯，已流转阶段纳入，当前阶段标记高亮，其后尚未发生的阶段不展示。
- **无分支 / 无回路**：不存在任何支线、分支或变更回路箭头，节点依时间先后排成单一序列。为适配长序列展示，图谱**每行最多展示 8 个节点，超过则自动换行**；换行采用「蛇形／回形」布局——第 1 行从左到右，第 2 行从右到左，第 3 行再从左到右，依此类推；奇数行整体向左错开一定间距，使换行处形成「下 → 横 → 下」的阶梯连线。换行箭头位于水平转折段，指向下一行的阅读方向（第 1 行→第 2 行指向左，第 2 行→第 3 行指向右），整体仍为同一时间序列、无分支无回路。
- 节点构成（按时间顺序）：
  - 前置阶段：开发、编目（始终执行）。
  - 核心流转：安全审查、登记、上架、交易、下架（仅展示已执行到的节点）。
  - 变更：可插入在「登记」之后或「上架」之后，并可在后续运营周期中反复多次，作为线性序列的普通节点，不形成回路；多次变更以右上角「×N」徽标区分。
  - 撤销：仅在已执行到撤销阶段时展示。
  - 上架 / 下架按「运营周期」口径展开为多次事件（如 上架 → 变更 → 下架 → 上架），依时间顺序线性排列；重复的上架 / 下架节点以右上角「×N」徽标区分第几次。
- 每个节点展示：序号（从 1 开始连续递增，与展示顺序一致）、阶段名称、分类标签、状态标签（当前阶段沿用列表阶段状态、其余已执行节点为「已完成」）、操作时间（由标识码派生、依时间先后递增）。
- **第一条数据固定演示**：列表页按「更新时间」倒序后的首行记录，在「生命图谱1」中固定展示 20 步完整线性序列，不受记录当前阶段动态推导限制。固定序列如下：
  1. 开发 → 2. 编目 → 3. 安全审查 → 4. 登记 → 5. 变更（登记后） → 6. 上架① → 7. 变更（上架后） → 8. 交易① → 9. 下架① → 10. 上架② → 11. 变更③ → 12. 交易② → 13. 下架② → 14. 上架③ → 15. 变更④ → 16. 交易③ → 17. 下架③ → 18. 上架④ → 19. 交易④ → 20. 撤销。
  该序列严格按时间先后顺序排列，无分支、无回路，所有步骤均为已执行状态，最后一步「撤销」标记为当前节点。

## 4. 交互

- 节点点击：点击任意节点，从页面右侧滑出抽屉面板，展示该阶段序号、阶段名称、状态标签、操作时间与阶段说明。
- 抽屉收起：点击抽屉外遮罩或抽屉右上角关闭按钮均可收起抽屉。
- 异常态：缺少 `code` 参数或标识码未匹配到记录时，页面展示「未找到对应的数据产品」提示并提供返回入口。
- 全部只读。

## 5. 视觉

- 复用 `Layout` 统一后台侧栏、顶部导航、面包屑和角色区域。
- 复用「生命图谱」整页的顶栏、图例、节点 SVG 样式与抽屉样式（`product-lifecycle-graph/graph-style.css`），节点分类配色与图例保持一致：前置阶段（蓝 `#1890ff`）、核心流转（绿 `#52c41a`）、变更循环（橙 `#fa541c`）、终止环节（红 `#f5222d`）。
- 与「生命图谱」的关键差异：所有节点严格排成一条水平直线，节点间为单一向前箭头，不存在变更回路、撤销绕行等分支。
- 线性时间线专属提示与画布内边距由本页 `graph1-style.css` 定义，不影响其他页面。

# 其他经营主体工作台

## 业务与功能

### 页面定位与核心目标

公共数据资源授权运营管理平台后台的一级菜单页面，面向「其他经营主体」角色。其他经营主体登录后台后，通过本页快速了解数据产品再开发的完整流程，并掌握与自身相关的关键指标数量与在办进展。

页面复用后台公共 `Layout`（侧边栏、顶部栏、面包屑、角色区域），不引入独立导航，避免后台出现双层导航。原后台「工作台」入口已按需求隐藏（代码保留未删除），入口位置由本页面承接。

### 功能清单

| 模块 | 说明 |
| --- | --- |
| 数据产品再开发步骤向导 | 以六个连续箭头呈现场景申请 → 签署协议 → 产品开发 → 产品编目 → 安全审查 → 产品上架的完整流程，每个步骤在箭头下方直接展示该步骤的办理说明 |
| 关键指标统计 | 四张指标卡，展示图标、指标数值、指标名称与在办进度（申请中数量 / 订阅次数），单行四列排布 |

### 交互要点

- 页面为只读工作台，不提供新增、编辑、删除等数据写入入口。
- 顶部角色区域固定展示「其他经营主体」，不提供其他角色选项，保证页面语义单一。
- 顶部栏保留后台统一的「版本管理」「页面说明」「原型修改记录」「消息通知」入口，交互与其他后台页面一致。
- 侧边栏当前项高亮显示，点击其他菜单可正常跳转至对应后台页面，不影响后台整体导航。

## 内容规划

### 信息架构

```text
其他经营主体工作台
├── 数据产品再开发步骤向导
│   └── 场景申请 / 签署协议 / 产品开发 / 产品编目 / 安全审查 / 产品上架（各含步骤说明）
└── 关键指标统计
    ├── 数据探查申请数(次)  2   申请中：1
    ├── 场景申请数(次)      29  申请中：13
    ├── 平台资源申请数(次)  0   申请中：4
    └── 数据产品数(个)      4   订阅次数：8
```

### 数据来源

- 页面内容与样式严格参考用户提供的设计图。
- 步骤名称与步骤说明沿用平台既有的数据产品再开发流程文案。
- 指标名称、指标数值与在办进度按设计图取值，均为内置演示数据，仅保存在组件状态中。

### 关键字段

- `redevelopmentSteps[]`：再开发流程步骤，含 `title`（步骤名称）、`description`（步骤说明）。
- `metrics[]`：指标卡配置，含 `icon`（图标标识）、`label`（指标名称）、`value`（指标数值）、`extraLabel`（在办进度说明）、`extraValue`（在办数量）。

## 布局与结构

### 整体布局

- 页面框架复用后台公共 `Layout`，主体区相对顶部栏与左侧边栏保留统一留白：上方 18px、左右 20px、下方 28px。
- 主体自上而下为两块白色面板，两块面板均占满整行（等宽）：步骤向导面板在上，关键指标统计面板在下。
- 步骤向导面板内部为等宽六列网格，列间距 28px；每个步骤由 40px 高的箭头色块与下方说明文字组成，说明文字自动换行。
- 关键指标统计面板内部为**单行四列**网格，列间距 20px；卡片最小高度 112px，卡内上下两行：上行图标与数值，下行为指标名称与在办进度。
- 页面最小宽度 1180px，窄屏下适当收紧步骤列间距与指标列间距。

### 响应式适配

- ≥1600px：步骤列间距 28px，指标列间距 20px。
- <1600px：步骤列间距 20px，指标列间距 16px，保证卡内文字不拥挤。

## 视觉规范

### 设计规范来源

用户提供设计图（其他经营主体工作台截图），并复用后台既有主题与公共布局样式。

### 自定义设计要点

- 面板：白色背景、6px 圆角、`0 1px 4px rgba(23, 35, 61, .06)` 轻投影；面板标题 16px / 600 / `#303133`。
- 步骤箭头：色块 `#d7b48a`，40px 高，采用左侧凹口、右侧凸尖的箭头形裁切，标题为 16px / 700 白色居中文字。
- 步骤说明：14px / `#303133`，行高 1.46，与箭头上方间距 22px。
- 指标卡：背景 `#f6fafe`，8px 圆角，内边距 14px 16px；数值 24px / 600 / `#303133`；指标名称 14px / `#303133`；在办进度说明 14px / `#606266`，数量为 `#ff4d4f`。
- 图标：30×30 内联 SVG，蓝金配色（`#0b5ba8` / `#0b4f96` / `#1668b3` / `#e7c9a1` / `#e0be96`），未引入新依赖。

### 组件状态

- 侧边栏菜单项：默认 / 悬停（蓝色文字）/ 当前项高亮，沿用后台公共样式。
- 面板与指标卡为静态展示，无悬停态变化。
- 顶部栏消息通知、角色区域、页面说明弹窗交互沿用 `Layout` 既有实现。

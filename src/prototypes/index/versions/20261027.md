## 列表权限：
- 列表按照更新时间倒序排列，列表查看范围如下
1. 实施机构：可查看本机构自有资源所开发的基础产品、再开发产品
2. 运营机构：可查看本机构开发的基础产品，以及由其衍生的再开发产品
3. 其他经营主体：可查看自身再开发所使用的基础产品、自身开发产出的再开发产品
4. 数据管理部门：基础数据产品监管页面查看全部基础产品；再开发数据产品监管页面查看全部再开发产品。数据权限按层级隔离：省级查看全部，地市级查看本市及下辖区县数据，区县级仅查看本区县数据
5. 行业主管部门：基础、再开发数据产品监管页面，仅查看备案实施机构对应领域的基础产品与再开发产品

## 筛选条件：
- 数据产品标识码、产品名称、产品类型（数据集 / API 产品）、产品阶段（基础产品 / 再开发产品）、产品提供方、当前状态、更新时间：
- 当前状态
1. 安全审查：待审查、审查不通过
2. 产品登记：首次登记待审核、变更登记待审核、撤销登记待审核、首次登记未通过、变更登记未通过、撤销登记未通过、已通过、已撒销
3. 产品上架：待审核、已通过、不通过
4. 产品下架：待审核、已通过、不通过
- 更新时间：
1. 安全审查：取安全审查申请审查流程里的最新时间
2. 产品登记：取自产品登记列表的更新时间
3. 产品上架：取上架申请审核流程里的最新时间
4. 产品下架：取下架申请审核流程里的最新时间

## 列表字段
序号、 数据产品标识码、 产品名称、产品类型、产品阶段、产品提供方、当前状态（展示产品所处阶段 + 状态标签）、更新时间、操作

## 操作
- 查看：点击跳转至产品详情弹窗
- 血缘：点击打开产品数据血缘页面（权限说明：当角色为其他经营主体，属于血缘链路末端，不展示血缘入口）
- 生命周期：弹出生命周期弹窗

## 生命周期弹窗
1. 顶部流程步骤条：产品开发 → 产品编目 → 安全审查 → 产品登记 → 产品上架 → 产品下架；已完成的环节为绿色，当前环节为蓝色，未进行的环节为灰色（不可点击）
2. 基础信息区：展示数据产品标识码、产品名称
3. 产品开发：展示流程节点（产品开发）、节点状态（已完成）、单位名称（产品配置信息提供方）、法人经办人姓名、操作时间（产品配置信息同步过来的时间）、产品来源（数据开发中心 / 可信数据空间）
产品编目：展示流程节点（产品编目）、节点状态（已完成）、单位名称、法人经办人姓名、操作时间（产品提交安全审查的时间）
安全审查、产品登记：复用原有页面详情审查情况 / 审核信息模块
产品上架、产品下架：将原有页面详情审核信息模块拆分开来，分别展示在不同的流程节点中

# 城市专区（门户）

## 业务与功能

### 核心目标
面向地市本级用户的门户专区，承接省级公共数据流通底座，适配湖南地市场景。原型以娄底市为例，集中展示本市可对外授权流通的数据资源、数据产品、公告政策与落地应用案例。

### 功能清单
- 专区专属顶部栏（可信数据空间）：位于门户全局导航正下方、Banner 之上，深蓝底色横向导航条，仅作用于本页面、与 PortalLayout 全局公共顶部相互独立。左侧为「可信数据空间」品牌标识 + 竖分隔线 + 专区切换下拉（可交互）：点击胶囊按钮展开面板，面板为整体一张白色圆角卡片，含「主空间」与「公共数据专区」（右侧带「未入驻」灰字与「公共专区」蓝色标签）两个选项，选项间无间隔、仅以浅色分隔线区分，无选中高亮；按钮默认显示当前专区「娄底市专区」，点击选项回显至按钮并收起面板，点击面板外空白处关闭，展开时箭头旋转 180°；中部为专区导航（首页、数据资源中心、数据产品中心、数据服务中心▾、数据需求中心、场景中心、资讯动态、标识查询、帮助中心），首页为默认高亮项；右侧为「应用中心」按钮与「登录 / 注册」入口。滚动时吸附在全局导航下方（sticky top:60px）。
- 专区头部 Banner：展示城市名称标题「XX 市数据流通专区」与一句话简介，并标注地市级专区属性。
- 统计概览卡片：首页首屏展示 5 个核心指标——数据资源、数据产品、数据需求、应用场景、入驻企业。
- 专区定位与特色：位于数据资源模块之前，左为信息卡片（专区类型、运营方、描述），右为蓝色城市配图。
- 模块1 数据资源：仅展示归属本市、可对外授权流通的数据资源，卡片展示资源名称、资源标识码、资源持有方、资源格式、更新频率、行业分类。
- 模块2 数据产品：卡片展示产品名称、产品标识码、产品提供方、产品简介。
- 模块3 公告与政策文件：分为「专区公告」与「政策规范」两类；列表展示标题、发布时间、文件类型，支持预览 / 下载。
- 模块4 业务应用案例：本市落地的数据流通应用案例，图文卡片展示案例名称、使用的数据产品、应用场景、所属行业、简介。
- 模块5 入驻企业：以 Logo/品牌卡形式展示已入驻本专区的数据开发与运营主体。
- 加入专区入口：蓝色 CTA 横幅，标题「加入 XX 市数据流通专区」，支持「立即加入」视觉入口。
- 专区专属底部栏（可信数据空间）：位于「加入专区入口」与门户全局页脚之间，蓝灰渐变底色，仅作用于本页面、与 PortalLayout 全局公共底部相互独立。左侧为品牌区（白色 Logo 方块 + 「湖南省公共数据流通利用基础设施 / 可信数据空间」）；中部「友情链接」栏（湖南数据产业集团有限公司、湖南省公共数据授权运营平台、湖南省公共数据运营监管平台、湖南省区域功能节点）；公众号二维码占位图 +「扫一扫进入公众号」；右侧「运营方」信息（湖南数据产业集团有限公司、地址、邮箱、电话）；底部居中版权条（Copyright + ICP 备案号）。

### 交互要点
- 顶部导航、页脚由公共组件 `src/common/PortalLayout.tsx` 统一维护，本页 `activeNav="city"` 高亮「城市专区」。
- 公告与政策文件为 Tab 切换（专区公告 / 政策规范），点击行内「预览 / 下载」为视觉入口。
- 卡片 hover 通过阴影和上移反馈可点击感。
- 原型为静态展示，导航、搜索、预览、下载均为视觉入口。

## 内容规划

### 信息架构
```text
城市专区（娄底市）
├── 专区专属顶部栏（可信数据空间，页面独立）
├── 专区头部 Banner
├── 统计概览卡片
├── 专区定位与特色（运营方 + 配图）
├── 数据资源（归属本市·可对外授权流通）
├── 数据产品
├── 公告与政策文件（专区公告 / 政策规范）
├── 业务应用案例
├── 入驻企业
├── 加入专区入口
└── 专区专属底部栏（可信数据空间，页面独立，位于全局页脚之上）
```

### 数据来源
- 用户提供的《城市专区原型内容说明》。
- 页面内置示例数据，复用湖南地市场景业务名称（娄底市数据资源管理局、娄底市市场监督管理局等）；入驻企业为娄底市及湖南省本地企业示例（如娄底数智科技集团、湖南涟源钢铁集团有限公司等）。

### 关键字段
- `stats`：指标名称、数值、单位、图标。
- `resources`：资源名称、标识码、持有方、格式、更新频率、行业分类。
- `products`：产品名称、标识码、提供方、简介。
- `announcements / policies`：标题、发布时间、文件类型。
- `cases`：案例名称、使用产品、应用场景、所属行业、简介、配图色。
- `enterprises`：企业名称、占位 Logo SVG（data URI，后续可替换为真实企业 Logo 图片）。
- `join`：标题、描述、按钮文案。
- `images/banner-bg.jpg`：专区头部 Banner 背景配图（用户提供，蓝色科技风横幅）。

## 布局与结构

### 整体布局
- 顶部固定 60px 蓝色导航栏（公共组件）。
- 专区专属底部栏为蓝灰渐变（#42618c→#334e6e），与主内容区同宽版心（约 1220px）分段布局：品牌区 | 友情链接 | 公众号二维码 | 运营方信息；底部为版权条。
- 专区专属顶部栏高 56px，深蓝渐变（#0a2b6b→#0f3d9c），通过 margin-top:60px 避开全局固定导航，sticky 吸附于其下方；左右分段布局：品牌区 + 专区切换 | 专区导航（居中） | 应用中心 + 登录/注册。
- 专区头部 Banner 高约 360px，以本地蓝色科技风横幅配图（`images/banner-bg.jpg`，右侧带齿轮科技元素）为背景，叠加轻量蓝色渐变保证文字可读，居中展示标题与简介。
- 统计概览卡片上浮覆盖 Banner 下沿，5 列等宽布局。
- 内容区采用宽版心（桌面端约 1220px）。数据资源、数据产品、业务应用案例为卡片网格；公告与政策文件为 Tab + 列表。
- 双数模块（第 2/4/6 个）使用浅蓝渐变背景并左右铺满视口：数据资源、公告与政策文件、入驻企业；单数模块（专区定位与特色、数据产品、业务应用案例、加入专区入口）保持白底。

### 响应式适配
- 按门户桌面端优先，页面设置最小宽度 1280px，避免卡片挤压变形。

## 视觉规范
- 主色沿用平台蓝（#1d74ec / 渐变 #0b5fee→#2c88fb），与门户保持一致。
- 卡片白底、轻阴影、紧凑信息密度。
- 标题左侧蓝色短竖条标识，与门户各模块标题风格统一。
- 操作按钮（预览 / 下载）保持蓝色体系下的轻反馈。

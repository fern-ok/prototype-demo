<strong style="color:red">#1949</strong>
1、门户发布需求弹窗中，增加数据需求分类的单选框。选择数据资源，应答方只能选择实施机构；选择数据产品，应答方选择运营机构或其他经营主体
2、门户个人中心我的需求列表中，增加需求筛选的列表字段和筛选条件，枚举值：待上报、已上报、已响应、意向达成。不论何种状态，操作都只有查看。已响应状态下可以看到需求基本信息、响应信息；意向达成状态下可以看到需求基本信息、响应信息、意向信息
3、后台增加需求管理的列表，分配给“数据基础设施运营方”角色
 - 列表字段：序号、需求标题、行业分类、资金预算、需求截止日期、需求状态、创建时间、更新时间、操作。
 - 筛选条件：需求标题、资金预算、需求状态、需求截止日期、创建时间、更新时间。
 - 状态流转顺序：待上报 -> 已上报 -> 已响应 -> 意向达成。
 - 待上报记录显示“查看、上报”；已上报记录显示“查看、响应”；已响应显示“查看、确认意向”；意向达成仅显示“查看”。
 - 点击上报、响应或确认意向后更新状态和更新时间；查看按钮展示需求详情。
 4、门户发布需求弹窗中，去掉是否公开的设置项，默认都是不公开，只有指定的应答方登录系统之后才能看到需求列表
<strong style="color:#0f63f4">响应弹窗</strong>
 - 需求标题只读带出；应答方必选；响应说明必填且最多 500 字；应答方决定数据类型，数据类型禁用；数据名称必填，根据数据类型自动带出数据标识，数据标识为禁用状态。
 <strong style="color:#0f63f4">确认意向弹窗</strong>
 - 需求标题只读带出；数据规模必填且仅允许数字，单位可选 MB、GB、TB；意向说明必填、最多 500 字。提交校验通过后，需求状态更新为“意向达成”。
 <strong style="color:#0f63f4">查看弹窗</strong>
 - 查看弹窗仅含基本信息时不显示页签；有响应信息时显示“基本信息、响应信息”页签；有意向信息时显示“基本信息、响应信息、意向信息”页签，默认选中基本信息。每个页签只展示对应分组内容。基本信息展示需求标题、行业分类、资源预算、需求截止日期、需求状态、创建时间、更新时间、联系人、联系方式、需求描述；响应信息展示应答方、响应说明和响应数据列表；意向信息展示数据规模和意向说明。

# 数据资源初审 - 规格文档

## 1. 业务目标

为实施机构提供数据资源授权单的初审管理功能，支持待处理和已处理两个视图，区分待初审和已完成的单据，提升审核效率。

## 2. 功能清单

| 功能模块 | 功能描述 |
|----------|----------|
| 待处理列表 | 展示所有待初审的资源授权单据，支持条件筛选、分页查询 |
| 已处理列表 | 展示已完成的初审单据（初审不通过/待复审/复审不通过/复审通过），支持条件筛选、分页查询 |
| 初审办理 | 审核人员录入初审结果和意见，提交后自动流转状态 |
| 查看详情 | 只读查看单据全部信息，包括基本信息和初审信息 |

## 3. 关键交互点

- TAB 切换：待处理 / 已处理，切换时重置分页
- 筛选查询：支持资源授权单名称、授权发起方、数据资源目录、审核状态、创建时间、更新时间筛选
- 初审弹窗：产品名称只读回显，初审结果必填（初审通过/初审不通过），初审意见选填
- 状态流转：待初审 → 初审通过 → 待复审；待初审 → 初审不通过

## 4. 信息架构

### 待处理 TAB 筛选条件
- 资源授权单名称（输入框，模糊搜索）
- 授权发起方（下拉选择：实施机构/运营机构）
- 数据资源目录（输入框，模糊搜索）
- 创建时间（日期范围选择器）
- 更新时间（日期范围选择器）

### 已处理 TAB 筛选条件
- 资源授权单名称（输入框，模糊搜索）
- 授权发起方（下拉选择：实施机构/运营机构）
- 数据资源目录（输入框，模糊搜索）
- 审核状态（下拉选择：初审不通过/待复审/复审不通过/复审通过）
- 创建时间（日期范围选择器）
- 更新时间（日期范围选择器）

### 表格字段
- 序号、资源授权单名称、授权发起方、数据资源目录、审核状态（仅已处理）、创建时间、更新时间、操作

### 操作按钮权限
- 待初审：【查看】【初审】
- 初审不通过/待复审/复审不通过/复审通过：【查看】

## 5. 数据来源

内置种子数据，包含 12 条记录（6 条待初审、6 条已处理）。

## 7. 视觉规范

- 复用产品安全审查模块的视觉风格
- TAB 采用 Element Plus 风格（底部蓝色指示条）
- 状态标签颜色：待初审（蓝色）、待复审（橙色）、复审通过（绿色）、初审不通过/复审不通过（红色）
- 角色权限：仅实施机构可见

## 8. 初审弹窗

| 字段名称 | 控件类型 | 是否必填 | 说明 |
|----------|----------|----------|------|
| 资源授权单名称 | 只读输入框 | 是 | 不可编辑，回显当前单据名称 |
| 初审结果 | 下拉选择框 | 是 | 选项：初审通过、初审不通过 |
| 初审意见 | 文本域输入框 | 否 | 多行文本框 |

### 业务规则
- 初审通过 → 单据状态变更为【待复审】
- 初审不通过 → 单据状态变更为【初审不通过】
- 提交后回填：初审人、初审时间、初审结果、初审意见
- 提交完成后，该单据不再允许再次初审

# 工作台

## 1. 页面定位

公共数据资源授权运营管理平台后台的一级菜单页面，位于侧边栏首位。页面沿用后台统一的侧边栏、顶部栏、面包屑和角色区域，支持实施机构、运营机构、其他经营主体、行业管理部门四类角色切换，并在同一入口展示对应角色的指标总览、待办任务、消息通知与统计分析。

## 2. 业务目标

- 为四类角色提供统一的工作台入口，进入后台即可看到与自身职责相关的关键指标与待处理事项。
- 将待办任务与消息通知收敛到同一页面，减少跨模块跳转，缩短事项响应路径。
- 通过趋势分析与订阅排行榜呈现平台运行态势，支撑运营决策与行业监管。

## 3. 功能清单

| 模块 | 说明 |
| --- | --- |
| 角色切换 | 右上角提供实施机构、运营机构、其他经营主体、行业管理部门四个选项，切换时同步刷新全部主体内容 |
| 指标总览 | 四张指标卡，展示图标、指标名称、数值与今日新增，指标项随角色变化 |
| 再开发步骤向导 | 仅其他经营主体展示，以连续箭头呈现场景申请到产品上架的六步流程，步骤说明集中在标题旁的帮助图标内 |
| 待办任务 | 待处理、已处理两个页签，列表展示业务名称、提示文案和时间，支持跳转处理与标记、删除 |
| 消息通知 | 未读、已读两个页签，列表展示消息类型、通知文案和时间，支持标记已读与删除 |
| 趋势分析 | 两张趋势图，支持全部、近一年、近30天、近7天筛选；行业管理部门不展示该模块 |
| 订阅 TOP10 | 仅行业管理部门展示，按订阅次数降序展示排名、产品名称、所属运营机构和订阅次数 |

## 4. 数据定义

| 字段 | 数据类型 | 说明 |
| --- | --- | --- |
| WorkTask | object | 待办任务，含 `id`、`title`（业务名称）、`content`（提示文案）、`time`、`href`（处理跳转地址）、`handled` |
| NoticeMessage | object | 消息通知，含 `id`、`title`（消息类型）、`content`（通知文案）、`time`、`read` |
| roleConfigs | Record | 按角色配置的指标、待办、通知与趋势数据，键为四个角色名 |
| metrics | array | 指标卡配置，每项含 `icon`、`label`、`value`、`extra`（今日新增）、`tone`（配色） |
| subscriptionTop10 | array | 订阅排行榜，每项含 `product`、`operator`、`count`，按 `count` 降序 |

## 5. 角色与权限

- 角色切换器提供实施机构、运营机构、其他经营主体、行业管理部门四个选项，默认选中实施机构。
- 实施机构：展示数据资源、授权、基础数据产品、再开发产品四类指标，以及数据资源上架趋势与授权趋势。
- 运营机构：展示基础数据产品、授权、再开发产品、其他经营主体四类指标，趋势切换为产品上架趋势与产品类型占比。
- 其他经营主体：在指标卡上方展示再开发步骤向导，指标为场景申请、再开发产品、订阅总数、调用总数。
- 行业管理部门：展示角色指标、消息通知与订阅 TOP10，不展示待办任务与趋势分析。
- 页面不提供新增、编辑、删除等数据写入入口；待办与通知的标记、删除仅影响当前页面的演示数据。

## 6. 布局与视觉

- 主体区域直接在当前页面内维护，不引入独立的顶部栏或侧边栏，避免后台页面出现双层导航。
- 主体相对顶部栏和左侧边栏保留统一留白：上方 18px、左右 20px、下方 28px。
- 主体自上而下为三段：指标卡网格（四列）、待办任务与消息通知双栏、趋势分析双栏。
- 行业管理部门仅渲染指标卡与消息通知、订阅 TOP10 两栏，不渲染待办任务与趋势分析。
- 指标卡采用图标、色彩侧边标识、指标名称、数值和今日新增的紧凑布局，不再展示指标释义。
- 待办与通知面板使用页签切换，列表行包含复选框、类型图标、标题、文案与时间。

## 7. 交互规则

| 场景 | 行为 |
| --- | --- |
| 切换角色 | 按新角色重新载入指标、待办、通知与趋势；待办回到「待处理」页签、通知回到「未读」页签，并清空已选记录 |
| 切换页签 | 切换待办或通知的页签时，清空当前已选记录 |
| 处理待办 | 点击「处理」跳转至该条待办对应的业务页面 |
| 标记已处理 | 待处理列表支持单条或批量标记已处理，记录随即移入「已处理」页签 |
| 删除待办 | 已处理列表支持单条或批量删除 |
| 标记已读 | 未读列表支持单条或批量标记已读，记录随即移入「已读」页签 |
| 删除通知 | 已读列表支持单条或批量删除 |
| 批量操作 | 未勾选任何记录时，批量按钮为禁用状态 |
| 列表计数 | 工具栏在已勾选时显示「已选 N 条」，未勾选时显示「共 N 条」 |
| 趋势筛选 | 支持全部、近一年、近30天、近7天；运营机构默认近 7 天，其余角色默认近 30 天 |
| 空状态 | 待办、通知列表无记录时，分别展示「暂无任务记录」「暂无消息记录」 |

## 8. 数据来源

- 待办任务与消息通知使用内置 seed 数据 `taskSeed`、`noticeSeed`；运营机构角色另有独立的待办与通知数据。
- 指标卡、趋势图与订阅 TOP10 均为内置演示数据，趋势折线由固定坐标点串渲染。
- 全部数据仅保存在组件状态中，标记、删除等操作在页面刷新后重置。

## 9. 公共样式

- 页面框架统一复用 `src/common/Layout.tsx` 提供的后台布局（侧边栏、顶部栏、面包屑、角色切换、消息通知）。
- 主体区域的指标卡、面板、列表、页签、趋势图、步骤向导与排行榜样式定义在原型自身 `style.css`。

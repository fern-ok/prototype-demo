# 监控大屏（公共数据授权运营大屏）

## 业务与功能

### 核心目标
授权运营平台后台的"监控大屏"菜单项所对应的可视化驾驶舱页面。用于全局展示公共数据授权运营的核心指标与分布情况，单页可视化大屏，深蓝色科技风，适合投屏展示。新页签全屏打开，不嵌入后台常规布局。

### 功能清单
- 顶部 4 个核心指标卡：数据资源总数、场景总数、基础数据产品总数、再开发数据产品总数（含数值 + 单位 + 关联子指标）。
- 中部左侧环形图：再开发数据产品订阅行业占比。
- 中部中央湖南地图：数据资源领域名称分布 + 各领域数值气泡。
- 中部右侧条形图：数据资源行业分布（含图例）。
- 左下折线图：再开发数据产品订阅趋势分析（2026-04 ～ 2026-09）。
- 右下双横向条形图：基础数据产品授权次数 TOP10、再开发数据产品订阅次数 TOP10。

### 交互要点
- 大屏为只读可视化页面，不做增删改操作。
- 监控大屏由授权运营后台一级菜单触发，另开新页签全屏展示。
- 不复用门户 `PortalLayout`，自带顶部标题栏与背景。
- 进入页面需通过 `PasswordGuard` 密码保护。

### 关键字段
- `stats[]`：核心指标，含 `label / value / unit / sub[]`。
- `industryRatio[]`：环形图行业占比，含 `name / value / color`。
- `domainPoints[]`：湖南地图领域分布点位，含 `name / value / x / y`。
- `industryBars[]`：行业分布条形图，含 `name / value`。
- `trendMonths[]`、`trendValues[]`：折线图 X 轴月份与 Y 轴值。
- `basicTop10[]`、`redevTop10[]`：两组 TOP10，含 `name / value`。

## 布局与结构

### 整体布局
- 全屏 1920×1080 视角设计，采用 CSS Grid 三行布局：标题区 / 中部三栏 / 底部三栏。
- 标题栏高约 70px，居中标题"公共数据授权运营大屏"，两侧装饰角与发光边框。
- 中部三栏等宽（约 25% / 50% / 25%），底部三栏比例为 30% / 35% / 35%。
- 卡片使用深蓝渐变背景 + 圆角 + 发光描边统一视觉。
- 图表均使用 ECharts 渲染（项目已安装 echarts 6.x）。

### 响应式适配
- 适配桌面端 1280px ～ 1920px 投屏，最小宽度 1280px，小屏按比例缩放。

### 设计规范来源
用户规范：`C:/Users/Lenovo/Desktop/监控大屏html.txt`、`C:/Users/Lenovo/Desktop/监控大屏.txt` 与用户提供截图。

### 自定义设计要点
- 背景：深蓝（#0a1f44 → #0d3a6e 渐变）+ 中心发光的 HUNAN 字样叠加。
- 主色：科技蓝 #1e88ff / 青蓝 #00d4ff；强调色橙 #ff9d4d。
- 指标卡大数字使用 28px 粗体，辅助小指标 16px。
- 卡片左上角装饰小三角 + 标题 + 副标题，标题前一个菱形点。
- 图表配色统一蓝/青/橙三色系，环图按行业分配不同色。
- 字体：系统默认无衬线 + 数字部分使用等宽风格（CSS `font-feature-settings`）。

## 公共组件维护
- 监控大屏为独立全屏页面，**不套用 `PortalLayout`**：不渲染门户公共顶部导航与页脚，整页仅保留大屏本体（深蓝背景自铺满视口）。
- 页面规格与修改记录通过本目录 `spec.md`、`change.md` 文件维护，页面上不再提供"页面说明""原型修改记录"入口。
- 进入页面需通过 `PasswordGuard` 密码保护。

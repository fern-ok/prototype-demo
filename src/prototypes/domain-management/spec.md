# 领域管理

## 1. 页面定位

公共数据资源授权运营管理平台后台的字典维护页面，位于一级菜单「系统管理」下，二级菜单为「领域管理」。页面为数据基础设施运营方提供公共数据资源业务领域及其展示排序的维护入口，不承载业务流程，仅维护基础字典。

## 2. 业务目标

- 为需要高频维护基础字典的运营人员提供稳定、低干扰、可快速扫描的政务后台操作环境。
- 统一公共数据资源的业务领域口径，供资源登记、目录挂载等下游模块引用。
- 通过排序值控制领域在各处的展示顺序，避免依赖创建时间导致的顺序混乱。

## 3. 功能清单

| 模块 | 说明 |
| --- | --- |
| 筛选查询区 | 支持按领域名称模糊检索，点击【查询】或按 Enter 提交；【重置】恢复完整列表 |
| 新增领域 | 表单弹窗，填写领域名称与排序，保存后写入当前时间 |
| 编辑领域 | 表单弹窗，回显该条记录的领域名称与排序 |
| 删除领域 | 二次确认弹窗，提示中带出领域名称，确认后不可恢复 |
| 领域表格 | 展示序号、领域名称、创建时间、排序、操作，按排序值升序排列 |
| 分页组件 | 总记录文案、上一页/下一页、页码、每页条数切换，默认 10 条/页 |

## 4. 数据定义

| 字段 | 数据类型 | 说明 |
| --- | --- | --- |
| id | number | 领域记录唯一 id，新增时取当前最大 id + 1 |
| name | string | 领域名称，必填，最大长度 30，全表不可重复 |
| createdAt | string | 创建时间，格式 `yyyy-MM-dd HH:mm:ss`，新增时写入当前时间，编辑不变 |
| sort | number | 展示排序，必填，且为大于 0 的整数 |

## 5. 角色与权限

- 页面分配给「数据基础设施运营方」角色，角色切换器固定显示该角色。
- 侧边栏「系统管理」分组处于展开态，「领域管理」处于激活态。
- 页面右上及侧栏底部显示当前角色与模块授权关系。
- 该角色拥有领域字典的全部维护权限（查询、新增、编辑、删除），不设只读限制。

## 6. 布局与视觉

- 公共顶部栏和侧边栏由后台 `Layout` 统一提供，内容区仅呈现领域管理标题、筛选区和领域表格。
- 筛选区底部统一为左侧【查询】【重置】两个按钮，右侧放置【新增】按钮。
- 主按钮使用需求管理同款蓝色 `#0f63f4`；筛选区和列表使用同款白底、`#dfe5ef` 边框与浅蓝表头；红色仅用于删除风险提示。
- 采用低对比度边框区分内容层级，避免卡片投影干扰表格阅读。
- 字体使用 Microsoft YaHei / PingFang SC；表格时间和排序使用等宽数字对齐，基础间距为 4px。
- 响应式：850px 以下压缩侧栏和筛选区，620px 以下保留图标侧栏并允许表格横向滚动。

## 7. 交互规则

| 场景 | 行为 |
| --- | --- |
| 默认状态 | 展示全部领域，按排序值升序，每页 10 条 |
| 查询 | 按领域名称模糊匹配，回到第 1 页 |
| 重置 | 清空筛选条件，恢复完整列表，回到第 1 页 |
| 新增 | 打开新增弹窗，排序默认带出「当前记录数 + 1」 |
| 编辑 | 打开编辑弹窗，回显该条记录的领域名称与排序 |
| 名称校验 | 未填写提示「请输入领域名称」；与已有记录重名提示「领域名称已存在」 |
| 排序校验 | 非大于 0 的整数时提示「排序请输入大于 0 的整数」 |
| 删除 | 打开确认弹窗，提示「确定要删除领域“{领域名称}”吗？删除后无法恢复，请谨慎操作。」 |
| 取消关闭 | 点击遮罩、关闭图标或【取消】均不更改数据 |
| 切换每页条数 | 支持 10 条/页与 20 条/页，切换后回到第 1 页 |
| 无数据 | 表格展示「暂无匹配的领域数据」占位 |

## 8. 数据来源

- 内置初始数据 `initialDomains`，共 9 条：卫生健康、气象服务、文化旅游、交通运输、城市治理、自然资源、工业制造、创新金融、就业创业，排序值依次为 1 至 9。
- 列表按 `sort` 升序排列，序号按当前分页重新编号。
- 全部数据仅保存在组件状态中，新增、编辑、删除在页面刷新后重置。

## 9. 公共样式

- 页面框架统一复用 `src/common/Layout.tsx` 提供的后台布局，与其他后台模块共用顶部栏、侧边栏、角色切换、通知和页面说明入口。
- 列表页基础样式统一复用 `src/common/backend-list.css`，筛选、按钮、表格、操作链接和分页与产品和服务清单备案页保持一致。
- 领域表格列宽、新增按钮位置等少量定制样式定义在原型自身 `style.css`。

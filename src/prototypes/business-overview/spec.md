# 业务概览 - 规格文档

## 1. 业务目标

面向数据管理部门，提供全省公共数据授权运营业务的「总览 + 地域分布」看板。以概览卡聚合全省核心指标，并以地域卡片呈现各地域的机构备案分布，支持按地域下钻查看领域明细与地域明细，帮助监管方快速掌握整体态势。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 全省总览卡 | 顶部概览卡分三大板块：机构数据、资源与产品登记、产品流通；指标含数据管理部门/行业主管部门/实施机构/运营机构/其他经营主体、数据资源登记/授权/基础数据产品/场景发布/场景申报/再开发数据产品、流通数据产品/有效交易订单/调用成功次数/产品订单总额/产品流通率 |
| 产品流通率 | 派生指标（流通率 = 流通数据产品 / 基础数据产品），带「?」说明角标，hover 展示口径 |
| 地域机构备案卡片 | 每个地域一张卡片，展示该地域「机构备案」板块（数据管理部门/行业主管部门/实施机构/运营机构/其他经营主体数量） |
| 卡片展开/收起 | 每张地域卡片支持「展开 / 收起」切换机构备案明细（默认展开） |
| 领域明细 | 全省及各地域均提供【领域明细】按钮，弹窗按业务领域（医疗健康、交通运输等）展示数据/产品数量 |
| 地域明细 | 仅市州卡片提供【地域明细】按钮，弹窗展示该市州下辖区县的机构数量（省本级无下级地域，不展示该按钮） |

## 3. 角色与权限

- 页面归属后台「其他」菜单组，为二级子菜单，与「机构监管」并列。
- 仅向「数据管理部门」角色分配，页面角色切换器固定显示数据管理部门。
- 页面为只读监管视角，不提供新增、编辑、删除等写操作。

## 4. 指标口径

| 板块 | 指标 | 说明 |
| --- | --- | --- |
| 机构数据 | 数据管理部门 / 行业主管部门 / 实施机构 / 运营机构 / 其他经营主体 | 全省各角色备案机构累计数量 |
| 资源与产品登记 | 数据资源登记 / 数据资源授权 / 基础数据产品 / 场景发布 / 场景申报数 / 再开发数据产品 | 资源与产品登记侧累计 |
| 产品流通 | 流通数据产品 / 有效交易订单 / 调用成功次数 / 产品订单总额 / 产品流通率 | 流通与交易侧累计，流通率为派生指标 |

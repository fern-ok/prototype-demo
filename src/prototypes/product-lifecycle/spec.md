# 产品生命周期 - 规格文档

## 1. 业务目标

面向运营机构，提供数据产品从「安全审查 → 产品登记 → 产品上架 → 产品交付 → 产品下架」全生命周期的统一跟踪入口。以「数据产品」为粒度展示当前所处阶段与阶段状态，支持按产品标识码、名称、类型、阶段、提供方、当前阶段、阶段状态、更新时间组合检索，并可查看产品档案、阶段流转时间轴与数据血缘关系，用于掌握产品加工链路与流转进度。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 组合筛选 | 数据产品标识码、产品名称、产品类型、产品阶段、产品提供方、当前阶段、阶段状态、更新时间，共 8 项，两行排布（每行 4 项；「更新时间」位于第二行第 4 格，单列日期范围） |
| 查询 / 重置 | 蓝色主按钮【查询】按当前条件过滤并回到第 1 页；白色次要按钮【重置】清空全部条件恢复全量数据 |
| 生命周期列表 | 展示序号、数据产品标识码、产品名称、产品类型、产品阶段、产品提供方、当前阶段、阶段状态、更新时间、操作 |
| 查看 | 打开「产品详情」只读弹窗，展示产品档案信息 |
| 时间轴 | 打开「生命周期时间轴」弹窗，按 安全审查 → 产品登记 → 产品上架 → 产品交付 → 产品下架 顺序展示各阶段流转记录 |
| 数据血缘 | 跳转至独立整页「数据血缘」，以分层图谱展示 数据源系统 → 数据资源 →（基础产品）→ 数据产品 →（数据服务）的血缘链路，并附血缘关系明细表；页面通过 `?code=数据产品标识码` 定位记录，支持直接访问与刷新 |
| 生命图谱 | 跳转至独立整页「生命图谱」，以流程图形式可视化展示产品完整的生命周期流转：开发 → 编目 → 安全审查 → 登记 → 上架 → 交易 → 下架 → 撤销，并以回路体现「变更」可反复多次；页面通过 `?code=数据产品标识码` 定位记录，支持直接访问与刷新 |
| 生命图谱1 | 跳转至独立整页「生命图谱1」，作为「生命图谱」的并列展现形式，但采用**线性时间线**形态：严格按时间先后顺序线性排列流程节点，仅展示已经实际执行过的步骤，未进行的步骤一律不显示，且不存在任何支线 / 分支 / 回路（例如：上架 → 变更 → 下架 → 上架，形成单一时间序列）；按钮仅出现在列表**第一条数据**的操作列，其余数据仅展示「生命图谱」 |
| 默认排序 | 列表按「更新时间」倒序排列，最新在前；查询/重置/翻页后排序不变 |
| 分页 | 共 X 条记录 + 上一页/页码/下一页 + 每页条数 + 跳页；默认每页 10 条，默认第 1 页 |

## 3. 角色与权限

- 页面为后台**一级菜单**「产品生命周期」，无父级菜单，面包屑展示 `首页 / 产品生命周期`。
- 仅向「运营机构」角色分配，页面角色切换器固定显示运营机构。
- 页面为只读跟踪视角，不提供新增、编辑、删除等写操作。

## 6. 产品详情弹窗（查看）

- 标题：「产品详情」，只读展示产品档案。
- 基本信息：数据产品标识码、产品名称、产品类型、产品阶段、产品提供方。
- 阶段信息：当前阶段、阶段状态、更新时间。
- 产品简介：整行展示。
- 底部仅提供【关闭】按钮。

## 7. 生命周期时间轴弹窗（时间轴）

- 标题：「生命周期时间轴」。
- 顶部概要条：数据产品标识码、产品名称、产品类型、产品阶段，便于核对当前查看对象。
- 时间轴按阶段流转顺序自上而下排列：安全审查 → 产品登记 → 产品上架 → 产品交付 → 产品下架。
- 每个节点展示：序号、阶段名称、阶段状态标签，以及两组结构化信息块（操作时间仅展示在发起信息内，节点头部不重复展示；不展示处理说明行）：
  - 发起信息：单位名称（取产品提供方）、法人经办人姓名、操作时间。
  - 审批信息：单位名称（固定「湖南省公共数据运营中心」）、法人经办人姓名、审核结果（已完成 → 审核通过 / 已驳回 → 审核不通过 / 其他状态 → —，标签绿底绿字 / 红底红字）、审核意见（通过 / 「首次××不通过，材料修改后重新提交」 / —）、操作时间（已完成 / 已驳回 → 取节点操作时间；其他状态 → —）。
- 当前阶段节点高亮（蓝色实心圆点 + 蓝色阶段名）；已流转完成的节点状态统一为「已完成」；当前阶段为已驳回/已终止/已暂停时，流转在该阶段终止，其后阶段不展示。
- 全部只读，底部仅提供【关闭】按钮。

## 8. 数据血缘独立整页（数据血缘）

- 入口：列表页操作列「数据血缘」按钮，跳转至独立整页 `/prototypes/product-lifecycle-lineage.html`，不再以弹窗形式展示。
- 参数传递：跳转时携带当前数据产品标识码，URL 形如 `?code=DP43010020260001`；页面依据该参数从演示数据中定位记录并加载，支持直接访问与刷新（刷新后参数保留，数据可复现）。
- 返回：页面顶部提供「返回产品生命周期」入口，返回列表页；亦可通过左侧菜单「产品生命周期」返回。
- 页面标题：「数据血缘」；面包屑：`首页 / 产品生命周期`（左侧菜单高亮「产品生命周期」）。
- 全屏图谱：图谱占满 `Layout` 内容区可视区域，无额外标题栏与卡片边距；SVG 随容器尺寸自适应重绘，节点与连线始终可见。
- 辐射式布局（SVG 绘制，带箭头贝塞尔连线）：
  - 中心节点：当前数据产品，类型为「一级产品」（蓝色），固定居中。
  - 上游节点：左侧均匀分布 4 个「数据资源」（橙色），名称为 `<地域><领域>数据资源1~4`。
  - 下游节点：右侧均匀分布 5 个「再开发产品」（绿色），名称为 `再开发产品-产品1~5`。
  - 边：每个上游节点连向中心节点，中心节点连向每个下游节点，箭头指向血缘下游。
  - 节点按类型配色：数据资源（橙色 `#fa541c`）、一级产品（蓝色 `#1890ff`）、再开发产品（绿色 `#52c41a`）；节点名称超长截断，悬停显示完整名称。
- 节点交互：点击任意节点，从页面右侧滑出抽屉面板；抽屉标题为节点类型，页签按节点类型动态展示：
  - 数据资源节点：仅展示「基本信息」一个页签。
  - 基础产品节点：展示「基本信息」「授权信息」两个页签。
  - 再开发产品节点：展示「基本信息」「交易信息」两个页签。
  - 基本信息：按节点类型分支展示。点击「数据资源」节点，展示资源名称、数据资源标识码、行业分类、是否涉及个人信息、资源格式、数据来源、更新频率、覆盖时间范围、地域分类、资源持有方、资源摘要共 11 项（字段顺序与数据资源目录一致）；点击「基础产品 / 再开发产品」节点（含中心节点），展示数据产品基本信息 16 项：产品名称、数据产品标识码、产品类型、覆盖时间范围、行业分类、地域分类、是否涉及个人信息、交付方式、授权使用、数据主体、数据规模、更新频率、个人或企业授权使用、产品简介、使用限制、提供方名称。
  - 授权信息（基础产品节点）：列表展示序号、运营机构、授权时间，按授权时间倒序排列，并配备分页组件（可切换每页条数）；演示数据由节点名派生，稳定且各节点互不相同。
  - 交易信息（再开发产品节点）：列表展示序号、数据需求方、创建时间，按创建时间倒序排列，并配备分页组件（可切换每页条数）；演示数据由节点名派生，稳定且各节点互不相同。
- 抽屉收起：点击抽屉外遮罩或抽屉右上角关闭按钮均可收起抽屉，收起后不干扰图谱的平移/点击等交互。
- 图例：页面顶部工具条右侧按节点类型展示色块说明。
- 画布交互（平移 / 缩放 / 重置）：整页图谱支持对画布的平移、缩放与重置，各能力互不冲突、可叠加操作：
  - 平移：在画布空白处按住鼠标（或单指触控）拖拽，整体平移全部节点与连线；拖动超过阈值（4px）即判定为平移，不会误触发节点点击。
  - 缩放：桌面端滚动鼠标滚轮以光标位置为锚点缩放；移动端双指捏合缩放（以双指中点为锚点）；缩放比例限定在 40%~300% 之间并持续保留，直至主动重置或刷新页面。
  - 重置：右下角悬浮控制条提供「放大 ＋ / 缩小 － / 重置 ⟳」三个按钮并实时显示当前缩放百分比；点击「重置」或按键盘 `R` 快捷键，画布视图回到初始状态（居中、100%）；`+` / `-`（或 `=` / `_`）键亦可步进缩放。
  - 叠加与固定：可在任意缩放比例下继续拖拽平移；控制条与抽屉遮罩均不随画布变换，始终固定在视口原位，保证操作可达且不干扰图谱其余交互。
- 异常态：缺少 `code` 参数或标识码未匹配到记录时，页面展示「未找到对应的数据产品」提示并提供返回入口。
- 全部只读。

## 10. 交互状态

- 页面初始化不带筛选条件，自动加载全部产品生命周期数据，并默认按「更新时间」倒序排列（最新在前）。
- 查询、重置、切换分页后排序保持不变；第一页始终展示更新时间最新的记录。
- 重置后列表刷新回全量数据并回到第 1 页。
- 无数据场景：表格展示空白提示「暂无数据」。
- 「查看」「时间轴」弹窗支持点击遮罩关闭；「数据血缘」「生命图谱」均为独立整页，通过页面内「返回」入口或左侧菜单返回列表页。
- 长文本单元格截断，悬停显示完整内容。
- 表格列宽固定不换行；操作列不裁剪按钮，容器宽度不足时表格区域出现横向滚动条。

## 11. 数据说明

- 演示数据按地域、领域、产品类型、产品阶段组合生成，共 48 条产品生命周期记录。
- 数据产品标识码规则：`DP` + 6 位行政区划代码 + 年份 `2026` + 4 位序号（如 `DP43010020260001`）。
- 当前阶段与阶段状态按阶段语义约束生成：审查/登记/上架阶段取 待处理、处理中、已完成、已驳回；交付阶段取 处理中、已完成、已终止、已暂停；下架阶段取 待处理、已完成、已终止、已暂停。
- 时间轴依据当前阶段回溯生成，已流转阶段统一为「已完成」，当前阶段沿用列表中的阶段状态。
- 血缘图谱依据产品阶段与当前阶段动态生成分层节点，边为相邻层节点的全连接。
- 数据资源节点详情（资源名称、数据资源标识码、行业分类、是否涉及个人信息、资源格式、数据来源、更新频率、覆盖时间范围、地域分类、资源持有方、资源摘要）由所属数据产品的地域 / 领域推导生成：资源名称取节点名称，地域分类取地域可读标签，行业分类取领域，资源持有方按领域映射到对应厅局（如医疗健康 → 湖南省卫生健康委信息统计中心），数据资源标识码按 `712430000MB0L046927` + 4 位地域代码 + 8 位后缀规则生成，其余字段取统一演示默认值（是否涉及个人信息=是、资源格式=OFD、数据来源=原始取得、更新频率=2次/天、覆盖时间范围=当年首月至至今、资源摘要=自动生成说明）。
- 数据产品节点（基础产品 / 再开发产品，含中心节点）详情 16 项由所属数据产品的地域 / 领域推导生成：产品名称取节点名称，数据产品标识码按 `712430000MB0L046927` + 4 位地域代码 + 8 位后缀规则生成，产品类型取记录产品类型，行业分类取领域，地域分类取地域可读标签，提供方名称取记录提供方；覆盖时间范围按节点序号生成 2026-09 至 2026-10 区间，数据规模与更新频率按节点序号取演示值（如 1 MB、11次/天），其余字段取统一演示默认值（是否涉及个人信息=否、交付方式=文件传输、授权使用=否、数据主体=个人信息、个人或企业授权使用=否、使用限制=自动生成说明、产品简介=记录产品简介）。

## 12. 生命图谱独立整页（生命图谱）

- 入口：列表页操作列「生命图谱」按钮，跳转至独立整页 `/prototypes/product-lifecycle-graph.html`，不再以弹窗形式展示。交互与展示方式参照「数据血缘」独立整页。
- 参数传递：跳转时携带当前数据产品标识码，URL 形如 `?code=DP43010020260001`；页面依据该参数从演示数据中定位记录并加载，支持直接访问与刷新。
- 返回：页面顶部提供「返回产品生命周期」入口，返回列表页；亦可通过左侧菜单「产品生命周期」返回。
- 页面标题：「生命图谱」；面包屑：`首页 / 产品生命周期`（左侧菜单高亮「产品生命周期」）；顶部工具条中部展示当前产品标识码、名称与「当前阶段」。
- 流程图（SVG 绘制，带箭头曲线连线）：

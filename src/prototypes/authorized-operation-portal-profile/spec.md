# 授权运营平台门户个人中心

## 业务与功能

### 核心目标
新增授权运营平台门户个人中心页面，用于展示当前登录主体的账号信息、注册信息和基本认证信息，并与门户右上角用户下拉入口联动。

### 功能清单
- 顶部门户导航：保持与门户首页一致的品牌、导航、搜索和用户信息。
- 用户下拉：悬浮用户信息显示“个人中心”和“管理后台”。
- 左侧个人中心菜单：账号信息、主体认证、我的订阅、我的需求、我的应用、我的收藏、我的反馈。
- 账号信息：展示注册信息、角色标签、注册时间、账号 ID、身份标识。
- 基本信息：展示法人类型、单位/企业名称、统一社会信用代码、法定代表人、核验类别、证件号码、手机号码。
- 页脚：复用门户联系方式和运营方信息。

### 交互要点
- 鼠标悬浮右上角用户信息时出现下拉菜单。
- 点击下拉“个人中心”停留或进入当前页面。
- 点击下拉“管理后台”跳转后台页面。
- 点击顶部品牌或“首页”返回门户首页。

## 布局与结构

### 整体布局
- 顶部固定 60px 蓝色导航栏。
- 主体采用 1300px 居中白色卡片，左侧 220px 菜单，右侧信息内容区。
- 页脚为深蓝灰色四列布局。

### 响应式适配
- 按桌面门户原型适配，页面最小宽度 1280px。

- 页面顶部和底部统一由 `src/common/PortalLayout.tsx` 与 `src/common/portal-layout.css` 维护。
- 顶部固定提供“返回首页”“页面说明”“原型修改记录”三个入口，其中“页面说明”读取本页面 `spec.md`，“原型修改记录”读取本页面 `change.md`。
- 个人中心主体仅维护左侧菜单和账号信息内容，门户导航、用户下拉、页脚联系方式统一从公共组件复用。

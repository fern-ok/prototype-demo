# 生命图谱 - 规格文档

## 1. 业务目标

面向运营机构，在「产品生命周期」列表页操作列提供「生命图谱」入口，跳转至独立整页，以流程图形式可视化展示单个数据产品完整的生命周期流转流程，清晰呈现各阶段的先后顺序与流转关系，并体现「变更」可反复多次（登记 / 上架 / 交易之后均可发起）与「撤销」（发生在登记之后，撤销后不再有上架、交易环节）的特性；并提供「运营周期」视图，以甘特时间轴呈现多次上架 / 下架 / 再上架的区间与先后顺序。点击阶段节点以时间轴式抽屉展示该阶段的发起信息与审批信息。交互与展示方式参照「数据血缘」独立整页。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 入口 | 「产品生命周期」列表页操作列「生命图谱」按钮，跳转至 `/prototypes/product-lifecycle-graph.html?code=<数据产品标识码>` |
| 流程图 | SVG 流程图展示 开发 → 编目 → 安全审查 → 登记 → 上架 → 交易 → 下架 → 撤销 主干流转；「变更」分支（登记 / 上架 / 交易之后发起）与「撤销」分支（登记之后直达终止）以虚线回路体现 |
| 阶段节点 | 9 个阶段节点，按类别配色（前置阶段/核心流转/变更循环/终止环节），展示序号、名称、类别；变更节点带已发生次数角标 |
| 进度呈现 | 依据记录当前阶段，已流转阶段实色、当前阶段高亮、未到达阶段虚线降透明度 |
| 节点交互 | 点击任意阶段节点，右侧抽屉采用与「时间轴」一致的版式，展示该阶段「发起信息」与「审批信息」（单位名称 / 法人经办人姓名 / 操作时间 / 审核结果 / 审核意见），并附阶段说明 |
| 画布交互 | 平移、缩放（滚轮/双指）、重置（控制条 ＋/－/⟳ 与 R 快捷键），初始自适应居中 |
| 返回 | 顶部「返回产品生命周期」入口，或左侧菜单返回 |
| 运营周期 | 顶部视图切换至「运营周期」，以甘特时间轴完整呈现产品每一次上架 / 下架的区间与先后顺序：甘特条区分在售（绿色）/ 停售（灰色）/ 当前进行中（蓝色虚线），并附明细表（序号 / 类型 / 起始日期 / 结束日期 / 持续天数 / 状态）；未上架产品展示空态。流转图谱中上架、下架节点带「×N」次数角标，与运营周期联动 |

## 3. 角色与权限

- 由「产品生命周期」入口跳转，左侧菜单高亮「产品生命周期」，面包屑 `首页 / 产品生命周期`。
- 仅向「运营机构」角色分配；页面为只读展示，不提供写操作。

## 4. 流程图设计

- 主干顺序：开发 → 编目 → 安全审查 → 登记 → 上架 → 交易 → 下架 → 撤销。
- 变更分支：登记、上架、交易之后均可发起「变更」（图中三条「发起变更」分支）；变更后需重新经过「安全审查 → 登记 → 上架」回到上架状态，形成可反复执行的闭合回路（橙色虚线回路箭头，标注「变更后重新安全审查 · 登记 → 上架（可多次）」）。
- 撤销分支：撤销发生在登记之后。除主干「下架 → 撤销（终止运营）」外，另有「登记 → 撤销」直达分支（红色虚线绕行箭头，标注「登记后直接撤销 · 不再上架 / 交易」），表示登记后可直接撤销，且撤销后不再有上架与交易环节。
- 连线走向：主干为水平直线；变更分支向下汇聚至「变更」节点；变更回路向左上绕行回到安全审查；撤销直达分支从主干上方绕行。
- 节点配色：前置阶段 蓝色 `#1890ff`、核心流转 绿色 `#52c41a`、变更循环 橙色 `#fa541c`、终止环节 红色 `#f5222d`。
- 变更次数：由数据产品标识码派生的稳定值（0~3），在变更节点角标展示，体现「变更可能反复多次」。

## 5. 数据说明

- 复用 `product-lifecycle/lifecycle-shared.tsx` 的 `getRecordByCode`、`getStageStatusClass` 按 `code` 定位记录；阶段流程为产品全生命周期通用模型，不随单条记录变化。本页新增的「发起信息 / 审批信息」派生逻辑仅在本页内实现，不修改既有共享逻辑。
- 进度依据记录当前阶段推导：开发、编目恒为已完成；安全审查/登记/上架/交易/下架依当前阶段判定已完成/进行中/未开始；变更、撤销在登记之后呈「可进行（尚未发生）」虚线态，变更一旦发生则标记为已变更次数。
- 变更次数由记录 `id % 4` 稳定派生，保证不同产品展示值稳定且互不相同。
- 「发起信息 / 审批信息」由记录标识码与阶段稳定派生：发起单位取记录提供方，审批单位取「湖南省公共数据运营中心」，经办人取自固定人员池，操作时间以记录更新时间按阶段序号回溯生成；当前阶段审批未完成时审核结果展示为「—」。
- **运营周期（多次上架 / 下架 / 再上架）**：由 `id % 3` 派生「额外再上架轮次」（0~2），据此生成交替的「上架 → 下架」序列。状态切换规则：当前阶段为「产品上架 / 产品交付」→ 末段为进行中的在售（开放上架区间）；当前阶段为「产品下架」→ 末段为进行中的停售（开放下架区间）；当前阶段早于上架（安全审查 / 产品登记）→ 无运营周期（空态）。各区间起止日期由标识码经线性同余伪随机稳定派生并累计，进行中区间按记录更新时间推算已持续天数；整体时间轴按起止跨度等比映射，确保先后顺序与区间长度清晰。上架、下架节点角标次数（×N）与运营周期统计口径一致。

## 6. 交互状态

- 页面初始化依据 URL 参数 `code` 加载记录并自适应铺满画布；无参数或匹配失败时展示「未找到对应的数据产品」并提供返回入口。
- 画布支持平移/缩放/重置，复位快捷键 `R`，步进 `+`/`-`。
- 点击节点滑出右侧抽屉，抽屉版式与「时间轴」一致：阶段序号 / 名称 / 状态标签 → 「发起信息」（单位名称、法人经办人姓名、操作时间）→ 「审批信息」（单位名称、法人经办人姓名、审核结果、审核意见、操作时间）→ 阶段说明。开发 / 编目阶段无审批环节，仅展示发起信息；尚未发生的阶段以「该阶段尚未开始」占位，撤销未发生时展示「尚未撤销」。
- 点击遮罩或关闭按钮收起抽屉。
- 顶部提供「流转图谱 / 运营周期」视图切换：默认展示流转图谱；切换至「运营周期」后，画布区域替换为甘特时间轴与明细表，用于呈现多次上架 / 下架 / 再上架的区间与顺序（详见第 7 节）。
- 全部只读。

## 7. 运营周期设计（多次上架 / 下架 / 再上架）

- **目标**：部分产品在上架后会经历「上架 → 下架 → 再上架」的循环状态变化。运营周期视图以时间轴方式完整呈现每一次上架与下架的区间及先后顺序，清晰区分在售（上架）与停售（下架）两类生命周期阶段，并妥善处理状态切换。
- **视图构成**：顶部汇总（共 N 次上架 · M 次下架 + 当前状态标签） → 图例（在售 / 停售 / 进行中） → 甘特时间轴（单条轨道，按时间跨度等比排布各区间） → 明细表。
- **甘特时间轴**：每一段为一个上架或下架区间，绿色为在售（上架）、灰色为停售（下架）；进行中的当前区间以蓝色虚线描边标注「进行中」，向右延伸至记录更新时间（至今）。区间内标注「第 N 次上架 / 下架」与起止日期；相邻区间交替在轨道上下方标注，避免文字重叠。轨道下方给出起止日期刻度。
- **明细表**：逐条列出序号、类型（上架（在售）/ 下架（停售）彩色标签）、起始日期、结束日期（进行中显示「进行中」）、持续天数、状态（进行中 / 已结束）。
- **状态切换处理**：
  - 未上架（当前阶段早于上架）：展示空态「该数据产品尚未上架，暂无运营周期记录」。
  - 单次上架无下架（再上架轮次为 0 且当前在售）：仅一段进行中的上架区间。
  - 多次循环（再上架轮次 ≥ 1）：交替出现多段上架、下架区间，末段为进行中的上架或下架。
  - 当前停售（当前阶段为下架）：末段为进行中的下架区间。
- **数据联动**：流转图谱中上架、下架节点带「×N」次数角标，与运营周期统计口径一致；点击上架 / 下架节点，抽屉阶段说明中补充提示「可在顶部『运营周期』视图中查看每一次上架 / 下架的区间与先后顺序」。

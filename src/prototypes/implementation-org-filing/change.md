# 原型修改记录 - 实施机构备案

## 2026-10-13
- 新建「实施机构备案」原型模块（备案管理二级模块）。
- 列表主页：表头含序号、授权运营类型、领域名称、实施机构、统一社会信用代码、创建时间、备案状态、备案时间、操作；顶部【+ 实施机构备案】蓝色主按钮；底部分页（共 N 条 / 上一页 / 页码 / 下一页 / 每页条数 / 跳页）。
- 备案状态枚举：已备案（绿）、待省级确认（蓝）、省级退回（红）；操作列按状态展示：已备案→查看/查看存证，待省级确认→查看，省级退回→查看/编辑。
- 实施机构名称超长缩略 + 悬浮查看完整名称。
- 新增弹窗：授权运营类型（默认分领域授权运营）、领域名称、实施机构名称、统一社会信用代码、情况说明；必填校验（带 *），确定提交后状态置「已备案」并生成备案时间。
- 查看弹窗：标题「查看」，右上角固定蓝色【查看存证】按钮；Tab 申请信息 / 审核信息；申请信息两列布局，审核信息为流程历史表（节点状态 / 确认结果绿色标签、经办人脱敏、机构名缩略）。
- 区块链存证弹窗：凭证编号、实施机构、信用代码、类型、领域、地域、备案时间、存证时间、电子证据、区块链 ID、存证状态。
- 省级退回编辑弹窗：复用表单结构预填，提交保存修改。
- 同步注册至公共侧边栏（备案管理分组），activeMenu 添加 implementation-org-filing。

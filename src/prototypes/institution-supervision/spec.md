# 机构监管 页面说明

## 一、页面概述
机构监管页面归属「其他」一级菜单下的二级菜单，面向**数据管理部门**。采用【单页面 + 角色 Tab 筛选】方案，包含顶部统计卡片、角色快捷 Tab、筛选区、机构列表与查看弹窗。数据管理部门在此统一监管全部类型机构（实施机构、运营机构、其他经营主体、行业主管部门），支持全局总览机构统计、多条件检索机构信息，并查看各机构备案详情；点击「查看」时，根据机构角色动态渲染对应角色专属备案信息。

> 业务说明：本页面为数据管理部门统一监管入口，不拆分独立角色页面。

## 二、顶部统计卡片区（页面最上方）
展示全局汇总统计，支持实时刷新（刷新按钮仅重新拉取，数据保持全局稳定）：
1. 机构总数：注册总数、备案总数（平台已备案全部机构合计数量）
2. 实施机构数量：实施机构备案总数
3. 运营机构数量：运营机构备案总数
4. 行业主管部门数量：行业主管部门备案总数
5. 其他经营主体数量：其他经营主体备案总数

## 三、角色快捷 Tab 与筛选区
- 快捷 Tab（点击 Tab 自动填充机构角色筛选）：`全部 | 实施机构 | 运营机构 | 行业主管部门 | 其他经营主体`
- **【全部】Tab** 高级筛选项：所属地域（省-市-区县三级联动）、授权运营类型（整体授权运营 / 分领域授权运营）、领域名称、机构角色、单位/企业名称（模糊检索）、统一社会信用代码、备案时间（起止日期范围）。按钮：【查询】【重置】。
- **各角色 Tab** 筛选区不包含「机构角色」（已由 Tab 固定），其余筛选项与【全部】一致。

## 四、列表字段
| 字段 | 说明 |
| 所属地域 | 所属地域 |
| 授权运营类型 | 整体授权运营 / 分领域授权运营 |
| 领域名称 | 领域名称 |
| 机构角色 | 实施机构 / 运营机构 / 其他经营主体 / 行业主管部门（仅【全部】Tab 展示该列） |
| 单位/企业名称 | 机构全称 |
| 统一社会信用代码 | 统一社会信用代码 |
| 备案时间 | 备案完成的时间 |
| 操作 | 【查看】按钮 |

## 五、查看弹窗
点击「查看」打开机构备案详情弹窗：上半部分为基本信息（单位/企业名称、统一社会信用代码、所属地域、授权运营类型、领域名称、机构角色、备案时间），下半部分依据机构角色动态渲染角色专属备案信息：
- 实施机构：实施方案名称、实施方案备案编号、实施内容概述、备案状态
- 运营机构：运营协议编号、授权运营范围、运营期限、备案状态
- 其他经营主体：经营主体类型、经营范围、关联运营机构、备案状态
- 行业主管部门：主管部门层级、主管行业领域、行政监管职责、备案状态

## 六、交互规则
1. 切换顶部角色 Tab，顶部统计卡片与列表结构固定（统计为全局汇总，不随 Tab 切换改变；列表按所选角色筛选并更新内容）。
2. 列表支持分页，默认每页 10 条。

# 工作台

## 页面定位

`implement-org-workbench` 是后台系统一级菜单中的工作台页面。页面沿用后台统一的侧边栏、顶部栏、面包屑和角色区域，支持实施机构、运营机构、其他经营主体、行业管理部门四类角色切换，并在同一入口展示对应工作台数据。

## 布局结构

1. 外层使用公共后台布局 `Layout`，当前菜单高亮为 `implement-org-workbench`，侧边栏名称为“工作台”。面包屑固定为“工作台”，页面标题随角色显示“{角色}工作台”。
2. 右上角角色切换提供“实施机构 / 运营机构 / 其他经营主体 / 行业管理部门”，切换时同步重置待办和通知列表状态。
2. 主体区域在当前页面内直接维护，总览、待办任务、消息通知和趋势分析代码均在本目录中。
3. 主体区域不再渲染独立面包屑，避免覆盖公共顶部栏的白色面包屑样式。
4. 工作台主体相对顶部栏和左侧边栏保留统一留白：上方 18px、左右 20px、下方 28px。

## 主体内容

主体内容按角色配置展示：

- 实施机构：数据资源、授权、基础数据产品、再开发产品指标，以及数据资源上架/授权趋势。
- 运营机构：基础数据产品总数 19、授权总数 19、再开发产品 26、其他经营主体 5；待办包含数据探查、产品安全审查、产品上架，通知包含资源目录、资源授权、平台资源；趋势切换为基础数据产品上架趋势和产品类型占比。
- 其他经营主体：在指标卡上方展示“数据产品再开发步骤向导”，以连续箭头呈现场景申请、签署协议、产品开发、产品编目、安全审查、产品上架六步流程。标题旁提供唯一的帮助图标，鼠标悬停或键盘聚焦时集中展示全部步骤操作说明；步骤内不再展示帮助图标。四项指标为场景申请总数、再开发数据产品总数、再开发数据产品订阅总数、再开发数据产品调用总数，采用图标、色彩侧边标识、指标名称、数值和今日新增的紧凑布局，不再展示指标释义。下方提供待办、通知和趋势概览。
- 行业管理部门：展示角色指标、消息通知和“再开发数据产品订阅 TOP10”排行榜；不展示待办任务、平台产品上架趋势或授权运营类型占比。TOP10 按订阅次数降序展示排名、产品名称、所属运营机构和订阅次数。

1. 总览部分：数据资源总数、数据资源授权总数、基础数据产品总数、再开发数据产品总数，并展示今日新增。
2. 待办任务：包含待处理、已处理两个页签，列表展示业务名称、提示文案和时间；待处理记录支持点击“处理”跳转、单条或批量标记已处理，已处理记录支持单条或批量删除。
3. 消息通知：包含未读、已读两个页签，列表展示消息类型、通知文案和时间；未读消息支持单条或批量标记已读，已读消息支持单条或批量删除。
4. 统计分析：包含数据资源上架趋势分析、数据资源授权趋势分析，并保留全部、近一年、近30天、近7天筛选。

## 交互约束

1. 不再展示旧版 `implement-org-workbench` 的任务卡片、快捷入口和待办任务表格主体。
2. 不引入独立的顶部栏或侧边栏，避免后台页面出现双层导航。
3. 后续主体内容能力在 `implement-org-workbench` 中直接维护。

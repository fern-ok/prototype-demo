# 运营机构备案（页面说明）

> 公共数据资源授权运营管理平台 → 备案管理 → **运营机构备案**

## 一、列表主页

- **页面标题**：运营机构备案
- **顶部操作按钮**：【+ 运营机构备案】蓝色主按钮，点击弹出新增运营机构备案弹窗。
- **列表表头**：序号、授权运营类型、领域名称、运营机构、统一社会信用代码、实施方案、创建时间、备案状态、备案时间、操作。
- **字段说明**
  - 实施方案：文件链接（PDF），点击可预览 / 下载。
  - 备案状态枚举：**待省级确认、已备案、省级退回**
    - 待省级确认：操作【查看】
    - 已备案：操作【查看、查看存证】
    - 省级退回：操作【查看、编辑】
  - 状态标签：已备案绿色标签；待省级确认蓝色标签；省级退回红色警示标签。
  - 文本溢出：运营机构名称、文件名超长自动缩略，悬浮展示完整内容。
- **分页组件**：总记录数、每页条数下拉（默认 10 条/页）、页码、上/下一页、跳页输入框。

## 二、新增 / 编辑运营机构备案弹窗

- **弹窗标题**：运营机构备案（新增）/ 编辑运营机构备案；右上角关闭 ×。
- **表单字段**

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| 实施方案 | 下拉选择 | * 必填（禁用） | 已完成备案的实施方案，不可修改 |
| 运营机构名称 | 输入框 | * 必填 | 填写运营机构全称 |
| 统一社会信用代码 | 输入框 | * 必填 | 机构信用代码，增加格式校验（18 位，数字 + 大写字母） |
| 附件 | 文件上传 | * 必填 | 位于统一社会信用代码之后；提示：上传运营机构公示结果、专家评审意见等文件，支持 PDF 上传 |
| 情况说明 | 多行文本框 | 非必填 | 备案补充说明文本 |

- **底部按钮**：【取消】【提交】
  - 取消：关闭弹窗，丢弃表单内容。
  - 提交：前端校验必填项；校验通过提交备案，进入备案审核流程（待省级确认）。
- **编辑弹窗**：仅「省级退回」记录触发，回填原有信息，修改后重新提交备案申请。

## 三、查看详情弹窗

- **弹窗标题**：查看；右上角关闭 ×；右上角固定蓝色按钮【查看存证】，点击查看区块链存证凭证。
- **内置双 Tab**：申请信息（默认）、审核信息。
- **Tab1 申请信息**（两列式表单布局）：所属地域、授权运营类型、领域名称、运营机构、统一社会信用代码、实施方案（附件链接）、法人经办人姓名、创建时间、备案状态、备案时间（待审核状态为空）、情况说明。
- **Tab2 审核信息**：备案流程历史表，表头：序号、流程节点、节点状态、单位名称、法人经办人姓名、操作时间、确认结果、处理意见。
  - 节点状态：已完成（绿色标签）。
  - 机构、经办人名称超长缩略展示。
  - 确认结果：备案通过（绿色标签）；退回记录可展示驳回原因。
  - 流程节点示例：提交备案、省级确认备案。

## 四、操作规则

1. 提交备案：填写表单后提交，流转至【待省级确认】。
2. 查看：打开详情弹窗，查看备案申请信息 + 完整审核流程记录。
3. 查看存证：打开存证弹窗，查看本备案记录区块链存证凭证。
4. 编辑：仅【省级退回】记录可用，修改备案信息，重新提交备案申请。

## 五、原型备注

- 实施方案、附件统一为 PDF 文件链接样式，支持在线预览、下载（演示环境以提示代替实际文件）。
- 弹窗点击右上角 × 或弹窗外层遮罩，可关闭弹窗。
- 表单必填项标 *，为空或不合规点击提交时给出提示，阻止提交。
- 状态流转：提交备案 → 待省级确认；省级审核通过 → 已备案（回填备案时间）；省级审核驳回 → 省级退回（可编辑重提）。

## 与原型描述差异说明

- 列表备案状态枚举采用「待省级确认、已备案、省级退回」（与原型描述主表一致）；查看详情 Tab1 备注中出现的「待市级确认 / 市级退回」视为笔误，未采用，全站统一为「省级」口径。
- 新增 / 编辑表单未采集「授权运营类型 / 领域名称 / 所属地域」，新增记录采用默认演示值（省本级 / 分领域授权运营 / 整体）；如需在表单中补充采集这些字段，可再扩展。

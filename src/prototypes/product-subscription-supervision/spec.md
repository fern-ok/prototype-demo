# 产品订阅监管 - 规格文档

## 1. 业务目标

面向数据管理部门，提供全量产品订阅订单的统一查询与监管入口，支持按地域、授权运营类型、领域、产品等条件筛选订阅情况，并可下钻查看单个产品的订阅流水明细，用于监控数据产品的实际使用与订阅合规情况。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 统计概览 | 列表上方一行四列的全量统计：可交易数据产品（个）、累计生成订单（条）、已交付订单（条）、累计调用次数（次） |
| 组合筛选 | 所属地域、授权运营类型、领域名称、产品名称、产品类型、产品提供方、订阅次数，共 7 项，两行排布 |
| 查询 / 重置 | 蓝色主按钮【查询】按当前条件过滤并回到第 1 页；白色次要按钮【重置】清空全部条件恢复全量数据 |
| 订阅列表 | 展示序号、所属地域、授权运营类型、领域名称、产品名称、产品类型、产品提供方、订阅次数、操作 |
| 查看 | 操作列【查看】打开「产品详情」只读弹窗 |
| 查看订阅明细 | 操作列【查看订阅明细】打开「订阅明细」弹窗，展示该产品下的订阅订单流水 |
| 分页 | 页码、上一页/下一页、每页条数、跳页；默认每页 10 条，默认第 1 页 |

## 3. 角色与权限

- 页面归属后台「授权监管」菜单组，为二级子菜单。
- 仅向「数据管理部门」角色分配，页面角色切换器固定显示数据管理部门。
- 页面为只读监管视角，不提供新增、编辑、删除等写操作。

## 3.1 统计概览区

位于筛选区上方，与列表区域共用同一套卡片外壳（白底 `#fff`、细边框 `#dfe5ef`、圆角 4px、`var(--layout-shadow)` 阴影、`margin: 0 18px 10px`）。

| 统计项 | 单位 | 说明 |
| --- | --- | --- |
| 可交易数据产品 | 个 | 平台上架可交易的数据产品总数 |
| 累计生成订单 | 条 | 平台累计生成的订阅订单总数 |
| 已交付订单 | 条 | 累计已完成交付的订单数 |
| 累计调用次数 | 次 | 平台数据产品累计被调用次数 |

- **统计口径：全量统计**，数据来源为模块级常量 `OVERVIEW_STATS`，**不随列表筛选条件联动**（不参与 `filteredList` 计算，不受查询 / 重置影响）。
- 数值统一走 `formatThousands()` 千分位格式化；`tabular-nums` 等宽数字保证对齐。
- 布局：`grid-template-columns: repeat(4, ...)`，桌面端一行四列、项间 1px 竖分隔线；`≤1024px` 降级两列（行间距 14px）；`≤620px` 降级单列并去掉分隔线。
- 标签过长单行省略 + `title` 悬浮显示完整文案。

## 5. 列表字段

| 字段 | 说明 |

| 序号 | 按当前分页连续编号 |
| 所属地域 | 产品归属地域 |
| 授权运营类型 | 整体授权运营 / 分领域授权运营 |
| 领域名称 | 产品所属领域 |
| 产品名称 | 超长截断，悬停显示完整名称 |
| 产品类型 | 蓝色标签展示数据集 / API产品 |
| 产品提供方 | 提供该产品的经营主体，超长截断 |
| 下单次数 | 数值 |
| 销售总额（元） | 位于「下单次数」之后、操作列之前。存储单位为**分**，展示不做单位换算；展示时添加千分位分隔符并**固定保留两位小数**（如 `12,845,600.00`），数字右对齐、内容不换行、列宽自适应 |
| 操作 | 【查看】【查看订阅明细】，从左到右固定顺序 |

### 5.1 金额字段规范

- 字段：`salesAmount`，类型 `number`，存储单位**分**，整数（不含小数位）。
- 格式化：`formatAmountInCents()` 做千分位分隔并固定保留两位小数（如 `12,845,600.00`），不做分→元换算。
- 样式：`.data-table .col-sales-amount` 宽度 150px（随表格布局自适应）、`text-align: right`、`white-space: nowrap`、`font-variant-numeric: tabular-nums` 保证数字等宽对齐。
- 表头标注单位：`销售总额（元）`。

## 6. 订阅明细（订单流水）

明细弹窗顶部展示**产品概要**（从订单明细接口读取），按 3 列 × 2 行网格排列，浅灰背景区分：

| 字段 | 含义 | 类型 |
| --- | --- | --- |
| 所属地域 | 产品归属地域 | string |
| 授权运营类型 | 整体授权运营 / 分领域授权运营 | string |
| 领域名称 | 产品所属领域 | string |
| 产品名称 | 产品标题 | string |
| 产品类型 | 数据集 / API产品 | string |
| 产品提供方 | 提供该产品的经营主体 | string |

- 数据来源：`fetchOrderDetailProduct()` 返回的 `OrderDetailProduct` 对象，字段名与后端保持一致；接口请求期间显示 6 个骨架占位，接口失败时该区域降级为「-」占位、不渲染错误信息。
- 视觉：浅灰背景 `#fafbfc`、细边框 `#edf0f5`，与下方表格区有明显区隔；标签 13px 灰字右对齐 + 英文冒号，值 13px 黑字左对齐；宽屏 3×2 网格，`≤1024px` 降级 2 列，`≤640px` 降级 1 列。
- 边界：空值统一显示 `—`；长值单行省略 + `title` 悬浮显示完整内容。

### 6.0 订阅明细表格字段

| 字段 | 说明 |
| --- | --- |
| 序号 | 按明细分页连续编号 |
| 订单编号 | 订阅订单号 |
| 数据需求方 | 发起订阅的单位名称 |
| 订单状态 | 已下单（蓝色）、交付中（橙色）、已完成（绿色）、已终止（红色）、已冻结（灰色） |
| 订单总额（元） | 位于「订单状态」之后、更新时间之前。存储单位为**分**，展示不做单位换算；千分位分隔并固定保留两位小数、数字右对齐、不换行 |
| 更新时间 | 订单最近一次状态变更时间 |
| 操作 | 位于「更新时间」之后。**仅当该订单对应产品类型为「API产品」时**展示【调用明细】按钮；数据集等非 API 产品不展示该按钮（列保留，单元格为空） |

### 6.0.1 调用明细（仅 API 产品）

点击【调用明细】打开与「订单交付监管」页一致的调用明细弹窗，展示该订单下 API 的调用记录：

- 顶部提示条：统计延时说明 + 【手动刷新】链接（刷新后统计值递增）。
- 汇总统计：API接口名称、调用总次数、调用成功次数、调用失败次数（千分位格式化，`统计中…` 为加载态）。
- 筛选：调用状态（成功 / 失败）、调用时间（近三个月 / 近半年 / 近一年）；【查询】【重置】。
- 表格：序号、调用状态（失败红色高亮）、响应时长(ms)、调用时间、操作（失败行显示【查看失败原因】）。
- 分页：与列表同一套控件，默认 10 条/页。
- 加载态显示「加载中…」；接口失败显示兜底文案；无记录显示「暂无调用记录」。
- 查看失败原因：弹窗展示错误码、调用时间、错误描述。
- 数据来源：`callLogsByOrder` / `callStatsByOrder`，按订单号索引，**仅为 `API产品` 类型的订单生成数据**。

- 明细自带分页控件，默认每页 10 条。
- 订阅次数为 0 的产品，明细表格展示「暂无数据」。
- 订单总额字段：`orderAmount: number`（单位：分），复用 `formatAmountInCents()` 与 `.col-order-amount` 样式，与列表「产品销售总额（分）」保持一致的金额规范。

### 6.1 订阅明细筛选

明细弹窗内置独立筛选区，与列表契约风格一致（内联 label + input，3 列网格，无外框）：

| 筛选项 | 控件 | 提示文字 | 取值 |
| --- | --- | --- | --- |
| 订单编号 | 输入框 | 请输入 | 模糊匹配（不区分大小写） |
| 数据需求方 | 输入框 | 请输入 | 模糊匹配 |
| 订单状态 | 下拉 | 请选择 | 已下单、交付中、已完成、已终止、已冻结 |
| 更新时间 | 日期范围 | 开始日期 - 结束日期 | 按更新时间（YYYY-MM-DD HH:MM:SS）范围筛选；状态为已下单、交付中、已终止、已冻结但无更新时间记录的行在设置范围时排除 |

- 操作按钮【查询】按当前条件过滤并回到第 1 页；【重置】清空全部 4 项条件并恢复当前产品全量明细。
- 筛选与分页、每页条数正确联动：切换每页条数、修改筛选条件均会重置到第 1 页。

## 7. 布局与视觉

- 复用 `Layout` 统一后台侧栏、顶部导航、面包屑和角色区域，面包屑为 `首页 / 授权监管 / 产品订阅监管`。
- 复用 `src/common/backend-list.css` 列表契约（筛选区、表格、分页、操作按钮、状态标签），页面样式仅补充列宽与弹窗样式。
- 延续蓝色主按钮、浅蓝表头、细边框、紧凑型 ToB 表格密度。
- 页面标题为「产品订阅监管」。

## 8. 交互状态

- 页面初始化不带筛选条件，自动加载全部产品订阅数据。
- 重置后列表刷新回全量数据并回到第 1 页。
- 无数据场景：表格展示空白提示「暂无数据」。
- 弹窗支持点击遮罩关闭。
- 长文本单元格截断，悬停显示完整内容。
- 表格列宽固定不换行；操作列不裁剪按钮，容器宽度不足时表格区域出现横向滚动条。

## 9. 数据说明

- 演示数据共 12 条产品订阅记录，覆盖不同地域、授权运营类型、领域与产品类型。
- 订阅订单明细按产品订阅次数生成（单产品最多 10 条），覆盖已下单、交付中、已完成、已终止、已冻结五种订单状态。
- 第 12 条产品订阅次数为 0，用于演示明细空态。

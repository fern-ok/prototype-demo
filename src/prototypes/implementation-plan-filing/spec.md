# 实施方案备案

> 归属：公共数据资源授权运营管理平台 → 备案管理 → 实施方案备案
> 角色视图：实施机构
> 说明：本页面为实施方案备案二级模块，提供实施方案备案的列表管理、新增 / 编辑 / 变更备案（PDF 附件上传）、备案详情查看（申请信息 / 审核信息）、区块链存证查看能力。

## 一、列表主页

### 页面标题
实施方案备案

### 顶部操作按钮
- 【+ 实施方案备案】蓝色主按钮，点击弹出「新增实施方案备案」弹窗。

### 列表表头字段
序号、授权运营类型、领域名称、实施方案、会议纪要、创建时间、备案状态、备案时间、操作

### 列表字段说明
1. 实施方案、会议纪要：文件链接，点击可预览 / 下载 PDF 文件；文件名过长自动缩略，悬浮展示完整名称。
2. 备案状态枚举：**待提交、待省级确认、已备案、省级退回**
   - 待提交：操作列展示【查看、编辑、提交备案】
   - 待省级确认：操作列仅展示【查看】
   - 已备案：操作列展示【查看、变更、查看存证】
   - 省级退回：操作列展示【查看、编辑】
3. 标签样式：状态使用标签展示
   - 已备案：绿色标签
   - 待省级确认：蓝色默认标签
   - 省级退回：红色警示标签
   - 待提交：灰色草稿标签
4. 文本溢出：文件名过长自动缩略，悬浮展示完整内容。

### 底部分页组件
- 记录统计：共 N 条记录
- 分页控件：上一页 / 页码 / 下一页、每页条数下拉（默认 10 条 / 页）、跳页输入框

## 二、新增 / 编辑 / 变更实施方案备案弹窗

- 弹窗标题：新增实施方案备案 / 编辑实施方案备案 / 变更实施方案备案
- 带关闭 × 按钮；点击弹窗外部 / 取消按钮可关闭弹窗，取消不保存数据。

### 表单字段（PDF 上传）
| 字段 | 类型 | 是否必填 | 提示文案 | 说明 |
| --- | --- | --- | --- | --- |
| 实施方案 | 文件上传 | * 必填 | 请上传经 “三重一大” 决策机制审议通过的实施方案 | 支持 PDF 上传，列表展示文件链接 |
| 会议纪要 | 文件上传 | * 必填 | 请上传会议纪要、盖章文件或者相关签批件 | 支持 PDF 上传 |
| 附件 | 文件上传 | * 必填 | 请上传 “湘办通” 联审通过的相关证明 | 支持 PDF 上传 |
| 情况说明 | 多行文本框 | 非必填 | 请输入 | 备案补充说明文本 |

### 弹窗底部按钮
- 【取消】：关闭弹窗，丢弃表单内容。
- 【提交】：前端校验必填附件是否上传；校验通过提交备案，进入备案审核流程。
- 编辑弹窗：仅「省级退回」记录触发，回填原有信息，提交后重新提交备案申请（流转至待省级确认）。
- 变更弹窗：仅「已备案」记录触发，回填原有全部附件与情况说明，提交后发起变更备案流程（流转至待省级确认）。

## 三、查看详情弹窗

- 弹窗标题：查看
- 右上角关闭 × 按钮；右上角固定蓝色按钮【查看存证】，点击查看区块链存证凭证。
- 弹窗内置 Tab 页：**申请信息、审核信息**

### Tab1：申请信息（默认激活）
采用两列式表单布局，字段如下：
| 字段 | 说明 |
| --- | --- |
| 所属地域 | 实施机构归属地域（省本级 / 地市 / 区县） |
| 授权运营类型 | 备案业务类型，如分领域授权运营 |
| 领域名称 | 业务领域，如卫生健康、交通 |
| 实施机构 | 提交备案的机构全称 |
| 报审实施方案 | 附件链接（对应表单「附件」），可点击下载预览 |
| 实施方案 | 附件链接，可点击下载预览 |
| 会议纪要 | 附件链接，可点击下载预览 |
| 创建时间 | 备案申请提交时间 |
| 法人经办人姓名 | 经办人信息 |
| 备案时间 | 备案办结时间（待审核状态为空，显示为 -） |
| 备案状态 | 状态标签（已备案 / 待省级确认 / 省级退回 / 待提交） |
| 情况说明 | 备案填写的补充说明 |

### Tab2：审核信息（点击切换）
备案流程历史表格，展示全流程节点记录。
表头：序号、流程节点、节点状态、单位名称、法人经办人姓名、操作时间、确认结果、处理意见、附件
- 节点状态：已完成（绿色标签）；进行中（灰色）。
- 机构、经办人名称超长缩略展示；法人经办人姓名脱敏展示。
- 确认结果：备案通过（绿色标签）；省级退回展示驳回原因（红色标签）。
- 流程节点示例：提交备案、省级确认备案；省级退回展示「省级退回备案」节点。

## 四、区块链存证弹窗
- 弹窗标题：区块链存证凭证
- 展示凭证编号、实施机构、授权运营类型、领域名称、所属地域、实施方案、备案时间、存证时间、电子证据、区块链 ID、存证状态（已确认）。
- 底部【关闭】【下载凭证】按钮（下载为演示功能）。

## 五、交互规则
1. 提交备案：待提交记录，填写并上传材料后点击列表【提交备案】，流转至【待省级确认】。
2. 查看：打开详情弹窗，查看申请材料 + 完整审核流程记录。
3. 查看存证：打开存证弹窗，查看本备案记录区块链存证凭证。
4. 变更：仅【已备案】记录可用，修改备案材料，提交后重新走备案审核流程（待省级确认）。
5. 编辑：仅【省级退回】记录可用，修改材料，重新提交备案申请（待省级确认）；【待提交】草稿亦可编辑后保存。
6. 状态流转
   - 新增保存 → 待提交（草稿）
   - 提交备案 → 待省级确认
   - 省级审核通过 → 已备案，回填备案时间，可发起变更
   - 省级审核驳回 → 省级退回，支持编辑重提

## 六、原型备注
- 附件统一为 PDF 文件链接样式，支持在线预览、下载（演示为点击弹窗提示）。
- 弹窗点击右上角 × 或者弹窗外层遮罩，可关闭弹窗。
- 表单必填项标 *，未上传必填附件点击提交时给出提示，阻止提交。

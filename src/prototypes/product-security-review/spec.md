# 数据产品安全审查管理列表

## 业务与功能

### 核心目标
为数据产品开发管理提供安全审查管理列表，支持待处理和已处理两个TAB页切换，实现审查申请单的筛选、查看、审查、存证查看等功能。

### 功能清单
- 待处理TAB：展示所有待审查的安全审查申请单据，支持筛选查询和审查操作。
- 已处理TAB：展示所有已审查完成的单据（审查通过/审查不通过），支持筛选查询和查看存证。
- 筛选查询：根据申请单号、产品名称、产品类型、产品来源、申请时间、审查时间、审查状态等条件筛选。
- 审查操作：对待审查单据进行审查，录入产品资料审查结果、产品代码审查结果、审查意见。
- 查看详情：查看安全审查详情（只读）。
- 查看存证：查看区块链存证信息。
- 角色权限：本页面仅分配给「运营机构」和「实施机构」角色，其余角色不可见；角色切换下拉框仅提供这两个选项。

### 交互要点
- TAB切换：点击待处理/已处理切换数据视图，切换时重置筛选条件和页码。
- 待处理操作列：【查看】、【审查】
- 已处理-审查通过操作列：【查看】、【查看存证】
- 已处理-审查不通过操作列：【查看】
- 审查弹窗：打开时表单为空白，仅产品名称自动回显。
- 审查规则：两项审查结果只要任意一项不通过，最终状态为审查不通过；两项全部通过则审查通过。
- 提交审查成功后，列表自动刷新更新审查状态和审查时间。
- 分页：页码切换、每页条数切换、跳至指定页。

## 内容规划

### 信息架构
```text
产品安全审查
├── 顶部筛选区（根据TAB动态变化）
├── TAB切换（待处理 / 已处理）
├── 列表数据区
├── 审查弹窗
├── 查看详情弹窗
└── 查看存证弹窗
```

### 数据来源
- 数据类型：安全审查申请记录
- 关键字段：
  - `reviewNo`：申请单号
  - `productName`：产品名称
  - `productType`：产品类型（API产品/数据集/数据报告）
  - `industryCategory`：行业分类
  - `productSource`：产品来源（可信数据空间/数据开发中心）
  - `legalHandler`：法人经办人姓名
  - `unitName`：单位名称
  - `applyTime`：申请时间
  - `reviewTime`：审查时间
  - `reviewStatus`：审查状态（待审查/审查通过/审查不通过）
  - `materialResult`：产品资料审查结果
  - `codeResult`：产品代码审查结果
  - `reviewOpinion`：审查意见

## 布局与结构

### 整体布局
- 布局模式：左侧导航 + 右侧顶部栏 + 内容区的后台管理布局。
- 筛选区：一行四个筛选条件，日期范围选择器占单列。
- TAB区：筛选区下方，数据表格上方。
- 弹窗：审查弹窗、查看详情弹窗、查看存证弹窗均使用居中模态框。

### 响应式适配
- 桌面端保持 180px 左侧导航与流式内容区。
- 小宽度场景保留最小宽度，避免后台表格和筛选条件挤压错位。

## 视觉规范

### 设计规范
- 遵循项目通用视觉规范，使用 Layout 组件提供的布局和主题变量。
- 主色调：蓝色 #0f63f4
- 待处理状态标签：蓝色
- 审查通过标签：绿色

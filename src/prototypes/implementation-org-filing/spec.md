# 实施机构备案

> 归属：公共数据资源授权运营管理平台 → 备案管理 → 实施机构备案
> 角色视图：实施机构
> 说明：本页面为实施机构备案二级模块，提供实施机构备案的列表管理、新增备案、备案详情查看（申请信息 / 审核信息）、区块链存证查看与省级退回后的编辑能力。

## 一、列表主页

### 页面标题
实施机构备案

### 顶部操作按钮
- 【+ 实施机构备案】蓝色主按钮，点击弹出「新增实施机构备案」弹窗。

### 列表表头字段
序号、授权运营类型、领域名称、实施机构、统一社会信用代码、创建时间、备案状态、备案时间、操作

### 列表行说明
1. 备案状态枚举：**已备案、待省级确认、省级退回**
   - 已备案：操作列展示【查看】【查看存证】
   - 待省级确认：操作列仅展示【查看】
   - 省级退回：操作列展示【查看】【编辑】
2. 文本溢出处理：实施机构名称过长自动缩略（省略号），悬浮可查看完整名称。
3. 标签样式：状态使用标签展示
   - 已备案：绿色标签
   - 待省级确认：蓝色默认标签
   - 省级退回：红色警示标签

### 底部分页组件
- 记录统计：共 N 条记录
- 分页控件：上一页 / 页码 / 下一页、每页条数下拉（默认 10 条 / 页）、跳页输入框

## 二、新增实施机构备案弹窗

- 弹窗标题：实施机构备案
- 带关闭 × 按钮；点击弹窗外部 / 取消按钮可关闭弹窗，取消不保存数据。

### 表单字段
- **布局**：授权运营类型、领域名称各占一整行（独占一行，不与其他字段并排）；其下依次为实施机构名称、统一社会信用代码、附件、情况说明。
| 字段 | 类型 | 是否必填 | 提示文字 | 备注 |
| --- | --- | --- | --- | --- |
| 授权运营类型 | 下拉选择框 | * 必填 | 默认选项：分领域授权运营 | 下拉枚举可选业务类型；独占整行 |
| 领域名称 | 下拉选择框 | * 必填 | 请选择领域名称 | 选择对应业务领域；独占整行 |
| 实施机构名称 | 输入框 | * 必填 | 请输入实施机构名称 | 机构全称 |
| 统一社会信用代码 | 输入框 | * 必填 | 请输入统一社会信用代码 |  |
| 附件 | 文件上传 | * 必填 | 上传会议纪要或其他佐证实施机构的文件证明 | 支持 PDF 上传；位于统一社会信用代码之后 |
| 情况说明 | 文本域 | 非必填 | 请输入 | 可填写备案补充描述，支持多行 |

### 弹窗底部按钮
- 【取消】：关闭弹窗，丢弃表单内容。
- 【确定】：表单校验（必填项非空）；校验通过提交备案信息，创建备案记录，状态置为「已备案」并生成备案时间。

## 三、查看详情弹窗

- 弹窗标题：查看
- 右上角关闭 × 按钮；右上角固定蓝色按钮【查看存证】，点击跳转 / 弹窗展示该备案记录区块链存证信息。
- 弹窗内置 Tab 页：**申请信息、审核信息**

### Tab1：申请信息（默认激活）
采用两列式表单布局，字段如下：
| 字段 | 说明 |
| --- | --- |
| 所属地域 | 实施机构归属地市 / 区县 |
| 授权运营类型 | 备案选择的运营类型 |
| 领域名称 | 备案选择领域 |
| 实施机构 | 机构全称 |
| 统一社会信用代码 | 机构信用代码 |
| 法人经办人姓名 | 法人经办人姓名 |
| 创建时间 | 备案申请提交时间 |
| 备案状态 | 状态标签（已备案 / 待省级确认 / 省级退回） |
| 备案时间 | 备案办结时间（待审核状态该字段为空，显示为 -） |
| 情况说明 | 备案提交时填写的补充说明，长文本自动换行 |

### Tab2：审核信息（点击切换）
流程历史表格，展示备案全流程节点记录。
表头：序号、流程节点、节点状态、单位名称、法人经办人姓名、操作时间、确认结果、处理意见
- 节点状态：已完成（绿色标签）
- 法人经办人姓名脱敏展示（保留首尾，中间 * 替代）；机构名称超长缩略。
- 确认结果：备案通过（绿色标签）
- 流程示例节点：提交备案、区县级确认备案

## 四、区块链存证弹窗
- 弹窗标题：区块链存证凭证
- 展示凭证编号、实施机构、统一社会信用代码、授权运营类型、领域名称、所属地域、备案时间、存证时间、电子证据、区块链 ID、存证状态（已确认）。
- 底部【关闭】【下载凭证】按钮（下载为演示功能）。

## 五、编辑弹窗（省级退回）
- 仅在备案状态为「省级退回」时，操作列展示【编辑】。
- 复用新增备案表单结构，预填已有数据；提交后保存修改（状态保持「省级退回」）。

## 六、交互规则
1. 查看：打开详情页面，查看该实施机构备案完整信息。
2. 查看存证：跳转 / 弹窗展示该备案记录区块链存证信息。
3. 备案状态流转：新增提交后，状态变更为「已备案」，生成备案时间。
4. 表单校验：带 * 为必填项，为空点击确定给出提示，阻止提交。

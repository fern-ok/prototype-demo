# 生命周期 - 规格文档

## 1. 业务目标

面向运营机构，在「产品生命周期」列表页操作列提供「生命周期」入口，跳转至独立整页，以「运营周期 / 操作记录」双视图展示单个数据产品完整的生命周期（原「流转图谱」流程视图已移除）；「运营周期」视图内容与「生命周期1」完全一致（蛇形回折跑道时间轴，详见第 7 节）。交互与展示方式参照「数据血缘」独立整页。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 入口 | 「产品生命周期」列表页操作列「生命周期」按钮，跳转至 `/prototypes/product-lifecycle-graph.html?code=<数据产品标识码>` |
| 节点交互（抽屉） | 右侧抽屉采用与「时间轴」一致的版式，展示阶段「发起信息」与「审批信息」（单位名称 / 法人经办人姓名 / 操作时间 / 审核结果 / 审核意见），并附阶段说明（原由流程图谱节点点击触发，流程图谱移除后该入口暂不对外展示，代码保留） |
| 返回 | 顶部「返回产品生命周期」入口，或左侧菜单返回 |
| 运营周期 | 顶部视图切换至「运营周期」，视图内容完整复用「生命周期1」的全部内容（蛇形回折跑道时间轴，与原甘特时间轴面板无任何保留）：按时间顺序线性展示已实际执行的步骤（多次上架 / 下架 / 变更以 ×N 徽标区分），画布支持拖拽平移 / 滚轮缩放 / 重置，右下角缩放工具栏与鸟瞰缩略小地图，点击节点右侧抽屉展示发起信息 / 审批信息 |
| 操作记录 | 顶部视图切换至「操作记录」，页签顶部以流程图形式按业务流转顺序排列 7 个环节节点：开发、编目、安全审查、登记、上架、交易、下架，节点间以连线箭头体现流转方向；已完成 / 进行中环节正常醒目，未流转环节弱化显示；点击节点切换下方操作记录列表，记录含序号、操作时间、法人经办人姓名、单位名称、审核意见、审核结果；上架 / 下架按实际发生次数生成多条记录，尚未发生的环节展示空态（详见第 8 节） |

## 3. 角色与权限

- 由「产品生命周期」入口跳转，左侧菜单高亮「产品生命周期」，面包屑 `首页 / 产品生命周期`。
- 仅向「运营机构」角色分配；页面为只读展示，不提供写操作。

## 5. 数据说明

- 复用 `product-lifecycle/lifecycle-shared.tsx` 的 `getRecordByCode`、`getStageStatusClass` 按 `code` 定位记录；阶段流程为产品全生命周期通用模型，不随单条记录变化。本页新增的「发起信息 / 审批信息」派生逻辑仅在本页内实现，不修改既有共享逻辑。
- 进度依据记录当前阶段推导：开发、编目恒为已完成；安全审查/登记/上架/交易/下架依当前阶段判定已完成/进行中/未开始；变更、撤销在登记之后呈「可进行（尚未发生）」虚线态，变更一旦发生则标记为已变更次数。
- 变更次数由记录 `id % 4` 稳定派生，保证不同产品展示值稳定且互不相同。
- 「发起信息 / 审批信息」由记录标识码与阶段稳定派生：发起单位取记录提供方，审批单位取「湖南省公共数据运营中心」，经办人取自固定人员池，操作时间以记录更新时间按阶段序号回溯生成；当前阶段审批未完成时审核结果展示为「—」。
- **运营周期（多次上架 / 下架 / 再上架）**：由 `id % 3` 派生「额外再上架轮次」（0~2），据此生成交替的「上架 → 下架」序列。状态切换规则：当前阶段为「产品上架 / 产品交易」→ 末段为进行中的在售（开放上架区间）；当前阶段为「产品下架」→ 末段为进行中的停售（开放下架区间）；当前阶段早于上架（安全审查 / 产品登记）→ 无运营周期。上架、下架节点角标次数（×N）沿用该统计口径。「运营周期」视图本身不再单独实现，完整复用「生命周期1」共享组件 `LifecycleTrackView` 的线性展开逻辑（含多次上架 / 下架 / 变更的线性节点序列与第一条数据固定 20 步演示数据，口径与「生命周期1」一致）。

## 6. 交互状态

- 页面初始化依据 URL 参数 `code` 加载记录并自适应铺满画布；无参数或匹配失败时展示「未找到对应的数据产品」并提供返回入口。
- 画布支持平移/缩放/重置（由「运营周期」视图复用「生命周期1」的 `LifecycleTrackView` 提供，详见第 7 节）。
- 点击节点滑出右侧抽屉，抽屉版式与「时间轴」一致：阶段序号 / 名称 / 状态标签 → 「发起信息」（单位名称、法人经办人姓名、操作时间）→ 「审批信息」（单位名称、法人经办人姓名、审核结果、审核意见、操作时间）→ 阶段说明。开发 / 编目阶段无审批环节，仅展示发起信息；尚未发生的阶段以「该阶段尚未开始」占位，撤销未发生时展示「尚未撤销」。
- 点击遮罩或关闭按钮收起抽屉。
- 顶部提供「运营周期 / 操作记录」视图切换：默认展示「运营周期」；切换至「运营周期」后，内容区域替换为「生命周期1」的全部内容（蛇形回折跑道时间轴，详见第 7 节）；切换至「操作记录」后，内容区域替换为 7 环节切换 + 操作记录列表（详见第 8 节）。
- 全部只读。

## 7. 运营周期设计（内容完整复用「生命周期1」）

- **目标**：部分产品在上架后会经历「上架 → 下架 → 再上架」的循环状态变化。「运营周期」视图的内容已完整替换为「生命周期1」的全部内容，与「生命周期1」完全一致，不保留任何原有内容（原甘特时间轴面板 `ServiceCyclePanel`、`CYCLE_STATE_TEXT`、`fmtTs` 已整体移除）。
- **实现**：直接复用 `product-lifecycle-graph1/index.tsx` 导出的共享组件 `LifecycleTrackView`（入参 `record`），并引入 `product-lifecycle-graph1/graph1-style.css`；两处共用同一组件，后续对「生命周期1」内容的调整将同步体现到本视图。
- **视图内容（与「生命周期1」一致）**：蛇形回折跑道时间轴——时间主线自画布左上起始、向右延伸，至边界平滑向下折返形成蛇形连续时间带；仅展示已实际执行过的步骤（含多次上架 / 下架 / 变更，重复节点以右上角「×N」徽标区分第几次），未执行步骤一律不显示，无任何支线 / 分支 / 回路；跑道与节点卡片**不再按「前置阶段 / 核心流转 / 变更循环 / 终止环节」分类配色**，改为**按环节状态着色**：待处理（蓝）、审核不通过（红）、审核通过（绿）；当前进行中的环节记为「待处理」，已执行完成的环节记为「审核通过」；节点卡片沿跑道依次排布并标注操作时间；第一条数据（列表按更新时间倒序后的首行）使用固定 20 步演示数据。具体设计见 `product-lifecycle-graph1/spec.md`。
- **交互（与「生命周期1」一致）**：画布支持拖拽平移、滚轮缩放，右下角保留缩放工具栏（＋ / － / ⟳，快捷键 R / + / -）与鸟瞰缩略小地图；点击节点从右侧抽屉展示「发起信息 / 审批信息」（单位名称、法人经办人姓名、操作时间、审核结果、审核意见），点击遮罩或关闭按钮收起；抽屉中不再额外显示节点说明文字（变更 / 上架 / 下架 的说明均已去掉）。
- **数据联动**：运营周期视图的上架、下架节点带「×N」次数角标，由 `buildServiceCycles` 派生，口径不变。

## 8. 操作记录视图（环节流程图 + 操作记录列表）

- **入口**：顶部「运营周期 / 操作记录」视图切换中的「操作记录」页签（位于「运营周期」之后）。
- **环节流程图**：视图顶部以流程图形式按业务流转顺序横向排列 7 个环节节点：开发、编目、安全审查、登记、上架、交易、下架（不含变更、撤销）；节点之间以连线 + 箭头体现流转方向与先后关系；节点卡片含序号徽标、环节名称与分类副标签（前置阶段 / 核心流转），配色沿用 `CAT_STYLE` 分类色系。
- **进度状态区分**：已完成与当前进行中的环节使用正常醒目颜色（当前环节加粗描边高亮），已流转区间的连线箭头同步点亮；尚未流转到的环节使用更浅更淡的弱化样式（灰调、虚线描边、降低透明度），可直观看出整体流程与当前所处位置。
- **节点交互**：点击任一环节节点即选中（蓝色描边光圈标识），下方列表同步切换为该环节的操作记录，切换流畅无刷新。
- **响应式**：流程图条带支持窄屏横向滚动，节点文字不换行、保持可读；列表区随窗口自适应。
- **记录列表**：下方表格展示当前选中环节的操作记录，列为：序号、操作时间、法人经办人姓名、单位名称、审核意见、审核结果；审核结果以彩色标签呈现（审核通过绿色 / 审核不通过红色 / 其余灰色「—」）。
- **数据派生（稳定可复现）**：
  - 上架、下架环节按运营周期统计口径（`buildServiceCycles` 的 shelfCount / unshelfCount）生成多条记录（第 N 次），其余环节各 1 条；仅展示已实际发生的环节，尚未发生的环节展示空态「当前环节暂无操作记录（该环节尚未发生）」。
  - 操作时间由 `deriveStageTime` 按环节序号与发生次序回溯派生；法人经办人由标识码散列从固定人员池选取；单位名称取记录提供方。
  - 开发、编目无审批环节：审核结果展示「—」，审核意见展示「本环节无审批环节」；当前进行中的环节仅最后一次操作取当前阶段状态（已完成→审核通过、已驳回→审核不通过、其余→—），此前各次均视为审核通过。
- **样式**：复用既有 `life-cycles-table` 表格与空态风格，新增 `life-records` / `life-records-flow` / `life-flow-node` / `life-flow-arrow` / `life-record-result` 样式（仅本页生效），整体与页面既有风格一致。

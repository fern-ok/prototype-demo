# 原型修改记录 - 实施方案备案

## 2026-10-13
- 新建「实施方案备案」原型模块（备案管理二级模块）。
- 列表主页：表头含序号、授权运营类型、领域名称、实施方案、会议纪要、创建时间、备案状态、备案时间、操作；顶部【+ 实施方案备案】蓝色主按钮；底部分页（共 N 条 / 上一页 / 页码 / 下一页 / 每页条数 / 跳页）。
- 实施方案、会议纪要列为 PDF 文件链接（点击预览 / 下载，悬浮展示全名，超长缩略）。
- 备案状态枚举（4 项）：待提交（灰）、待省级确认（蓝）、已备案（绿）、省级退回（红）；操作列按状态展示：待提交→查看/编辑/提交备案，待省级确认→查看，已备案→查看/变更/查看存证，省级退回→查看/编辑。
- 新增 / 编辑 / 变更弹窗：实施方案、会议纪要、附件均为 PDF 必填上传控件，附情况说明（非必填）；必填校验（带 *），未上传阻止提交。
  - 新增提交 → 待提交（草稿）；列表【提交备案】→ 待省级确认。
  - 编辑（省级退回）→ 重新提交（待省级确认）；编辑（待提交）→ 保存草稿。
  - 变更（已备案）→ 重新走审核流程（待省级确认）。
- 查看弹窗：标题「查看」，右上角固定蓝色【查看存证】按钮；Tab 申请信息 / 审核信息；申请信息两列布局（含报审实施方案 / 实施方案 / 会议纪要文件链接）；审核信息为流程历史表（含附件列，节点状态 / 确认结果绿色标签、经办人脱敏、机构名缩略，省级退回展示驳回原因）。
- 区块链存证弹窗：凭证编号、实施机构、类型、领域、地域、实施方案、备案时间、存证时间、电子证据、区块链 ID、存证状态。
- 字段映射决策：表单「附件（湘办通联审证明）」在查看详情「申请信息」中对应展示为「报审实施方案」；因表单未采集授权运营类型 / 领域名称 / 实施机构 / 所属地域，新增记录采用默认演示值（省本级 / 分领域授权运营 / 卫生健康 / 湖南省数据产业集团有限公司），后续可按需补充采集字段。
- 同步注册至公共侧边栏（备案管理分组），activeMenu 添加 implementation-plan-filing。

## 2026-10-14
- 优化新增 / 编辑 / 变更弹窗中文件上传控件的提示文字展示：`.upload-name` 取消单行省略，改为自动换行（white-space: normal），并调整上传按钮与提示文字居中对齐（align-items: center），确保「附件」等较长提示说明完整可见且与按钮在同一水平线上。

## 2026-10-14
- 再次调整文件上传控件：`.upload-control` 改为 `align-items: center`，使「选择文件」按钮与提示文字垂直居中对齐、保持在一条水平线上；`.upload-name` 增加 `text-align: left` 和 `word-break: break-all`，保证换行后左对齐。

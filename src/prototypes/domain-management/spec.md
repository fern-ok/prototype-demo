# 领域管理

## 业务与功能

- 归属：公共数据资源授权运营管理平台后台，一级菜单为“系统管理”，二级菜单为“领域管理”。
- 使用角色：数据基础设施运营方。页面右上及侧栏底部显示当前角色与模块授权关系。
- 核心任务：维护公共数据资源业务领域和展示排序。
- 操作：按领域名称检索和重置；分页浏览；新增领域；编辑领域名称和排序；二次确认删除领域。

## 信息结构与数据

- 页面框架：复用公共后台 `Layout` 组件，与其他后台模块公用顶部栏、侧边栏、角色切换、通知和页面说明入口。系统管理菜单中，领域管理处于激活态。
- 表格字段：序号、领域名称、创建时间、排序、操作。
- 初始数据：卫生健康、气象服务、文化旅游、交通运输、城市治理、自然资源、工业制造、创新金融、智慧农业、体育竞技等。
- 领域名称必填、不可重复；排序必填，且为大于 0 的整数。新增记录写入当前时间。

## 布局与交互

- 公共顶部栏和侧边栏由后台 `Layout` 统一提供；内容区仅呈现领域管理标题、筛选区和领域表格。筛选条件、列表间距与颜色、分页及按钮样式复用后台需求管理页面的规范。
- 筛选区支持点击查询或 Enter 提交，重置后恢复完整列表。
- 新增和编辑使用表单弹窗；删除使用包含领域名称的确认弹窗。点击遮罩、关闭或取消均不更改数据。
- 表格每页默认 10 条，可切换为 20 条；筛选及切换每页条数时回到第 1 页。

## 视觉规范

- 设计意图：为需要高频维护基础字典的运营人员提供稳定、低干扰、可快速扫描的政务后台操作环境。
- 色彩：主按钮使用需求管理同款蓝色 `#0f63f4`，筛选区和列表使用同款白底、`#dfe5ef` 边框与浅蓝表头；红色仅用于删除风险提示。
- 深度策略：采用低对比度边框区分内容层级，避免卡片投影干扰表格阅读。
- 字体：Microsoft YaHei / PingFang SC；表格时间和排序使用等宽数字对齐。基础间距为 4px。
- 响应式：850px 以下压缩侧栏和筛选区，620px 以下保留图标侧栏并允许表格横向滚动。
# 公共样式

列表页基础样式统一复用 `src/common/backend-list.css`，筛选、按钮、表格、操作链接和分页与产品和服务清单备案页保持一致。
筛选区底部统一为左侧“查询”“重置”，右侧放置“新增”按钮。

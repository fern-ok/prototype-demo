# 生命周期1 - 规格文档

## 1. 业务目标

作为「产品生命周期」列表页「生命周期」的**并列**数据展现形式，以全新的**蛇形回折跑道时间轴**形态呈现产品生命周期。与「生命周期」（流程图 + 变更回路 + 撤销分支）不同，本页采用连续「跑道」时间带：时间主线自画布左上起始、向右延伸，到达画布边界时平滑向下折返、继续向右排布，形成蛇形回折的连续时间带；跑道按业务阶段以低饱和底色分段着色，仅展示已经实际执行过的步骤，未进行的步骤一律不显示，且不存在任何支线 / 分支 / 回路，形成单一时间序列。

## 2. 入口与定位

- 入口：原列表页操作列「生命周期1」按钮已**直接删除**（代码移除，非隐藏），列表不再提供入口；页面仍可通过 URL `/prototypes/product-lifecycle-graph1.html` 直接访问，且其主内容组件 `LifecycleTrackView` 被「生命周期」页「运营周期」视图复用。
- 参数传递：跳转时携带当前数据产品标识码，URL 形如 `?code=DP43010020260001`；页面依据该参数从演示数据中定位记录并加载，支持直接访问与刷新（刷新后参数保留，数据可复现）。
- 返回：页面顶部提供「返回产品生命周期」入口，返回列表页；亦可通过左侧菜单「产品生命周期」返回。
- 页面标题：「生命周期1」；面包屑：`首页 / 产品生命周期`（左侧菜单高亮「产品生命周期」）；顶部工具条中部展示当前产品标识码、名称与「当前阶段」。
- 共享复用：本页全部主内容（蛇形回折跑道时间轴画布、缩放工具栏、鸟瞰缩略小地图、节点抽屉）已抽取为导出组件 `LifecycleTrackView`（入参 `record`）；「生命周期」页「运营周期」视图直接复用该组件并引入本页 `graph1-style.css`，内容与本页完全一致（顶部工具条属页面自身，不在共享范围内）。

## 3. 蛇形回折跑道时间轴形态（核心规则）

- **视觉形式与「生命周期」保持一致**：节点采用相同的圆角矩形卡片样式，含左上角编号、阶段名称、完成时间（节点名称下方的分类小字已隐藏、不再展示，原位置改放完成时间 `MM-DD HH:mm`）；分类配色与图例与「生命周期」完全一致（前置阶段蓝、核心流转绿、变更循环橙、终止环节红）。
- **连续跑道时间带（蛇形回折，U 形平滑弯道）**：时间主线自画布左上起始、向右延伸，到达右端边界时以 **180° 半圆弧**平稳向下折返、继续向左排布，至左端再以半圆弧折返向右，如此往复形成蛇形回折的连续时间带（跑道）。整条跑道由**单条连续中心线路径**以粗描边绘成：横向直道与半圆弯道在衔接点**切线连续（G1 平滑）**，行与行之间无锐角折角、无矩形 T 形接缝，视觉连贯自然。两侧直道向内缩进，为半圆回折预留回转半径（= 行中心距的一半），保证弯道圆润饱满。奇数行（第 2、4… 行）节点自右向左反向排布，使相邻行首尾自然衔接于半圆折返处。
- **跑道按环节状态分段着色**：跑道与节点卡片统一按环节状态着色——当前进行中节点为「待处理」（蓝色 `#1890ff`），当前阶段被驳回时为「审核不通过」（红色 `#f5222d`），其余已执行完成节点为「审核通过」（绿色 `#52c41a`）。同一记录中当前进行中的环节**仅有一个**。
- **操作时间标注**：各节点的完成时间以 `MM-DD HH:mm` 形式直接展示于卡片内（位于原分类小字位置，由标识码派生、依时间先后递增）；原「贯穿跑道的白色竖刻度线」与跑道下方的时间文字均**已隐藏、不再展示**（渲染代码保留、由 CSS 隐藏），节点中间不再出现白线。
- **业务节点卡片沿跑道排布**：卡片展示序号（从 1 开始连续递增）、步骤名称与完成时间（阶段分类小字已隐藏，其位置改放完成时间）；多次发生的步骤（上架 / 下架 / 变更，且发生次数 >1）右上角增加圆形角标标识发生次数（如 ×2）。**卡片之间有明显的横向空隙**：节点节距（相邻节点中心距）大于卡片宽度，二者之差即留白（约 44px），卡片互不紧贴，读起来更透气；节点间的流转箭头恰好落在该空隙内。
- **时间流转方向箭头**：节点之间使用沿跑道走向的短小箭头标识时间流转方向——同行内为水平箭头（奇数行自动反向），折返处为**严格沿跑道中心线的 180° 半圆弧形箭头**（起止点取相邻两行中心线、半径与跑道基底半圆一致，弧线居中不偏摆），标识时间向下／回折流转。跑道本身不使用任何流动/动画效果。
- **严格按时间线顺序**：流程节点依时间先后依次排列，形成单一时间序列，例如：上架节点之后接续变更节点，再接续下架节点，最后接续上架节点。
- **仅展示已执行步骤**：未进行的步骤一律不显示；时间线由记录当前阶段回溯，已流转阶段纳入。**当前进行中的环节仅有一个**，标记为「待处理」（当前阶段状态含“不通过/未通过”时显示「审核不通过」）；其前所有已执行节点标记为「审核通过」，其后尚未发生的阶段不展示。
- **无分支 / 无回路**：不存在任何支线、分支或变更回路箭头，节点依时间先后排成一条蛇形回折的单一序列。**每行最多展示 8 个节点**，超过则折返至下一行继续排布。
- 节点构成（按时间顺序）：
  - 前置阶段：开发、编目（始终执行）。
  - 核心流转：安全审查、登记（卡片显示名「首次登记」）、上架、交易、下架（仅展示已执行到的节点）。
  - 变更（卡片显示名「变更登记」）：可插入在「首次登记」之后或「上架」之后，并可在后续运营周期中反复多次，作为线性序列的普通节点，不形成回路；多次变更以右上角「×N」徽标区分。
  - 撤销（卡片显示名「撤销登记」）：仅在已执行到撤销阶段时展示。
  - 上架 / 下架按「运营周期」口径展开为多次事件（如 上架 → 变更 → 下架 → 上架），依时间顺序线性排列；重复的上架 / 下架节点以右上角「×N」徽标区分第几次。
- 每个节点展示：序号（从 1 开始连续递增，与展示顺序一致）、阶段名称、完成时间（位于原分类小字位置，格式 `MM-DD HH:mm`）、状态标签（当前节点为「待处理」，若当前阶段状态含“不通过/未通过”则当前节点显示「审核不通过」，其余已执行节点为「审核通过」）。**节点名称下方的分类小字不展示**（代码保留、CSS 隐藏），状态通过跑道分段底色与顶栏图例体现；原跑道下方的时间文字已隐藏、避免与卡片内时间重复。
- **第一条数据固定演示**：列表页按「更新时间」倒序后的首行记录，在「生命周期1」中固定展示 20 步完整蛇形序列，不受记录当前阶段动态推导限制。固定序列如下：
  1. 开发 → 2. 编目 → 3. 安全审查 → 4. 登记 → 5. 变更（登记后） → 6. 上架① → 7. 变更（上架后） → 8. 交易① → 9. 下架① → 10. 上架② → 11. 变更③ → 12. 交易② → 13. 下架② → 14. 上架③ → 15. 变更④ → 16. 交易③ → 17. 下架③ → 18. 上架④ → 19. 交易④ → 20. 撤销。
  该序列严格按时间先后顺序排列，无分支、无回路，所有步骤均为已执行状态，最后一步「撤销」标记为当前节点，沿蛇形跑道时间轴排布（前 8 步第 1 行从左到右，第 9–16 步第 2 行从右到左，第 17–20 步第 3 行从左到右）。

## 4. 交互

- 节点点击：点击任意节点，从页面右侧滑出抽屉面板，展示该阶段序号、阶段名称、状态标签与操作时间（含「发起信息」与「审批信息」）。
- 抽屉收起：点击抽屉外遮罩或抽屉右上角关闭按钮均可收起抽屉。
- 异常态：缺少 `code` 参数或标识码未匹配到记录时，页面展示「未找到对应的数据产品」提示并提供返回入口。
- 全部只读。

## 5. 视觉

- 复用 `Layout` 统一后台侧栏、顶部导航、面包屑和角色区域。
- 复用「生命周期」整页的顶栏、图例、节点 SVG 样式与抽屉样式（`product-lifecycle-graph/graph-style.css`），节点分类配色与图例保持一致：前置阶段（蓝 `#1890ff`）、核心流转（绿 `#52c41a`）、变更循环（橙 `#fa541c`）、终止环节（红 `#f5222d`）。
- 与「生命周期」的关键差异：以蛇形回折「跑道时间轴」呈现单一时间序列，跑道按业务阶段低饱和分段着色、白色竖刻度线标记操作时间、关键拐点设黄色里程碑气泡，节点间为沿跑道走向的短小箭头（含折返处竖向箭头），不存在变更回路、撤销绕行等分支。
- 画布交互：支持**拖拽平移**与**滚轮缩放**（以光标为锚点），右下角保留缩放工具栏（＋ / 百分比 / － / ⟳ 重置，快捷键 `R` 重置、`+` / `-` 缩放）；右下角同时提供**鸟瞰缩略小地图**，实时显示当前视口位置，点击 / 拖拽小地图可快速导航定位。
- 蛇形跑道时间轴专属样式（节点卡片、刻度、里程碑、缩略图、提示）由本页 `graph1-style.css` 定义，不影响其他页面。

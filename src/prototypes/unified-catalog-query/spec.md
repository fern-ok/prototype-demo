# 统一目录查询

## 1. 页面定位
公共数据资源授权运营管理平台 - 备案管理 - 统一目录查询页面。数据管理部门（监管）角色进入该页面后，跨平台聚合查看授权运营平台、资源登记平台、政务信息资源等不同来源的目录数据，仅提供查看权限，不开放新增、编辑、删除等写入操作。

## 2. 业务目标
- 为数据管理部门提供统一的目录数据查询入口，在一个页面内即可跨数据来源掌握公共数据资源的目录全貌。
- 通过资源持有方、目录来源、更新时间等维度统计资源分布，支撑数据资源规划与监管决策。
- 与各实施机构的资源登记平台、运营机构的授权运营平台之间形成"前台各自登记、后台统一查看"的数据治理闭环。

## 3. 功能清单
| 模块 | 说明 |
| --- | --- |
| 顶部统计卡片 | 展示资源持有方（家）数量与目录总数（条），筛选条件变化时同步刷新 |
| 筛选查询区 | 支持资源名称、资源持有方、目录来源（下拉）、更新时间（起止日期）四个筛选条件 |
| 列表表格 | 展示序号、资源名称、资源持有方、目录来源、更新时间，提供查看入口 |
| 查看详情 | 弹窗展示该目录条目的完整元数据（资源名称、提供方、来源平台、所属领域、更新时间、目录描述等），只读 |
| 分页组件 | 总记录文案、页码、每页条数、跳转输入框，默认 10 条/页 |
| 数据权限 | 监管角色查看权限；不提供新增、编辑、删除、导出按钮 |

## 4. 字段定义
| 字段 | 数据类型 | 说明 |
| --- | --- | --- |
| id | number | 目录条目唯一 id |
| name | string | 资源名称（数据资源的对外展示名） |
| provider | string | 资源持有方 / 提供机构 |
| source | enum[] | 目录来源，可存储一个或多个来源值，限值：授权运营平台 / 资源登记平台 / 政务信息资源；筛选时按包含关系匹配，任一来源均可独立检索对应资源 |
| domain | string | 资源所属领域（用于查看弹窗展示），例如卫生健康、交通运输、金融服务等 |
| updateTime | string | 该目录条目最近一次更新时间，格式 `yyyy-MM-dd HH:mm:ss` |
| description | string | 目录描述（用于查看弹窗展示） |

## 5. 角色与权限
- 该页面在后台侧边栏为**一级菜单**（位于"工作台"之后、"备案管理"分组之前），不是任何分组的子项。
- 面包屑展示为"首页 / 统一目录查询"，无父级分类层级。
- 角色切换器固定显示"数据管理部门"。
- 数据管理部门仅可查询、查看，不可在该页面进行目录的增删改。

## 6. 布局与视觉
- 整体沿用 `src/common/Layout.tsx` 提供的公共后台布局（侧边栏 + 顶部栏 + 主体）。
- 主体采用上 → 中 → 下三段：
  1. 顶部 2 个统计卡片，左右各 1，卡片内部展示图标、数值、计量单位说明。
  2. 中部为筛选查询卡片，沿用 `src/common/backend-list.css` 的四列栅格筛选 + 单行按钮区；【查询】与【重置】按钮在按钮区左侧对齐。
  3. 底部为表格 + 分页卡片，同样沿用公共样式。
- 统计卡片底色白底、细边框、卡片圆角 4px、数值使用 24px 粗体，配以左侧浅色图标底块。
- 操作列仅保留【查看】，使用蓝色文字链接；按钮使用 backend-list.css 的 `.btn .btn-primary .btn-default` 风格。
- 表格行高、字号（13px）、浅蓝表头与现有后台列表保持一致。

## 7. 交互规则
| 场景 | 行为 |
| --- | --- |
| 默认状态 | 表单为空，统计卡显示全量统计，表格显示全部数据 |
| 查询 | 按当前筛选条件过滤数据；目录来源为多值字段时按包含关系匹配，任一已配置来源均可独立命中资源；统计卡片同步重算；分页回到第 1 页 |
| 重置 | 清空所有筛选条件，统计卡片恢复全量统计，分页回到第 1 页 |
| 更新时间校验 | 若起始日期晚于结束日期，前端展示提示"起始日期不能晚于结束日期"，不执行查询 |
| 查看 | 弹出查看弹窗，展示该条目录的完整元数据，点击遮罩或关闭按钮关闭弹窗 |
| 分页 | 支持首页/上一页/下一页/末页、页码跳转、每页条数下拉切换 |
| 无数据 | 表格展示"暂无数据"占位，统计卡片数值保持当前筛选下的统计结果（无结果时显示 0） |
| 新增/编辑/删除 | 不提供入口；监管角色只读 |

## 8. 数据来源
- 内置 seed 数据 `SEED_RECORDS`，用于演示目录列表与统计；第二条数据配置“授权运营平台”和“政务信息资源”两个目录来源，用于验证多值筛选。
- 列表 key 唯一，按 `updateTime` 倒序展示。
- 查看弹窗通过该条记录的 id 索引展示元数据。

## 9. 公共样式
列表页基础样式统一复用 `src/common/backend-list.css`，筛选、按钮、表格、操作链接、分页以该样式为基准。统计卡片、查看弹窗与少量表格列宽定义在原型自身 `style.css`。

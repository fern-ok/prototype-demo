# 产品生命周期 - 规格文档

## 1. 业务目标

面向运营机构，提供数据产品从「安全审查 → 产品登记 → 产品上架 → 产品交易 → 产品下架」全生命周期的统一跟踪入口。以「数据产品」为粒度展示当前所处阶段与阶段状态，支持按产品标识码、名称、类型、阶段、提供方、当前阶段、阶段状态、更新时间组合检索，并可查看产品档案、阶段流转时间轴与数据血缘关系，用于掌握产品加工链路与流转进度。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 组合筛选 | 数据产品标识码、产品名称、产品类型、产品阶段、产品提供方、当前阶段、阶段状态、更新时间，共 8 项，两行排布（每行 4 项；「更新时间」位于第二行第 4 格，单列日期范围） |
| 查询 / 重置 | 蓝色主按钮【查询】按当前条件过滤并回到第 1 页；白色次要按钮【重置】清空全部条件恢复全量数据 |
| 生命周期列表 | 展示序号、数据产品标识码、产品名称、产品类型、产品阶段、产品提供方、当前阶段、阶段状态、更新时间、操作 |
| 查看 | 打开「产品详情」只读弹窗，按「基本信息 / 配置信息」两个页签展示产品档案。基本信息页签下含「基本信息 / 提供方信息 / 声明信息」三个区块：基本信息包含产品名称、类型、覆盖时间范围、行业/地域分类、是否涉及个人信息、交付方式、授权使用、数据主体、数据规模、更新频率、个人或企业授权使用、数据资源标识码（蓝色高亮）、产品简介、使用限制、产品开发方案/实施方案/运营协议附件、领域名称；提供方信息包含名称/主体类型/身份标识码/法人经办人姓名/电话/授权委托书附件/简介；声明信息包含数据样例、合法合规声明/数据来源声明附件、安全分级分类、数据质量产品价值评估报告。配置信息页签按产品类型分支展示——数据集产品展示「字段信息」表（序号/字段名称/字段中文名/数据类型/主键/允许为空/描述），API产品展示「API接口信息」（接口名称/接口地址/请求方式/返回格式/接口描述）及请求参数表、返回参数表。底部仅【关闭】（详见第 6 节） |
| 时间轴 | 打开「生命周期时间轴」弹窗，按 安全审查 → 产品登记 → 产品上架 → 产品交易 → 产品下架 顺序展示各阶段流转记录 |
| 数据血缘 | 跳转至独立整页「数据血缘」，以分层图谱展示 数据源系统 → 数据资源 →（基础产品）→ 数据产品 →（数据服务）的血缘链路，并附血缘关系明细表；页面通过 `?code=数据产品标识码` 定位记录，支持直接访问与刷新 |
| 生命周期 | 跳转至独立整页「生命周期」，以流程图形式可视化展示产品完整的生命周期流转：开发 → 编目 → 安全审查 → 登记 → 上架 → 交易 → 下架 → 撤销，并以回路体现「变更」可反复多次；页面通过 `?code=数据产品标识码` 定位记录，支持直接访问与刷新 |
| 默认排序 | 列表按「更新时间」倒序排列，最新在前；查询/重置/翻页后排序不变 |
| 分页 | 共 X 条记录 + 上一页/页码/下一页 + 每页条数 + 跳页；默认每页 10 条，默认第 1 页 |

## 3. 角色与权限

- 页面为后台**一级菜单**「产品生命周期」，无父级菜单，面包屑展示 `首页 / 产品生命周期`。
- 仅向「运营机构」角色分配，页面角色切换器固定显示运营机构。
- 页面为只读跟踪视角，不提供新增、编辑、删除等写操作。

## 6. 产品详情弹窗（查看）

- 标题：「产品详情」，只读展示；弹窗尺寸为大弹窗（`modal-large`），支持点击遮罩与【关闭】按钮关闭。
- 弹窗顶部为两个 TAB 页签：「基本信息」「配置信息」。打开时默认显示「基本信息」，切换时保留当前查看记录；点击同一页签不刷新内容。
- **基本信息页签**：包含「基本信息 / 提供方信息 / 声明信息」三个区块。
  - **基本信息**：产品名称、产品类型、覆盖时间范围、行业分类、地域分类、是否涉及个人信息、交付方式、授权使用、数据主体、数据规模、更新频率、个人或企业授权使用。
    - 数据资源标识码：整行展示，蓝色高亮文本。
    - 产品简介、使用限制：整行展示。
    - 产品开发方案、实施方案、运营协议、领域名称：附件（PDF）以文件 chip 形式展示，可点击下载；无附件时单元格留空。
  - **提供方信息**：提供方名称、提供方主体类型、身份标识码、法人经办人姓名、法人经办人电话、授权委托书（PDF 附件）、提供方简介。
  - **声明信息**：数据样例、合法合规声明（PDF 附件）、数据来源声明（PDF 附件）、安全分级分类、数据质量产品价值评估报告。
- **配置信息页签**：按产品类型分支展示，完整保留不得删除或覆盖。
  - 数据集产品：展示「字段信息」表，列含 序号、字段名称、字段中文名、数据类型、主键（是/否）、允许为空（是/否）、描述，由 `buildDatasetFields()` 稳定派生（5~9 个字段）。
  - API产品：先展示「API接口信息」网格（接口名称、接口地址、请求方式 POST、返回格式 JSON、接口描述），再分别展示「请求参数」表（参数名、参数位置、必填、字段类型、说明）与「返回参数」表（参数名、字段类型、说明），由 `buildApiInfo()` 稳定派生。
- 底部仅提供【关闭】按钮。
- 所有字段由 `buildProductDetail()` / `buildDatasetFields()` / `buildApiInfo()` 稳定派生；不展示「流程信息」「审查情况」等图片中未出现的区块。

## 7. 生命周期时间轴弹窗（时间轴）

- 标题：「生命周期时间轴」。
- 顶部概要条：数据产品标识码、产品名称、产品类型、产品阶段，便于核对当前查看对象。
- 时间轴按阶段流转顺序自上而下排列：安全审查 → 产品登记 → 产品上架 → 产品交易 → 产品下架。
- 每个节点展示：序号、阶段名称、阶段状态标签，以及两组结构化信息块（操作时间仅展示在发起信息内，节点头部不重复展示；不展示处理说明行）：
  - 发起信息：单位名称（取产品提供方）、法人经办人姓名、操作时间。
  - 审批信息：单位名称（固定「湖南省公共数据运营中心」）、法人经办人姓名、审核结果（已完成 → 审核通过 / 已驳回 → 审核不通过 / 其他状态 → —，标签绿底绿字 / 红底红字）、审核意见（通过 / 「首次××不通过，材料修改后重新提交」 / —）、操作时间（已完成 / 已驳回 → 取节点操作时间；其他状态 → —）。
- 当前阶段节点高亮（蓝色实心圆点 + 蓝色阶段名）；已流转完成的节点状态统一为「已完成」；当前阶段为已驳回/已终止/已暂停时，流转在该阶段终止，其后阶段不展示。
- 全部只读，底部仅提供【关闭】按钮。

## 8. 数据血缘独立整页（数据血缘）

- 入口：列表页操作列「数据血缘」按钮，跳转至独立整页 `/prototypes/product-lifecycle-lineage.html`，不再以弹窗形式展示。
- 参数传递：跳转时携带当前数据产品标识码，URL 形如 `?code=DP43010020260001`；页面依据该参数从演示数据中定位记录并加载，支持直接访问与刷新（刷新后参数保留，数据可复现）。
- 返回：页面顶部提供「返回产品生命周期」入口，返回列表页；亦可通过左侧菜单「产品生命周期」返回。
- 页面标题：「数据血缘」；面包屑：`首页 / 产品生命周期`（左侧菜单高亮「产品生命周期」）。
- 全屏图谱：图谱占满 `Layout` 内容区可视区域，无额外标题栏与卡片边距；SVG 随容器尺寸自适应重绘，节点与连线始终可见。
- 辐射式布局（SVG 绘制，带箭头贝塞尔连线）：
  - 中心节点：当前数据产品，类型为「一级产品」（蓝色），固定居中。
  - 上游节点：左侧均匀分布 4 个「数据资源」（橙色），名称为 `<地域><领域>数据资源1~4`。
  - 下游节点：右侧均匀分布 5 个「再开发产品」（绿色），名称为 `再开发产品-产品1~5`。
  - 边：每个上游节点连向中心节点，中心节点连向每个下游节点，箭头指向血缘下游。
  - 节点按类型配色：数据资源（橙色 `#fa541c`）、一级产品（蓝色 `#1890ff`）、再开发产品（绿色 `#52c41a`）；节点名称超长截断，悬停显示完整名称。
  - 节点标签：每个节点分两行、**统一居左**展示——第一行为名称（数据资源节点显示资源名称、基础 / 再开发产品节点显示产品名称，超长截断并悬停显示完整名称）；第二行显式带字段前缀：数据资源节点显示「资源格式：<格式>」（如 `资源格式：OFD`），基础 / 再开发产品节点显示「产品类型：<类型>」（如 `产品类型：API产品` / `产品类型：数据集`）。即：基础与再开发产品节点显示「产品名称 + 产品类型」、数据资源节点显示「资源名称 + 资源格式」，且「产品类型：」「资源格式：」前缀文字均常驻展示。
- 节点交互：点击任意节点，从页面右侧滑出抽屉面板；抽屉标题为节点类型，页签按节点类型动态展示：
  - 数据资源节点：展示「基本信息」「授权信息」两个页签。
  - 基础产品节点：展示「基本信息」「授权信息」两个页签。
  - 再开发产品节点：展示「基本信息」「交易信息」两个页签。
  - 基本信息：按节点类型分支展示。点击「数据资源」节点，展示资源名称、数据资源标识码、行业分类、是否涉及个人信息、资源格式、数据来源、更新频率、覆盖时间范围、地域分类、资源持有方、资源摘要共 11 项（字段顺序与数据资源目录一致）；点击「基础产品 / 再开发产品」节点（含中心节点），展示数据产品基本信息 16 项：产品名称、数据产品标识码、产品类型、覆盖时间范围、行业分类、地域分类、是否涉及个人信息、交付方式、授权使用、数据主体、数据规模、更新频率、个人或企业授权使用、产品简介、使用限制、提供方名称。
  - 授权信息（数据资源节点）：固定展示四项授权信息——实施机构（湖南省卫生健康委信息统计中心）、运营机构（湖南数据产业集团）、授权发起方（运营机构）、授权时间（2026-06-15 14:20:00）。
  - 授权信息（基础产品节点）：列表展示序号、运营机构、授权时间，按授权时间倒序排列，并配备分页组件（可切换每页条数）；演示数据由节点名派生，稳定且各节点互不相同。
  - 交易信息（再开发产品节点）：列表展示序号、数据需求方、创建时间，按创建时间倒序排列，并配备分页组件（可切换每页条数）；演示数据由节点名派生，稳定且各节点互不相同。
- 抽屉收起：点击抽屉外遮罩或抽屉右上角关闭按钮均可收起抽屉，收起后不干扰图谱的平移/点击等交互。
- 图例：页面顶部工具条右侧按节点类型展示色块说明。
- 节点筛选（可搜索筛选框）：画布左上角固定悬浮一个可搜索筛选框，支持按资源名称或产品名称筛选节点：
  - 位置固定：绝对定位于画布容器左上角（`top: 16px; left: 16px`），不随画布平移 / 缩放变换，缩放比例与拖拽位置变化时始终停留在原位，层级（`z-index: 30`）高于图谱节点与连线。
  - 搜索输入：输入框占位文字「搜索资源名称 / 产品名称」，按关键字对全部节点名称（数据资源 + 基础产品 + 再开发产品）模糊匹配（不区分大小写）；有内容时展示「清空」按钮与匹配数量提示（「匹配 N 个节点」/ 无匹配时红字「无匹配节点」）。
  - 下拉候选：聚焦 / 输入时展开候选列表，展示全部或按关键字过滤后的节点（带类型色块与类型名称），点击候选项即选中该名称作为筛选条件；点击筛选框外部收起候选列表。
  - 高亮标记：输入或选择筛选条件后，名称命中的节点以橙色加粗描边（`#fa8c16`，2.5px）加橙色光晕投影重点标记，与之相连的连线同步高亮为橙色加粗；未命中的节点与连线保持原有样式不变。节点点击查看详情等既有交互不受影响；清空筛选条件后图谱恢复原状。
- 画布交互（平移 / 缩放 / 重置）：整页图谱支持对画布的平移、缩放与重置，各能力互不冲突、可叠加操作：
  - 平移：在画布空白处按住鼠标（或单指触控）拖拽，整体平移全部节点与连线；拖动超过阈值（4px）即判定为平移，不会误触发节点点击。平移范围按 G6 / X6 标准钳制：内容始终覆盖可视区域，不允许把整图拖到视口外（缩放比例 < 1 时整图居中、不可平移）。
  - 缩放：桌面端滚动鼠标滚轮以光标位置为锚点缩放；移动端双指捏合缩放（以双指中点为锚点）；缩放比例限定在 40%~300% 之间并持续保留，直至主动重置或刷新页面。
  - 重置：右下角悬浮控制条提供「放大 ＋ / 缩小 － / 重置 ⟳」三个按钮并实时显示当前缩放百分比；点击「重置」或按键盘 `R` 快捷键，画布视图回到初始状态（居中、100%）；`+` / `-`（或 `=` / `_`）键亦可步进缩放。
  - 叠加与固定：可在任意缩放比例下继续拖拽平移；控制条、抽屉遮罩与缩略图浮层均不随画布变换，始终固定在视口原位，保证操作可达且不干扰图谱其余交互。
- 缩略图（概览 / minimap）：画布右下角、缩放工具栏上方固定悬浮一个缩略图浮层，与主图同步展示血缘拓扑，便于快速定位与导航：
  - 形态与位置：浅灰背景（`#F7F8FA`）、细灰边框、圆角 4px；默认宽 200px、高 140px；位于右下角缩放工具栏上方，二者互不重叠；层级（`z-index: 30`）高于画布节点连线、低于抽屉弹窗（90 / 100），不会被节点遮挡也不会盖住弹窗。
  - 内容与配色：等比例缩小绘制全部节点与连线，配色与主图一致（橙色 = 数据资源、蓝色 = 基础产品、绿色 = 再开发产品）；不渲染节点文字，仅展示位置与连线拓扑，避免密密麻麻看不清。
  - 视口框：白色实线矩形、带半透明浅蓝填充，代表当前主画布正在查看的可视范围；当主图放大很大时视口框最小宽高限制为 12px，防止缩成看不见。
  - 交互：① 在缩略图内按住白色视口框拖动，主画布同步平移，视口框不可拖出缩略图容器边界（拖到边缘自动停住）；② 点击缩略图任意空白区域，视口框中心点跳到点击位置，主画布直接平移跳转；③ 主画布平移 / 缩放（按钮、滚轮、手势）时，缩略图白色视口框实时更新位置与大小（100ms 节流，避免高频重绘卡顿）；④ 缩略图区域内鼠标滚轮禁用缩放，滚轮只作用于主画布，防止误触。
  - 收起 / 展开：右上角「−」按钮收起缩略图；收起后在左下角出现悬浮按钮【显示概览】，点击恢复展开并保持上次内容；初始状态默认展开。
  - 异常适配：全图整体小于当前视口时，视口框自动填满图形区域，此时拖动视口框无效果；节点 / 连线变化（切换记录）时缩略图自动重绘拓扑；顶部搜索框命中唯一节点时主画布自动将其平移到视口中心，缩略图视口框同步跳转。
- 异常态：缺少 `code` 参数或标识码未匹配到记录时，页面展示「未找到对应的数据产品」提示并提供返回入口。

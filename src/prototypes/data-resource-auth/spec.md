# 数据资源授权

## 1. 页面概述

- **页面名称**：数据资源授权
- **页面用途**：供实施机构查看自己提交的全部资源授权单据；支持条件筛选、分页；提供新增授权、查看授权记录入口；根据审核状态动态展示【查看】【编辑】【查看存证】操作按钮。
- **角色分配**：实施机构

## 2. 页面结构

### 2.1 筛选查询区域

| 字段名称 | 控件类型 | 说明 |
|---------|---------|------|
| 资源授权单名称 | 输入框 | 模糊检索授权单名称 |
| 数据资源目录 | 输入框 | 模糊检索资源目录名称 |
| 审核状态 | 下拉选择框 | 选项：待初审、初审不通过、待复审、复审不通过、复审通过 |
| 创建时间 | 日期范围选择器 | 单据创建起止时间筛选 |
| 更新时间 | 日期范围选择器 | 单据更新起止时间筛选 |

右上角操作按钮：
- **清空**：一键清空全部筛选条件
- **搜索**：执行条件查询，刷新表格数据
- **授权记录**：打开授权记录弹窗，展示单据统计概览和最近记录
- **数据资源授权**：打开新增授权弹窗，发起新的授权申请

### 2.2 表格列表

| 列 | 说明 |
|----|------|
| 序号 | 表格行序号，从 1 开始 |
| 资源授权单名称 | 资源授权单据名称 |
| 数据资源目录 | 授权绑定的数据资源目录，支持多个资源分号分隔展示 |
| 审核状态 | 待初审 / 初审不通过 / 待复审 / 复审不通过 / 复审通过 |
| 创建时间 | 单据提交创建时间 |
| 更新时间 | 单据最新修改、审核流转时间 |
| 操作 | 动态操作按钮组，根据审核状态控制显隐 |

#### 操作列权限规则

| 审核状态 | 操作按钮 | 说明 |
|---------|---------|------|
| 待初审 | 查看 | 仅可读查看单据详情，不可编辑 |
| 初审不通过 | 查看、编辑 | 查看：查看详情；编辑：修改后重新提交 |
| 待复审 | 查看 | 单据已过初审，等待复审，发起方不可编辑 |
| 复审不通过 | 查看、编辑 | 查看：查看详情；编辑：修改后重新提交 |
| 复审通过 | 查看、查看存证 | 查看：查看详情；查看存证：查看区块链存证信息 |

### 2.3 分页组件

- 分页控件：上一页、页码、下一页
- 每页条数下拉：10 条 / 页
- 跳至：输入页码跳转

### 2.4 弹窗交互

| 弹窗 | 触发条件 | 说明 |
|------|---------|------|
| 查看详情 | 点击【查看】 | 只读展示单据全部内容，包括基本信息、初审信息、复审信息 |
| 编辑单据 | 点击【编辑】 | 修改单据名称、资源目录，提交后状态回到【待初审】 |
| 查看存证 | 点击【查看存证】 | 展示区块链存证信息：哈希、区块高度、存证时间等 |
| 授权记录 | 点击【授权记录】 | 展示单据统计概览和最近授权记录列表 |
| 新增授权 | 点击【数据资源授权】 | 新建授权申请单，提交后进入【待初审】 |

## 3. 业务规则

1. 筛选条件全部为空，默认查询当前登录发起方的全部授权单据，按创建时间倒序排列
2. 空数据：展示空状态提示「暂无数据」
3. 编辑仅驳回状态（初审不通过、复审不通过）可见；编辑完成提交后，单据回到【待初审】状态
4. 查看存证仅复审通过状态可见
5. 查看为所有状态通用操作
6. 待初审、待复审：已经进入审核流程，发起方不允许编辑
7. 初审不通过 / 复审不通过：允许编辑修改，重新提交，再次进入待初审
8. 复审通过：流程完结，只允许查看详情、查看区块链存证，不允许编辑

## 4. 数据模型

```typescript
interface AuthRecord {
  id: number;
  authName: string;        // 资源授权单名称
  resourceCatalog: string; // 数据资源目录（分号分隔）
  reviewStatus: string;    // 审核状态
  createTime: string;      // 创建时间
  updateTime: string;      // 更新时间
  initiator: string;       // 发起方
  unitName: string;        // 单位名称
  reviewResult?: string;   // 初审结果
  reviewOpinion?: string;  // 初审意见
  reviewer?: string;       // 初审人
  reviewTime?: string;     // 初审时间
  recheckResult?: string;  // 复审结果
  recheckOpinion?: string; // 复审意见
  recheckReviewer?: string; // 复审人
  recheckTime?: string;    // 复审时间
  evidenceHash?: string;   // 存证哈希
  evidenceTime?: string;   // 存证时间
}
```

## 5. 审核状态枚举

- 初审不通过
- 待复审
- 复审不通过
- 复审通过

# 监控大屏（公共数据授权运营大屏）

## 业务与功能

### 核心目标
授权运营平台后台的"监控大屏"菜单项所对应的可视化驾驶舱页面。用于全局展示公共数据授权运营的核心指标与分布情况，单页可视化大屏，深蓝色科技风，适合投屏展示。新页签全屏打开，不嵌入后台常规布局。

### 功能清单
- 顶部 4 个核心指标卡：数据资源总数、场景总数、基础数据产品总数、再开发数据产品总数（含数值 + 单位 + 关联子指标）。
- 主区域三列布局，中间"数据资源领域名称分布"湖南地图纵向贯通占满指标卡以下全部高度：
  - 左列上：环形图——再开发数据产品订阅行业占比。
  - 左列下：折线图——再开发数据产品订阅趋势分析（2026-04 ～ 2026-09）。
  - 右列上：环形图 + 三列图例——数据资源行业分布（左侧多彩圆环、右侧 3×3 色点图例，颜色与扇区一一对应）。
  - 右列中：基础数据产品授权次数 TOP10。
  - 右列下：再开发数据产品订阅次数 TOP10。

### 交互要点
- 大屏为只读可视化页面，不做增删改操作。
- 监控大屏由授权运营后台一级菜单触发，另开新页签全屏展示。
- 不复用门户 `PortalLayout`，自带顶部标题栏与背景。
- 进入页面需通过 `PasswordGuard` 密码保护。

## 布局与结构

### 整体布局
- 全屏 1920×1080 视角设计，采用 CSS Grid 两行布局：标题区 / 主区域三列（`row-main`）。
- 标题栏高约 70px，居中标题"公共数据授权运营大屏"，两侧装饰角与发光边框。
- 主区域三列比例约 29% / 42% / 29%；中列"数据资源领域名称分布"纵向贯通占满主区域全高；左列上下两面板按 46 / 54 分配高度，右列三个面板按 36 / 32 / 32 分配高度（flex 权重）。
- 卡片使用深蓝渐变背景 + 圆角 + 发光描边统一视觉。
- 图表均使用 ECharts 渲染（项目已安装 echarts 6.x）。

### 响应式适配
- 采用「固定设计稿 + 等比缩放」方案：页面按 1920×1080 设计稿固定布局（`.screen-viewport` 视口容器 + `.data-screen` 固定舞台），JS 监听窗口 resize 计算 `scale = min(视口宽/1920, 视口高/1080)`，通过 `transform: scale()` 整体缩放并居中。
- 任意分辨率与宽高比（含 4K、1366×768、超宽屏、非 16:9 屏幕）下内容均完整呈现：无溢出、无截断、无滚动条、无元素重叠；比例不匹配时上下或左右留边，留边区域填充同款深蓝渐变背景保持视觉连贯。
- 图表容器为固定像素尺寸，ECharts 仅按舞台尺寸渲染一次，缩放由 transform 完成，不引发重排或画布模糊问题。

### 自定义设计要点
- 背景：深蓝（#0a1f44 → #0d3a6e 渐变）+ 中心发光的 HUNAN 字样叠加；地图只在中间面板渲染一次，背景不重复渲染地图。
- 主色：科技蓝 #1e88ff / 青蓝 #00d4ff；强调色橙 #ff9d4d。
- 指标卡大数字使用 28px 粗体，辅助小指标 16px。
- 卡片左上角装饰小三角 + 标题 + 副标题，标题前一个菱形点。
- 图表配色统一蓝/青/橙三色系，环图按行业分配不同色；行业占比面板内环形图（flex:1 自适应）与两列图例（固定面板底部内侧）纵向排布。
- 字体：系统默认无衬线 + 数字部分使用等宽风格（CSS `font-feature-settings`）。

# 再开发数据产品监管 - 规格文档

## 1. 业务目标

面向数据管理部门，提供公共数据资源授权运营场景下「再开发数据产品」的统一监管入口。以「产品」为粒度展示再开发数据产品台账，支持按数据产品标识码、产品名称、产品类型、所属地域、领域名称、产品提供方、产品状态组合筛选，并可查看单个产品的详情，用于监控再开发数据产品从审查、登记、上架到下架的全生命周期进度与状态。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 组合筛选 | 数据产品标识码、产品名称、产品类型、所属地域、领域名称、产品提供方、产品状态，共 7 项，两行排布 |
| 查询 / 重置 | 蓝色主按钮【查询】按当前条件过滤并回到第 1 页；白色普通按钮【重置】清空全部条件恢复全量数据 |
| 产品列表 | 展示序号、数据产品标识码、产品名称、产品类型、所属地域、领域名称、产品提供方、产品进度、产品状态、操作 |
| 查看 | 操作列【查看】文字链接（蓝色），打开「产品详情」只读弹窗 |
| 分页 | 共 X 条记录 + 上一页/页码/下一页 + 每页条数（默认 10 条/页）+ 跳页，默认第 1 页 |

## 3. 角色与权限

- 页面归属后台「授权监管」菜单组，为二级子菜单，与「产品交易监管」「订单交付监管」并列。
- 仅向「数据管理部门」角色分配，页面角色切换器固定显示数据管理部门。
- 页面为只读监管视角，仅提供【查看】，不提供新增、编辑、删除等写操作。

## 4. 筛选条件

| 筛选项 | 控件 | 提示文字 | 取值 |
| --- | --- | --- | --- |
| 数据产品标识码 | 输入框 | 请输入 | 模糊匹配（忽略大小写） |
| 产品名称 | 输入框 | 请输入 | 模糊匹配 |
| 产品类型 | 下拉 | 请选择 | API产品、数据集 |
| 所属地域 | 级联下拉（RegionCascader 公共组件） | 请选择 | 两级联动：第一级为省本级 + 14 个市州（省本级为末级，直接选中；市州行悬停展开第二级），第二级为对应区县；点击行首单选钮或末级行完成选择，选中市州或区县均按名称与列表精确匹配；点击组件外部关闭，页面【重置】清空恢复「请选择」 |
| 领域名称 | 下拉 | 请选择 | 科技创新、软件开发、农业农村、医疗健康、交通运输、教育、文化旅游、金融服务、城市治理、应急管理 |
| 产品提供方 | 输入框 | 请输入 | 模糊匹配 |
| 产品状态 | 下拉 | 请选择 | 待审查、登记中、上架中、已上架、已下架 |

## 5. 列表字段

| 字段 | 说明 |
| --- | --- |
| 序号 | 按当前分页连续编号 |
| 数据产品标识码 | 产品唯一标识码，超长截断，悬停显示完整编码 |
| 产品名称 | 超长截断，悬停显示完整名称 |
| 产品类型 | 蓝色标签展示数据集 / API产品 |
| 所属地域 | 产品归属地域（省本级 / 市州 / 区县） |
| 领域名称 | 产品所属领域 |
| 产品提供方 | 产品提供单位名称，超长截断，悬停显示完整名称 |
| 产品进度 | 进度条组件 + 百分比文字：待审查（蓝色 50%）、登记中（蓝色 50%）、上架中（蓝色 80%）、已上架（绿色 100%）、已下架（红色 100%） |
| 产品状态 | 标签组件：待审查（浅蓝）、登记中（浅蓝）、上架中（浅蓝）、已上架（绿色）、已下架（红色） |
| 操作 | 仅【查看】文字链接（蓝色） |

## 6. 产品详情弹窗（查看）

- 标题：「产品详情」，只读展示产品档案，整体为「顶部流程步骤条 + 左侧信息栏 / 右侧交易记录」两栏布局：左侧栏自上而下为「基本信息」「定价信息」，右侧栏为「产品交易记录」。
- 顶部流程步骤条（4 步）：安全审查 → 产品登记 → 产品上架 → 产品交易。
  - 已完成步骤（安全审查、产品登记、产品上架）为绿色实心对勾圆点，并显示完成时间（2026-09-09 17:12:54 / 2026-09-09 17:15:01）。
  - 当前步骤（产品交易）为红色空心圆圈，时间显示「-」。
  - 步骤之间连线：已完成步骤之间为蓝色实线；当前步骤之前为蓝色实线（本页面 4 步均为蓝色实线）。
- 主体上方左右并排两栏：
  - 「基本信息」模块（标题带蓝色竖线，左侧栏）：四列栅格（每行两组字段标签+值），含产品名称、数据产品标识码、产品类型（API 产品）、行业分类、产品进度（绿色进度条 100%）、产品状态（浅绿标签「已上架」）、产品简介（跨三列）。
  - 「定价信息」模块（标题带蓝色竖线，右侧栏）：四列栅格，含计量方式（按次数）、价格（0.01 元 / 次）、产品配图（图片预览框，跨三列）。
- 主体下方通栏：
  - 「产品交易记录」模块（标题带蓝色竖线）：列表式记录，每条含蓝色序号圆点、时间、订单编号、数据需求方、订单状态（浅绿标签「审核通过」）。
- 产品进度在弹窗内以进度条 + 百分比形式展示，产品状态以标签形式展示。
- 底部仅提供【关闭】按钮。

## 7. 布局与视觉

- 复用 `Layout` 统一后台侧栏、顶部导航、面包屑和角色区域，面包屑为 `首页 / 授权监管 / 再开发数据产品监管`。
- 复用 `src/common/backend-list.css` 列表契约（筛选区、表格、分页、操作按钮、状态标签），页面样式仅补充列宽、进度条与弹窗样式。
- 延续蓝色主按钮、浅蓝表头、细边框、紧凑型 ToB 表格密度。
- 页面标题为「再开发数据产品监管」。

## 8. 交互状态

- 页面初始化不带筛选条件，自动加载全部再开发数据产品数据。
- 查询、重置、切换分页后数据排列顺序保持稳定。
- 重置后列表刷新回全量数据并回到第 1 页。
- 无数据场景：表格展示空白提示「暂无数据」。
- 弹窗支持点击遮罩关闭。
- 长文本单元格截断，悬停显示完整内容。
- 表格列宽固定不换行；操作列不裁剪按钮，容器宽度不足时表格区域出现横向滚动条。

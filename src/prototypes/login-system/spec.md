# 登录系统

## 📋 业务与功能

### 1.1 核心目标

页面用于用户身份验证，提供安全、简洁的登录入口，支持账号密码登录、记住我、忘记密码等功能。

### 1.2 功能清单

- **账号输入框**：支持输入用户名/邮箱
- **密码输入框**：支持密码输入与显示/隐藏切换
- **记住我复选框**：记住登录状态
- **登录按钮**：提交登录表单
- **忘记密码链接**：跳转到密码找回页面
- **注册链接**：跳转到注册页面
- **表单验证**：实时验证输入格式
- **加载状态**：登录请求中的加载反馈

### 1.3 交互要点

- 输入框聚焦：显示边框高亮与浮动标签
- 密码显示/隐藏：点击眼睛图标切换
- 表单验证：输入时实时反馈，提交前校验
- 登录按钮：点击后显示加载状态，禁止重复提交
- 链接点击：跳转到对应页面（当前为占位）

## 📊 内容规划

### 2.1 信息架构

```
登录系统
├── Logo 区域
├── 登录表单
│   ├── 账号输入框
│   ├── 密码输入框（含显示/隐藏切换）
```

### 2.2 数据来源

- **数据类型**：用户登录信息
- **数据源**：用户输入
- **关键字段**：
  - `username`: 用户名/邮箱
  - `password`: 密码
  - `rememberMe`: 是否记住登录状态

### 2.3 内容示例

- 账号示例：admin@example.com 或 admin
- 密码示例：******（6-20位字符）

## 🎨 布局与结构

### 3.1 整体布局

- **布局模式**：居中卡片式布局
- **容器宽度**：固定宽度 400px
- **关键尺寸**：
  - 卡片宽度：400px
  - 输入框高度：40px
  - 按钮高度：44px
  - 间距：16px

### 3.2 响应式适配

- **桌面端（≥768px）**：居中卡片布局，宽度 400px
- **平板端（480-767px）**：卡片宽度 90%
- **移动端（<480px）**：卡片宽度 95%，表单元素自适应

## 🎨 视觉规范

### 4.1 设计规范来源

**设计依据**：Element UI 风格（参考）

### 4.2 自定义设计要点

**自定义色彩**（Element UI 风格）：
- 主色调：#409EFF - 用于按钮、输入框边框高亮
- 成功色：#67C23A - 用于成功状态
- 警告色：#E6A23C - 用于警告提示
- 危险色：#F56C6C - 用于错误提示
- 信息色：#909399 - 用于辅助文字

**自定义尺寸**：
- 圆角：8px - 用于卡片与输入框
- 阴影：轻微阴影效果

### 4.3 组件状态

- **默认态（default）**：输入框灰色边框，按钮主色调
- **悬停态（hover）**：输入框边框变亮，按钮颜色加深
- **聚焦态（focus）**：输入框边框变为主题色，显示聚焦效果
- **禁用态（disabled）**：按钮灰显，不可点击
- **加载态（loading）**：按钮显示加载动画
- **错误态（error）**：输入框边框红色，显示错误提示

## ⚙️ Axure API 说明

### 5.1 事件列表（eventList）

| 事件名称 | Payload 类型 | 触发时机 | 说明 |
|---------|-------------|---------|------|
| `onLogin` | `{ username: string; password: string; rememberMe: boolean }` | 点击登录按钮且验证通过 | 提交登录信息 |

### 5.2 动作列表（actionList）

| 动作名称 | Params 类型 | 参数说明 | 功能描述 |
|---------|------------|---------|---------|
| `resetForm` | 无 | 无 | 重置表单到初始状态 |

### 5.3 变量列表（varList）

| 变量名称 | 类型 | 默认值 | 说明 |
|---------|-----|-------|------|
| `username` | `string` | `''` | 用户输入的账号 |
| `password` | `string` | `''` | 用户输入的密码 |
| `remember_me` | `boolean` | `false` | 是否记住登录状态 |
| `is_loading` | `boolean` | `false` | 是否正在登录 |

### 5.4 配置项列表（configList）

| 配置项名称 | 类型 | 默认值 | 说明 |
|----------|-----|-------|------|
| `title` | `string` | `'系统登录'` | 页面标题 |
| `logo` | `string` | `''` | Logo 图片路径（可选） |

### 5.5 数据项列表（dataList）

**数据结构**：
```typescript
{
  username: string;      // 用户账号（邮箱或用户名）
  password: string;      // 用户密码
  rememberMe: boolean;   // 是否记住我
}
```

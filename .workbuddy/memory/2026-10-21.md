## SPA 切换的全局样式污染问题（重要，2026-10-21）
- 现象：从其他备案页（实施方案/实施机构/运营机构备案）切到运营协议备案后，弹窗变成双列、出现横向滚动——因为这些页的 `.form-grid` 是 `repeat(2, minmax(0,1fr))`，SPA 切换后其 `<style>` 残留在 head 覆盖本页单列 `.form-grid`。
- 根治（src/common/Layout.tsx）：`loadSpaModuleComponent` 加载前 `dropSpaInjectedStyles()` 移除上一次 SPA 加载注入的样式节点，加载后用 `trackSpaInjectedStyles(before)` 记录本次新增节点（快照 diff，宿主页原有样式不受影响）。dev 与构建产物两条路径均生效。
- 局部防护：pending-operation-agreement-filing/style.css 增加 `.form-modal .form-grid { grid-template-columns: 1fr; gap: 16px 0 }` 与 `.form-modal .form-item { min-height: 35px }`（两级选择器提高优先级）。
- 注意：Layout.tsx 为公共文件，改动后需重建全部 dist 入口（42 个）保持一致。

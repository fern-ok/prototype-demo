# 机构监管 原型修改记录

## 2026-10-16
- 新增「其他」一级菜单，并在其下新增二级菜单「机构监管」（页面 key：`institution-supervision`）。
- 新建机构监管原型页面（数据管理部门视角，单页面 + 角色 Tab 筛选方案）：
  - 顶部全局统计卡片区：机构总数（注册/备案）、实施机构/运营机构/行业主管部门/其他经营主体备案数量，支持实时刷新。
  - 角色快捷 Tab（全部 / 实施机构 / 运营机构 / 行业主管部门 / 其他经营主体），点击 Tab 自动联动「机构角色」筛选；各角色 Tab 下筛选区与列表隐藏「机构角色」维度。
  - 筛选区：所属地域三级联动、授权运营类型、领域名称、单位/企业名称模糊检索、统一社会信用代码、备案时间起止范围，含【查询】【重置】。
  - 机构列表：所属地域、授权运营类型、领域名称、机构角色（仅全部 Tab）、单位/企业名称、统一社会信用代码、备案时间、查看操作，默认每页 10 条分页。
  - 查看弹窗：基本信息 + 按机构角色动态渲染的角色专属备案信息（实施机构 / 运营机构 / 其他经营主体 / 行业主管部门）。
- 新增配套文件：`index.tsx`、`style.css`、`spec.md`。

# 数据管理部门工作台

## 业务与功能

### 页面定位与核心目标

公共数据资源授权运营管理平台后台的一级菜单页面，面向「数据管理部门」角色。数据管理部门登录后台后，通过本页一站式掌握全省/指定地域与领域下的平台运行态势：数据范围、关键统计、授权业务漏斗、备案待办、快捷入口与机构角色分布。

页面复用后台公共 `Layout`（侧边栏、顶部栏、面包屑、角色区域），不引入独立导航，避免后台出现双层导航。

### 功能清单

| 模块 | 说明 |
| --- | --- |
| 数据范围 | 顶部数据范围条，可切换「地域」（全省/省本级/地市/长沙市/株洲市）与「领域」（全部/整体/医疗健康），切换后提示文案实时联动：「您正在查看【地域】【领域】领域的数据」 |
| 统计项 | 七张指标卡，单行七列：入驻机构、数据资源、基础产品、再开发产品、业务场景、有效交易订单、产品订单总额，每张含图标、名称、数值与单位 |
| 授权业务漏斗 | 双漏斗：数据资源（资源编目→资源登记→资源挂载→资源授权）、数据产品（产品编目→安全审查→产品登记→产品上架→产品授权/交易），每个阶段展示数量、单位与占首阶段比例，自上而下收窄呈漏斗形态 |
| 待办 | 备案待处理表格，列：所属地域、授权运营类型、领域名称、备案类型、创建时间、操作（处理）；「处理」为蓝色文字链接，跳转至对应备案页面；表格下方提供分页组件（共 N 条记录、首页/上一页/页码/下一页/末页、每页条数切换、跳至指定页） |
| 快捷入口 | 蓝渐变标题卡片，3×2 网格六个入口：数据资源、数据资源授权、基础数据产品、基础数据产品授权、再开发数据产品、数据产品交易，点击跳转对应后台页面 |
| 机构角色数量占比 | 环状图展示平台各机构角色数量占比：数据管理部门、行业主管部门、实施机构、运营机构、其他经营主体，含中心总数与图例（数量/百分比） |

### 交互要点

- 页面为只读工作台，不提供新增、编辑、删除等数据写入入口；数据范围切换与待办「处理」仅影响当前页面演示数据或跳转对应页面。
- 顶部角色区域固定展示「数据管理部门」，不提供其他角色选项，保证页面语义单一。
- 数据范围下拉为自定义控件，点击展开、点击外部自动收起，选中即更新提示文案。
- 顶部栏保留后台统一的「版本管理」「页面说明」「原型修改记录」「消息通知」入口，交互与其他后台页面一致。
- 侧边栏当前项高亮显示，点击其他菜单可正常跳转至对应后台页面，不影响后台整体导航。

## 内容规划

### 信息架构

```text
数据管理部门工作台
├── 数据范围（地域下拉 / 领域下拉）
├── 统计项（7 卡：入驻机构/数据资源/基础产品/再开发产品/业务场景/有效交易订单/产品订单总额）
├── 授权业务漏斗
│   ├── 数据资源：资源编目→资源登记→资源挂载→资源授权
│   └── 数据产品：产品编目→安全审查→产品登记→产品上架→产品授权/交易
├── 待办（备案待处理表格 + 分页）
│   ├── 所属地域/授权运营类型/领域名称/备案类型/创建时间/操作（处理·蓝色文字链接）
│   └── 分页条（共 N 条记录 / 首页·上一页·页码·下一页·末页 / 每页条数 / 跳至指定页）
└── 两栏右区
    ├── 快捷入口（6 入口）
    └── 机构角色数量占比（环状图）
```

### 数据来源

- 页面内容与样式参考用户提供的设计参考图（工作台样式：白底卡片、蓝渐变快捷入口、环状图）。
- 统计数值、漏斗数量、待办与机构角色占比均为内置演示数据，仅保存在组件状态中，刷新后重置。
- 机构角色占比数据沿用机构监管模块的演示口径（数据管理部门 5、行业主管部门 5、实施机构 8、运营机构 7、其他经营主体 6，合计 31）。

### 关键字段

- `REGION_OPTIONS` / `DOMAIN_OPTIONS`：数据范围可选项。
- `stats[]`：统计项配置，含 `icon`、`label`、`value`、`unit`、`tone`（配色）。
- `resourceFunnel` / `productFunnel`：漏斗阶段配置，含 `label`、`value`、`unit`。
- `todoSeed[]`：待办备案数据，含 `region`、`authType`、`domain`、`filingType`、`createdAt`、`href`。
- `quickEntries[]`：快捷入口配置，含 `icon`、`label`、`tone`、`href`。
- `roleSlices[]`：机构角色占比配置，含 `label`、`value`、`color`。

## 布局与结构

### 整体布局

- 页面框架复用后台公共 `Layout`，主体区保留统一留白：上方 18px、左右 20px、下方 28px。
- 主体自上而下：数据范围条（整行）→ 两栏网格。
- 两栏网格：左栏（宽，约占 3/4）含统计项面板与待办面板（上下堆叠）；右栏（窄，约 1/4、最小 300px）含快捷入口面板与授权业务漏斗面板（上下堆叠）。
- 页面最小宽度 1180px，窄屏下两栏转单列。

### 响应式适配

- 默认（≥1280px）：两栏 3fr / 1fr（右栏最小 300px）；统计项每个分组 6 张卡片单行排列。
- <1280px：两栏转单列，环状图居中。

## 视觉规范

### 设计规范来源

用户提供设计参考图（工作台截图），并复用后台既有主题与公共布局样式。

### 自定义设计要点

- 面板：白色背景、8px 圆角、`0 2px 8px rgba(24, 62, 119, .06)` 轻投影；面板标题 16px / 700 / `#1a2943`。
- 数据范围条：白底卡片，下拉触发器 30px 高、`#1677ff` 蓝字、`#f3f8ff` 浅蓝底，提示文案灰阶 `#7b8798`。
- 统计卡：白底卡片、`#fbfdff` 底，卡片内边距 9px、左侧 30px 圆角图标（按配色分组），标签 11px 灰（单行不换行），数值 22px / 700，单位 11px 灰；每个分组固定 6 列，卡片间距 10px。
- 漏斗：阶段条居中自上而下收窄，蓝紫渐变（`#5b8def`→`#7b61ff`），内含阶段名称与数量/百分比，阶段间以灰色下箭头连接。
- 待办表格：表头浅蓝底 `#f6f9fd`，备案类型标签浅蓝底，操作「处理」为蓝色文字链接（无边框、无背景）；表格下方分页条与表格同宽，左「共 N 条记录」右分页控件。
- 快捷入口：与统计项一致的白底卡片风格，面板标题同其他面板（16px / 700 / `#1a2943`），3×2 网格卡片白底细边框、图标 32px 圆角方块（按配色分组），标签 11px、深色 `#17233d`。
- 机构角色占比：150px 环状 `conic-gradient`，中心白孔展示总数，图例含色块、名称、数量与百分比。

### 组件状态

- 侧边栏菜单项、顶部栏交互沿用 `Layout` 既有实现。
- 数据范围下拉：默认 / 展开（蓝边 + 浅蓝光晕）/ 选中态浅蓝底。
- 其余面板为静态展示，无悬停态变化（快捷入口卡片与待办行有轻微悬停反馈）。

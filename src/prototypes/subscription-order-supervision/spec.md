# 订阅订单监管 - 规格文档

## 1. 业务目标

面向数据管理部门，提供全部产品订阅订单的统一查询与监管入口。以「订单」为粒度展示订阅流水，支持按订单编号、地域、授权运营类型、领域、产品、需求方、订单状态、更新时间组合筛选，并可查看订单所属产品的详情；API 产品订单可进一步下钻查看调用明细（调用汇总指标与原始调用日志），用于监控数据产品订阅执行、订单状态与 API 调用合规情况。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 组合筛选 | 订单编号、所属地域、授权运营类型、领域名称、产品名称、产品类型、数据需求方、订单状态、更新时间，共 9 项，三行排布 |
| 查询 / 重置 | 蓝色主按钮【查询】按当前条件过滤并回到第 1 页；白色次要按钮【重置】清空全部条件恢复全量数据 |
| 订单列表 | 展示序号、订单编号、所属地域、授权运营类型、领域名称、产品名称、产品类型、数据需求方、订单状态、更新时间、操作 |
| 查看 | 操作列【查看】打开「产品详情」只读弹窗，展示订单所属产品的完整档案 |
| 调用明细 | 仅产品类型为 API产品 的订单展示【调用明细】按钮，打开「调用明细」弹窗查看调用汇总与调用日志；数据集订单不展示该按钮 |
| 下载明细 | 仅产品类型为 数据集 的订单展示【下载明细】按钮，打开「下载明细」弹窗查看下载汇总与下载日志；API产品订单不展示该按钮 |
| 默认排序 | 列表按「更新时间」倒序排列，最新在前；查询/重置/翻页后排序不变 |
| 分页 | 页码、上一页/下一页、每页条数、跳页；默认每页 10 条，默认第 1 页 |

## 3. 角色与权限

- 页面归属后台「授权监管」菜单组，为二级子菜单，与「产品订阅监管」并列。
- 仅向「数据管理部门」角色分配，页面角色切换器固定显示数据管理部门。
- 页面为只读监管视角，不提供新增、编辑、删除等写操作。

## 4. 筛选条件

| 筛选项 | 控件 | 提示文字 | 取值 |
| --- | --- | --- | --- |
| 订单编号 | 输入框 | 请输入 | 模糊匹配 |
| 所属地域 | 级联下拉（RegionCascader 公共组件） | 请选择 | 两级联动：第一级为省本级 + 14 个市州（省本级为末级，直接选中；市州行悬停展开第二级），第二级为对应区县（如长沙市 → 芙蓉区、天心区、岳麓区、开福区、雨花区、望城区等）；点击行首单选钮或末级行完成选择，选中市州或区县均按名称与列表精确匹配；点击组件外部关闭，页面【重置】清空恢复「请选择」 |
| 授权运营类型 | 下拉 | 请选择 | 整体授权运营、分领域授权运营 |
| 领域名称 | 下拉 | 请选择 | 医疗健康、交通运输、教育、文化旅游、自然资源、城市治理、金融服务、工业制造、智慧农业、应急管理 |
| 产品名称 | 输入框 | 请输入 | 模糊匹配 |
| 产品类型 | 下拉 | 请选择 | 数据集、API产品 |
| 数据需求方 | 输入框 | 请输入 | 模糊匹配 |
| 订单状态 | 下拉 | 请选择 | 已下单、交付中、已完成、已终止、已冻结 |
| 更新时间 | 输入框 | 请输入 | 模糊匹配（如输入 `2026-08-12` 或 `2026-08`） |

## 5. 列表字段

| 字段 | 说明 |
| --- | --- |
| 序号 | 按当前分页连续编号 |
| 订单编号 | 订阅订单号，超长截断，悬停显示完整编号 |
| 所属地域 | 订单所属产品归属地域 |
| 授权运营类型 | 整体授权运营 / 分领域授权运营 |
| 领域名称 | 订单所属产品领域 |
| 产品名称 | 超长截断，悬停显示完整名称 |
| 产品类型 | 蓝色标签展示数据集 / API产品 |
| 数据需求方 | 发起订阅的单位名称，超长截断 |
| 订单状态 | 已下单（蓝色）、交付中（橙色）、已完成（绿色）、已终止（红色）、已冻结（灰色） |
| 订单总额（元） | 订单交易总金额，存储单位：分（整数），展示不做单位换算；千分位分隔并固定保留两位小数（如 `594,500.00`）；位于订单状态之后、更新时间之前 |
| 更新时间 | 订单最近一次状态变更时间，列表默认按此字段倒序排列，最新在前 |
| 操作 | 【查看】；产品类型为 API产品 时追加【调用明细】，产品类型为 数据集 时追加【下载明细】，从左到右固定顺序 |

## 6. 产品详情弹窗（查看）

- 标题：「产品详情」，只读展示订单所属产品的档案。
- 字段：产品名称、产品类型、所属地域、授权运营类型、领域名称、产品提供方、订阅次数、产品简介。
- 底部仅提供【关闭】按钮。

## 7. 调用明细弹窗（API产品专用）

由操作列【调用明细】打开，整体从上至下分为：提示与统计汇总区 → 筛选查询区 → 调用日志表格区 → 分页区。

### 7.1 提示与统计汇总

- 提示文案：「由于数据量较大导致调用次数统计存在延时，您可手动刷新获取最新的调用次数」，其中「手动刷新」为蓝色可点击文字按钮。
- 点击「手动刷新」仅重新加载顶部汇总统计（独立于表格分页），刷新期间展示「统计中…」。
- 统计指标（两行四列，标签灰底）：API接口名称、调用总次数、调用成功次数、调用失败次数。

### 7.2 筛选查询

| 筛选项 | 控件 | 取值 | 默认 |
| --- | --- | --- | --- |
| 调用状态 | 下拉 | 请选择（空）、成功、失败 | 空 |
| 调用时间 | 下拉 | 近三个月、近半年、近一年 | 近三个月 |

- 【查询】按当前条件刷新表格并回到第 1 页；【重置】清空调用状态、调用时间恢复默认近三个月。

### 7.3 调用日志表格

| 字段 | 说明 |
| --- | --- |
| 序号 | 按明细分页连续编号 |
| 调用状态 | 成功为普通黑色文字；失败为红色字体高亮 |
| 响应时长(ms) | 接口返回耗时，单位毫秒 |
| 调用时间 | 精确到分钟，格式 `yyyy-MM-dd HH:mm` |
| 操作 | 调用状态为失败时显示蓝色文字链接【查看失败原因】；成功时操作列为空 |

- 加载中：表格区域展示「加载中…」。
- 错误：展示错误提示文案（如「未获取到调用明细数据，请点击查询重试」）。
- 空数据：筛选后无日志时展示「暂无调用记录」。
- 分页与主列表一致：共 X 条记录 + 上一页/页码/下一页 + 每页条数（默认 10 条/页）+ 跳页。

### 7.4 失败原因弹窗

- 由【查看失败原因】打开，展示：订单编号、API接口名称、调用时间、响应时长(ms)、调用状态、错误码、错误信息。
- 全部只读，底部仅提供【关闭】按钮。

## 8. 下载明细弹窗（数据集专用）

由操作列【下载明细】打开，整体从上至下分为：统计汇总区 → 筛选查询区 → 下载日志表格区 → 分页区。与调用明细弹窗同一套视觉与交互契约，仅业务语义不同。

### 8.1 统计汇总

- 统计指标（两行四列、标签灰底，无手动刷新控件）：表名、下载总次数、下载成功次数、下载失败次数。
- 统计卡片独立展示，不受表格分页与筛选控制。

### 8.2 筛选查询

| 筛选项 | 控件 | 取值 | 默认 |
| --- | --- | --- | --- |
| 下载状态 | 下拉 | 请选择（空）、成功、失败 | 空 |
| 下载时间 | 下拉 | 近三个月、近半年、近一年 | 近三个月 |

- 【查询】按当前条件刷新表格并回到第 1 页；【重置】清空下载状态、下载时间恢复默认近三个月。

### 8.3 下载日志表格

| 字段 | 说明 |
| --- | --- |
| 序号 | 按明细分页连续编号 |
| 下载状态 | 成功为普通黑色文字；失败为红色字体高亮 |
| 下载耗时(ms) | 下载返回耗时，单位毫秒 |
| 下载时间 | 精确到分钟，格式 `yyyy-MM-dd HH:mm` |
| 操作 | 下载状态为失败时显示蓝色文字链接【查看失败原因】；成功时操作列为空 |

- 加载中：表格区域展示「加载中…」。
- 错误：展示错误提示文案（如「未获取到下载明细数据，请点击查询重试」）。
- 空数据：筛选后无日志时展示「暂无下载记录」。
- 分页与主列表一致：共 X 条记录 + 上一页/页码/下一页 + 每页条数（默认 10 条/页）+ 跳页。

### 8.4 失败原因弹窗

- 由【查看失败原因】打开，展示：订单编号、表名、下载时间、下载耗时(ms)、下载状态、错误码、错误信息。
- 全部只读，底部仅提供【关闭】按钮。

## 9. 布局与视觉

- 复用 `Layout` 统一后台侧栏、顶部导航、面包屑和角色区域，面包屑为 `首页 / 授权监管 / 订阅订单监管`。
- 复用 `src/common/backend-list.css` 列表契约（筛选区、表格、分页、操作按钮、状态标签），页面样式仅补充列宽与弹窗样式。
- 延续蓝色主按钮、浅蓝表头、细边框、紧凑型 ToB 表格密度。
- 页面标题为「订阅订单监管」。

## 10. 交互状态

- 页面初始化不带筛选条件，自动加载全部订阅订单数据，并默认按「更新时间」倒序排列（最新在前）。
- 查询、重置、切换分页后排序保持不变；第一页始终展示更新时间最新的记录。
- 重置后列表刷新回全量数据并回到第 1 页。
- 无数据场景：表格展示空白提示「暂无数据」。
- 弹窗支持点击遮罩关闭。
- 长文本单元格截断，悬停显示完整内容。
- 表格列宽固定不换行；操作列不裁剪按钮，容器宽度不足时表格区域出现横向滚动条。

## 11. 数据说明

- 演示数据由产品订阅情况展开生成，覆盖不同地域、授权运营类型、领域与产品类型，共 76 条订阅订单。
- 订单编号、需求方与状态按产品维度稳定生成，与「产品订阅监管」页的订阅订单明细数据保持一致。
- 订单状态覆盖已下单、交付中、已完成、已终止、已冻结五种，标签配色依次为蓝、橙、绿、红、灰。
- 调用明细数据仅针对产品类型为 API产品 的订单生成：每条订单 26~55 条调用日志（含少量失败记录，失败记录带错误码与错误信息），调用时间分布在近一年内，供调用时间范围筛选演示；汇总统计基准值按订单稳定生成，「手动刷新」会在基准值上小幅递增以模拟统计延时。
- 下载明细数据仅针对产品类型为 数据集 的订单生成：每条订单 12~27 条下载日志（失败率高于调用，失败记录带错误码与错误信息），下载时间分布在近一年内；汇总统计（表名、下载总次数、成功/失败次数）按订单稳定生成，不提供手动刷新。

# 实施方案联审

## 业务与功能

### 核心目标
为公共数据资源授权运营管理平台「备案管理」提供实施方案联审列表页，供实施机构提交本机构实施方案并联审，跟踪省级审核状态与区块链存证。

### 功能清单
- 列表展示：展示本机构全部实施方案联审单据，字段包含授权运营类型、领域名称、实施方案、创建时间、审核状态、审核时间。
- 新增联审：点击标题下方操作区的【+ 实施方案联审】打开新增弹窗，选择授权运营类型、领域名称并上传实施方案文件。
- 查看详情：【查看】打开详情弹窗，展示单据基本信息和实施方案附件。
- 查看存证：【查看存证】打开区块链存证凭证弹窗，并提供凭证下载入口。

### 角色与权限
- 本页分配给「实施机构」角色，角色切换器仅提供「实施机构」。
- 操作栏按钮规则：所有状态均展示【查看】；审核完成（省级审核通过）额外展示【查看存证】，其余状态「查看存证」置灰不可点击。

### 交互要点
- 点击标题下方操作区的【+ 实施方案联审】打开新增弹窗，三项均为必填校验。
- 实施方案文件在列表与详情中均以蓝色附件链接（回形针图标 + 文件名）呈现，点击触发文件预览。
- 操作栏【查看】【查看存证】以蓝色文字链接展示，中间以竖线分隔。
- 详情弹窗右上角提供【查看存证】主按钮，可直接跳转存证弹窗。
- 侧边栏支持收缩展开和一级菜单折叠。

## 内容规划

### 信息架构
```text
实施方案联审
├── 顶部栏
│   ├── 角色切换（实施机构）
│   └── 用户信息
├── 左侧导航
│   └── 备案管理
│       ├── 产品和服务清单备案
│       ├── 运营协议备案
│       ├── 实施方案联审（当前页）
│       └── 授权记录
├── 页面标题行（仅页面标题）
├── 操作区（页面标题下方独立一行，主按钮居右）
├── 列表上方提示说明
├── 列表表格区
├── 新增弹窗
├── 查看弹窗
└── 存证弹窗
```

### 页面布局层级
- 自上而下依次为：页面标题行 → 操作区（按钮居右）→ 列表上方提示说明 → 列表表格区。
- 操作区为独立区块，与页面标题上下分列，左右边距与列表卡片一致（18px），不与其他区块重叠。

### 列表上方提示说明
- 在操作区与列表卡片之间展示一条静态文案（左对齐，与列表左边缘一致）：
  「已在湘办通平台完成实施方案联审的，无需再次联审，请直接发起“实施方案备案”。」
- 样式仅作用于本页 `.plan-review-notice`：红色字体（#d54941）、13px、无图标、不可关闭，不遮挡操作列与分页组件。

### 列表字段
- 序号：自增数字，按当前页起算。
- 授权运营类型：整体授权运营 / 分领域授权运营。
- 领域名称：数据所属业务领域，示例为卫生健康。
- 实施方案：PDF 文件名，蓝色附件链接。
- 创建时间：单据首次提交时间，格式 `YYYY-MM-DD HH:mm:ss`。
- 审核状态：省级联审结果标签，通过为浅绿底绿字。
- 审核时间：省级审核完成时间。
- 操作：查看、查看存证（竖线分隔）。

### 新增弹窗字段
- *授权运营类型：下拉必填（整体授权运营 / 分领域授权运营）
- *领域名称：下拉必填（卫生健康 / 交通运输 / 教育 / 文化旅游 / 自然资源）
- *实施方案：文件上传必填，支持 PDF、DOC、DOCX

### 详情弹窗字段
- 授权运营类型、领域名称、实施方案（附件链接）
- 创建时间、审核状态（标签）、审核时间

### 存证弹窗字段
- 凭证编号、授权运营类型、领域名称、实施方案、审核状态、审核时间、存证状态

### 数据来源
- 数据类型：实施方案联审单据（页面内示例数据）。
- 关键字段：
  - `auditStatus`：审核状态，用于列表标签与操作按钮显隐。
  - `planFile`：实施方案文件名。

## 公共样式

列表页基础样式统一复用 `src/common/backend-list.css`，与备案管理下其他列表页保持一致；本页仅维护标题行、操作区、提示说明、附件链接、操作分隔线及弹窗的专属样式（`style.css`）。

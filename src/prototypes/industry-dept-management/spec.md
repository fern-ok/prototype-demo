# 行业主管部门管理

## 业务与功能

### 核心目标
为运营管理平台提供行业主管部门管理原型，供数据基础设施运营方维护行业主管部门主体信息，支持查询、新增、删除行业主管部门。

### 功能清单
- 列表查询：按所属地域、单位 / 企业名称、统一社会信用代码、批次、创建时间多条件组合筛选。
- 备案操作：支持新增行业主管部门、删除行业主管部门记录。
- 角色范围：仅向数据基础设施运营方开放。

### 交互要点
- 点击右上角【+ 新增】按钮打开新增弹窗。
- 列表【删除】按钮打开删除确认弹窗，确认后移除该条记录并刷新列表。
- 筛选区【查询】按多条件“且”组合筛选；【重置】清空所有条件并加载全部数据。

## 内容规划

### 信息架构
```text
行业主管部门管理
├── 顶部栏
│   ├── 角色切换
│   └── 用户信息
├── 左侧导航
│   └── 系统管理
│       ├── 领域管理
│       └── 行业主管部门管理（当前页）
├── 筛选条件区
├── 行业主管部门列表区
├── 新增弹窗
└── 删除确认弹窗
```

### 筛选条件
- 所属地域：下拉选择（省本级 / 市 / 区县）
- 单位 / 企业名称：文本输入，支持模糊检索
- 统一社会信用代码：文本输入，支持模糊检索
- 批次：文本输入，支持模糊检索
- 创建时间：日期范围选择器
- 操作按钮：【查询】【重置】

### 列表字段
1. 序号：自增数字
2. 批次：标识当前记录为第几批行业主管部门
3. 所属地域：省本级 / 市 / 区县
4. 单位 / 企业名称：行业主管部门机构名称
5. 统一社会信用代码：机构信用代码
6. 创建时间：本条记录新增保存的时间
7. 操作：删除

### 新增弹窗字段
弹窗标题：新增
表单布局：标签与输入框水平排列（label 在左、输入控件在右），各表单项保持统一对齐与间距。
必填项（带 *）：
1. *批次：下拉选择，填写该行业主管部门归属接入批次（第1批 ~ 第5批）
2. *行业主管部门：文本输入，必填
3. *所属地域：下拉选择，必选
4. *单位 / 企业名称：文本输入，必填
5. *统一社会信用代码：文本输入，必填
底部按钮：
- 取消：关闭弹窗，不保存数据，返回列表页
- 确定：校验表单，校验通过后保存行业主管部门信息，刷新主列表

### 删除确认弹窗
- 提示“确定要删除‘<单位名称>’这条行业主管部门记录吗？”
- 取消 / 确定按钮，确定后删除并刷新列表。

### 分页控件
底部展示总记录条数；支持上一页、下一页、页码跳转、每页条数切换（10 / 20 / 50 条）、跳转到指定页码。

## 公共样式
列表页基础样式统一复用 `src/common/backend-list.css`，与系统管理下其他页面保持一致；本页仅维护行业主管部门专属字段与弹窗样式。

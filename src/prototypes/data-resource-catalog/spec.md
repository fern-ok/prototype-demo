# 数据资源目录 - 规格文档

## 1. 业务目标

为实施机构提供数据资源目录的查询、筛选、查看和新增入口，帮助实施机构维护不同审核阶段的数据资源，并跟踪数据源挂载状态。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 行业分类树 | 展示全部及国民经济行业分类，支持展开、收起和按行业过滤 |
| 组合筛选 | 支持资源名称、审核状态、数据源挂载状态、创建时间范围，并与行业筛选叠加 |
| 审核状态枚举 | 待提交、提交待审核、变更待审核、撤销待审核、提交未通过、变更未通过、撤销未通过、已通过、已撤销；目录样例每种状态至少一条 |
| 目录表格 | 展示序号、资源名称、行业分类、审核状态、挂载状态、创建时间、更新时间和操作 |
| 新增资源 | 打开新增数据资源表单，填写资源名称、行业分类和描述 |
| 关联政务信息资源目录 | 新增弹窗顶部提供入口，点击打开子弹窗「资源目录关联」；弹窗头部仅保留标题「资源目录关联」与关闭 × 按钮。弹窗**正文区顶部**设置「已关联政务信息资源目录」**芯片列表区**（置于「资源名称」查询条件之上，仅在存在初始关联项或当前选中行时显示），列出当前已关联的全部目录项（蓝色芯片样式，每项可点击唤起详情弹窗）；当用户在表格中勾选某行时，对应芯片在正文区同步高亮（白字蓝色填充 + ✓ 前缀），保证选中状态在芯片区与表格行底色两处一致可见；若勾选项不在初始关联列表内，会额外追加一颗带「当前选中」标签的虚线描边芯片。筛选区含资源名称输入框与【重置】【查询】按钮（顺序：重置、查询）。表格字段：复选框（**单选**）、序号、资源名称、数据所属领域、资源摘要、操作（含【查看】唤起只读详情弹窗）；表格为单选模式，已勾选行高亮蓝色底色；分页保留勾选状态，不丢失。底部按钮【取消】直接关闭并丢弃本次勾选；【确定】若未勾选则给出红色提示「请选择需要关联的资源目录」，否则保存勾选并关闭弹窗，上级表单刷新关联结果。每个回显的目录标签尾部附带红色圆形 × 按钮，点击即可移除该条已选目录 |
| 编辑资源 | 操作列「编辑」（仅待提交、提交未通过状态可见）打开编辑弹窗。弹窗字段与新增弹窗完全一致：第一步「基本信息」（资源名称、行业分类、是否涉及个人信息、资源格式、数据来源、更新频率、覆盖时间范围、地域分类、扩展码、资源摘要）+ 资源持有方信息（资源持有方、统一社会信用代码、联系人、联系方式），第二步「信息项」（信息项数据类型与信息项表格）。编辑弹窗会回显该行的已填写数据：资源名称、行业分类（取首个细分项，若不在下拉粗分类中则自动补为可选项）、资源持有方（即提供机构）等 |
| 变更资源 | 操作列「变更」（仅变更未通过、撤销未通过、已通过状态可见）打开变更弹窗。字段结构与新增弹窗一致，并回显该行的已填写数据。新增、编辑、变更三处弹窗共用同一套表单字段（ResourceForm），通过 `mode`（add／edit／change）区分行为，仅标题与初始回显数据不同。**变更弹窗专属差异**：①第二步「信息项」表格下方增加「变更说明」必填输入框（整行 textarea，3 行高度，标签与输入框左右布局、标签右对齐）；②底部按钮仅保留【取消】【上一步】【提交】，**不显示「存为草稿」**（新增与编辑弹窗仍保留该按钮） |
| 信息项工具栏 | 新增／编辑／变更弹窗第二步「信息项」顶部工具栏，从左到右依次为：「信息项」标题 →【下载模板】（绿色）→【导入文件】→【新增】（后两者蓝色），三个按钮整体靠左排列（不右对齐）；【新增】按钮右侧紧跟一行红色提示文字「信息项英文名须与挂载的数据源字段名完全一致（区分大小写）」，12px 字号 |
| 操作按钮 | 统一显示顺序（从左到右）：关联 → 查看 → 编辑 → 删除 → 变更 → 撤销 → 变更记录 → 查看存证。各按钮按审核状态控制可见性：关联（除已撤销外全部）；查看（全部状态）；编辑（待提交、提交未通过）；删除（待提交、提交未通过）；变更（变更未通过、撤销未通过、已通过）；撤销（变更未通过、撤销未通过、已通过）；变更记录（已通过 且 已发生过变更，即「变更已通过」状态，如第 10 条数据）；查看存证（变更未通过、撤销未通过、已通过） |
| 查看详情 | 打开只读详情弹窗，提供“基本信息”、“信息项”和“审核信息”三个页签，页签栏右上角提供【查看存证】蓝色主按钮（各页签下均可见）；不提供编辑、新增、删除等操作入口 |
| 审核信息页签 | 详情弹窗第三个页签，默认激活「基本信息」，可切换至本页签查看。内容区为审核流程表格（纯展示，无行内操作按钮），列为：序号、流程节点、节点状态、单位名称、法人经办人姓名、操作时间、审核结果、审核意见；演示数据覆盖 首次登记 → 审核 → 变更登记 → 审核 → 撤销登记 → 审核 共 6 个节点，节点状态「已完成」为蓝色标签，审核结果「审核通过」为绿色标签，空审核结果/意见统一展示「—」 |
| 查看存证 | 弹窗展示存证编号、上链时间、区块高度和交易哈希；入口有两处：列表操作列「查看存证」、详情弹窗页签栏右上角【查看存证】按钮（子弹窗 z-index 1100，不随详情关闭） |
| 变更记录 | 仅「已通过 且 已发生过变更」的资源显示。点击弹出变更记录弹窗，支持变更状态与变更时间筛选，表格展示序号、变更状态、更新时间、变更审核意见和操作；变更中、变更通过、变更不通过记录均可打开只读变更详情，对比变更前后内容 |
| 变更详情 | 点击变更记录行的「查看」打开只读变更详情弹窗。弹窗顶部展示「变更状态 / 变更时间 / 操作人」三段元信息，下方以左右双栏并排方式呈现「变更前信息」与「变更后信息」：①全量字段展示：基本信息和资源持有方信息按 2 列成对的 KV 网格、信息项按 5 列表格分别完整列出，未变更字段同样展示，两侧字段名与顺序严格对齐便于逐行比对；基本信息中「资源摘要」字段在 KV 网格内独占整行，便于完整阅读；②变更标识：变更前侧文字与背景均不标红（纯展示）；变更后侧按操作类型着色——modified / added 字段文字标红、背景不标红，deleted 字段背景标红、文字不标红（变更后侧值为空），信息项 deleted 行不标红；信息项 modified 行额外做单元格级 diff（仅变更后差异单元格文字标红），三类状态视觉可区分；③同步滚动：左右两栏均使用独立滚动容器，通过双 ref 同步两侧 scrollTop，行高与单元格宽度严格一致，长文本完整换行不省略；底部仅保留「关闭」按钮 |
| 分页 | 支持页码、上一页/下一页、每页条数和跳页 |

## 3. 角色与权限

- 页面归属后台“数据产品开发管理”菜单组。
- 仅向“实施机构”角色分配，页面角色切换器固定显示实施机构。
- 实施机构可查询、查看、新增资源并查看存证；审核与复审由已有页面负责。

## 4. 布局与视觉

- 复用 `Layout` 统一后台侧栏、顶部导航和角色区域。
- 主体采用左侧行业树 + 右侧筛选/表格双栏布局。
- 延续蓝色主按钮、浅蓝表头、细边框和紧凑型 ToB 表格密度。
- 状态标签：已通过/已挂载为绿色；提交、变更、撤销待审核及待挂载为蓝色；三类未通过为红色；待提交和已撤销为橙色。

## 5. 交互状态

- 重置清空所有筛选并回到第 1 页；刷新保留筛选条件。
- 长资源名称和行业分类单元格截断，悬停显示完整内容。
- 弹窗支持点击遮罩关闭，新增表单支持保存和关闭。
- 数据资源查看详情弹窗采用只读键值对表格布局。“基本信息”页签展示基本信息与资源持有方信息：基本信息前 14 项按两列成对展示，资源摘要独占整行；“信息项”页签展示信息项数据类型、信息项表格及分页预留区；“审核信息”页签展示审核流程表格（8 列固定宽度，容器过窄时表格内出现横向滚动条）。空字段统一展示 `-`，长文本自动换行完整显示。
- 表格列宽固定，不允许换行；操作列不裁剪按钮，遇到容器宽度不足时表格下方出现横向滚动条（滚动条出现在列表面板内，而非整个页面）。
- 关联政务信息资源目录子弹窗与父弹窗（新增）层级叠加：点击子弹窗遮罩只关闭子弹窗；点击父弹窗遮罩关闭父弹窗。
- 变更记录弹窗筛选区采用两行布局：第一行展示变更状态与变更时间，第二行展示查询、重置按钮，保证筛选条件完整可见。
- 子弹窗内的目录详情弹窗为三层嵌套（z-index 1100），与子弹窗互不影响关闭逻辑。

# 产品生命周期 - 规格文档

## 1. 业务目标

面向运营机构，提供数据产品从「安全审查 → 产品登记 → 产品上架 → 产品交付 → 产品下架」全生命周期的统一跟踪入口。以「数据产品」为粒度展示当前所处阶段与阶段状态，支持按产品标识码、名称、类型、阶段、提供方、当前阶段、阶段状态、更新时间组合检索，并可查看产品档案、阶段流转时间轴与数据血缘关系，用于掌握产品加工链路与流转进度。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 组合筛选 | 数据产品标识码、产品名称、产品类型、产品阶段、产品提供方、当前阶段、阶段状态、更新时间，共 8 项，三行排布 |
| 查询 / 重置 | 蓝色主按钮【查询】按当前条件过滤并回到第 1 页；白色次要按钮【重置】清空全部条件恢复全量数据 |
| 生命周期列表 | 展示序号、数据产品标识码、产品名称、产品类型、产品阶段、产品提供方、当前阶段、阶段状态、更新时间、操作 |
| 查看 | 打开「产品详情」只读弹窗，展示产品档案信息 |
| 时间轴 | 打开「生命周期时间轴」弹窗，按 安全审查 → 产品登记 → 产品上架 → 产品交付 → 产品下架 顺序展示各阶段流转记录 |
| 数据血缘 | 跳转至独立整页「数据血缘」，以分层图谱展示 数据源系统 → 数据资源 →（基础产品）→ 数据产品 →（数据服务）的血缘链路，并附血缘关系明细表；页面通过 `?code=数据产品标识码` 定位记录，支持直接访问与刷新 |
| 默认排序 | 列表按「更新时间」倒序排列，最新在前；查询/重置/翻页后排序不变 |
| 分页 | 共 X 条记录 + 上一页/页码/下一页 + 每页条数 + 跳页；默认每页 10 条，默认第 1 页 |

## 3. 角色与权限

- 页面为后台**一级菜单**「产品生命周期」，无父级菜单，面包屑展示 `首页 / 产品生命周期`。
- 仅向「运营机构」角色分配，页面角色切换器固定显示运营机构。
- 页面为只读跟踪视角，不提供新增、编辑、删除等写操作。

## 4. 筛选条件

| 筛选项 | 控件 | 提示文字 | 取值 |

| 数据产品标识码 | 输入框 | 请输入 | 模糊匹配 |

| 产品类型 | 下拉 | 请选择 | API产品、数据集 |

## 5. 列表字段

| 字段 | 说明 |
| --- | --- |
| 序号 | 按当前分页连续编号 |
| 数据产品标识码 | 产品唯一标识码，如 `DP43010020260001`，超长截断，悬停显示完整编码 |
| 产品名称 | 超长截断，悬停显示完整名称 |
| 产品类型 | 蓝色标签展示 API产品 / 数据集 |
| 产品阶段 | 基础产品 / 再开发产品，普通文字 |
| 产品提供方 | 产品开发运营单位，超长截断 |

| 阶段状态 | 待处理（蓝色）、处理中（橙色）、已完成（绿色）、已驳回（红色）、已终止（灰色）、已暂停（紫色） |

| 操作 | 【查看】【时间轴】【数据血缘】，从左到右固定顺序；其中「数据血缘」为页面跳转（非弹窗），携带当前数据产品标识码进入独立整页 |

## 6. 产品详情弹窗（查看）

- 标题：「产品详情」，只读展示产品档案。
- 基本信息：数据产品标识码、产品名称、产品类型、产品阶段、产品提供方。
- 阶段信息：当前阶段、阶段状态、更新时间。
- 产品简介：整行展示。
- 底部仅提供【关闭】按钮。

## 7. 生命周期时间轴弹窗（时间轴）

- 标题：「生命周期时间轴」。
- 顶部概要条：数据产品标识码、产品名称、产品类型、产品阶段，便于核对当前查看对象。
- 时间轴按阶段流转顺序自上而下排列：安全审查 → 产品登记 → 产品上架 → 产品交付 → 产品下架。
- 每个节点展示：阶段名称、阶段状态标签、操作时间、操作人（含操作单位）、处理说明。
- 当前阶段节点高亮（蓝色实心圆点 + 蓝色阶段名）；已流转完成的节点状态统一为「已完成」；当前阶段为已驳回/已终止/已暂停时，流转在该阶段终止，其后阶段不展示。
- 全部只读，底部仅提供【关闭】按钮。

## 8. 数据血缘独立整页（数据血缘）

- 入口：列表页操作列「数据血缘」按钮，跳转至独立整页 `/prototypes/product-lifecycle-lineage.html`，不再以弹窗形式展示。
- 参数传递：跳转时携带当前数据产品标识码，URL 形如 `?code=DP43010020260001`；页面依据该参数从演示数据中定位记录并加载，支持直接访问与刷新（刷新后参数保留，数据可复现）。
- 返回：页面顶部提供「返回产品生命周期」入口，返回列表页；亦可通过左侧菜单「产品生命周期」返回。
- 页面标题：「数据血缘」；面包屑：`首页 / 产品生命周期`（左侧菜单高亮「产品生命周期」）。
- 全屏图谱：图谱占满 `Layout` 内容区可视区域，无额外标题栏与卡片边距；SVG 随容器尺寸自适应重绘，节点与连线始终可见。
- 辐射式布局（SVG 绘制，带箭头贝塞尔连线）：
  - 中心节点：当前数据产品，类型为「一级产品」（蓝色），固定居中。
  - 上游节点：左侧均匀分布 4 个「数据资源」（橙色），名称为 `<地域><领域>数据资源1~4`。
  - 下游节点：右侧均匀分布 5 个「再开发产品」（绿色），名称为 `再开发产品-产品1~5`。
  - 边：每个上游节点连向中心节点，中心节点连向每个下游节点，箭头指向血缘下游。
  - 节点按类型配色：数据资源（橙色 `#fa541c`）、一级产品（蓝色 `#1890ff`）、再开发产品（绿色 `#52c41a`）；节点名称超长截断，悬停显示完整名称。
- 节点交互：点击任意节点，从页面右侧滑出抽屉面板；抽屉标题为节点类型，内部展示「基本信息 / 授权信息」两个页签：
  - 基本信息：节点名称、节点类型；若点击中心节点，额外展示产品标识码、产品类型、行业分类、地域分类、产品提供方、产品简介。
  - 授权信息：授权状态、授权对象、授权时间、授权范围。
- 抽屉收起：点击抽屉外遮罩或抽屉右上角关闭按钮均可收起抽屉，收起后不干扰图谱的平移/点击等交互。
- 图例：页面顶部工具条右侧按节点类型展示色块说明。
- 画布交互（平移 / 缩放 / 重置）：整页图谱支持对画布的平移、缩放与重置，各能力互不冲突、可叠加操作：
  - 平移：在画布空白处按住鼠标（或单指触控）拖拽，整体平移全部节点与连线；拖动超过阈值（4px）即判定为平移，不会误触发节点点击。
  - 缩放：桌面端滚动鼠标滚轮以光标位置为锚点缩放；移动端双指捏合缩放（以双指中点为锚点）；缩放比例限定在 40%~300% 之间并持续保留，直至主动重置或刷新页面。
  - 重置：右下角悬浮控制条提供「放大 ＋ / 缩小 － / 重置 ⟳」三个按钮并实时显示当前缩放百分比；点击「重置」或按键盘 `R` 快捷键，画布视图回到初始状态（居中、100%）；`+` / `-`（或 `=` / `_`）键亦可步进缩放。
  - 叠加与固定：可在任意缩放比例下继续拖拽平移；控制条与抽屉遮罩均不随画布变换，始终固定在视口原位，保证操作可达且不干扰图谱其余交互。
- 异常态：缺少 `code` 参数或标识码未匹配到记录时，页面展示「未找到对应的数据产品」提示并提供返回入口。
- 全部只读。

## 9. 布局与视觉

- 复用 `Layout` 统一后台侧栏、顶部导航、面包屑和角色区域，面包屑为 `首页 / 产品生命周期`。
- 复用 `src/common/backend-list.css` 列表契约（筛选区、表格、分页、操作按钮、状态标签），页面样式仅补充列宽、时间轴与血缘图谱样式。
- 延续蓝色主按钮、浅蓝表头、细边框、紧凑型 ToB 表格密度。
- 页面标题为「产品生命周期」。

## 10. 交互状态

- 页面初始化不带筛选条件，自动加载全部产品生命周期数据，并默认按「更新时间」倒序排列（最新在前）。
- 查询、重置、切换分页后排序保持不变；第一页始终展示更新时间最新的记录。
- 重置后列表刷新回全量数据并回到第 1 页。
- 无数据场景：表格展示空白提示「暂无数据」。
- 「查看」「时间轴」弹窗支持点击遮罩关闭；「数据血缘」为独立整页，通过页面内「返回」入口或左侧菜单返回列表页。
- 长文本单元格截断，悬停显示完整内容。
- 表格列宽固定不换行；操作列不裁剪按钮，容器宽度不足时表格区域出现横向滚动条。

## 11. 数据说明

- 演示数据按地域、领域、产品类型、产品阶段组合生成，共 48 条产品生命周期记录。
- 数据产品标识码规则：`DP` + 6 位行政区划代码 + 年份 `2026` + 4 位序号（如 `DP43010020260001`）。
- 当前阶段与阶段状态按阶段语义约束生成：审查/登记/上架阶段取 待处理、处理中、已完成、已驳回；交付阶段取 处理中、已完成、已终止、已暂停；下架阶段取 待处理、已完成、已终止、已暂停。
- 时间轴依据当前阶段回溯生成，已流转阶段统一为「已完成」，当前阶段沿用列表中的阶段状态。
- 血缘图谱依据产品阶段与当前阶段动态生成分层节点，边为相邻层节点的全连接。

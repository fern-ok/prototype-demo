# 实施机构工作台

## 1. 页面定位

- **页面名称**：实施机构工作台
- **使用角色**：实施机构
- **核心目标**：集中展示资源总览、待办任务、系统通知和统计趋势，帮助实施机构快速处理日常业务事项。
- **设计依据**：用户提供的功能修改说明、实施机构菜单截图、现有工作台页面。

## 2. 页面结构

### 第一部分：总览

展示 4 项资源指标：

| 指标 | 展示内容 |
| --- | --- |
| 数据资源总数 | 总数、今日新增 |
| 数据资源授权总数 | 总数、今日新增 |
| 基础数据产品总数 | 总数、今日新增 |
| 再开发数据产品总数 | 总数、今日新增 |

### 第二部分左侧：待办任务

待办任务分为两个 Tab：

| Tab | 功能 |
| --- | --- |
| 待处理 | 展示待处理任务；点击“处理列表页”跳转对应业务列表；支持单条标记已处理；支持批量标记已处理 |
| 已处理 | 展示已处理任务；支持单条删除记录；支持批量删除已处理记录 |

待办任务字段：

- 业务类型
- 任务标题
- 单据编号
- 发起方
- 创建时间
- 更新时间
- 操作

### 第二部分右侧：消息通知

消息通知展示系统自动触发的通知消息，分为两个 Tab：

| Tab | 功能 |
| --- | --- |
| 未读 | 展示未读通知；支持单条标记已读；支持批量标记已读 |
| 已读 | 展示已读通知；支持单条删除消息；支持批量删除消息 |

消息通知字段：

- 消息标题
- 消息内容
- 触发动作
- 触发时间
- 操作

### 第三部分：统计分析

统计分析分左右两个图表：

| 区域 | 图表 |
| --- | --- |
| 左侧 | 数据资源上架趋势分析 |
| 右侧 | 数据资源授权趋势分析 |

每个图表展示：

- 本周期新增数量
- 环比变化
- 全部、近一年、近 30 天、近 7 天筛选
- 近 30 天趋势折线
- 导出统计入口
- 更新时间说明

## 3. 交互规则

1. 待办任务默认进入“待处理”页签。
2. 待处理任务标记已处理后，移入“已处理”页签。
3. 已处理任务删除后，从列表中移除。
4. 消息通知默认进入“未读”页签。
5. 未读消息标记已读后，移入“已读”页签。
6. 已读消息删除后，从列表中移除。
7. 批量按钮在未勾选记录时禁用。
8. 切换 Tab 时清空当前勾选状态。

## 4. 视觉规范

- 延续现有平台蓝色顶部栏、白色内容面板和浅灰蓝背景。
- 总览指标采用 4 等分卡片布局。
- 第二部分采用左右 1:1 双列表布局，列表高度较统计区更紧凑，保证统计分析更早露出。
- 第三部分采用左右 1:1 双图表布局，突出上架趋势和授权趋势对比。
- 列表操作使用文本链接和图标按钮，批量操作使用描边按钮。

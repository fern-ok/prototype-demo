# 其他经营主体备案 - 规格文档

## 1. 业务目标

面向运营机构，提供其他经营主体的备案管理入口。运营机构可登记与本机构合作的其他经营主体（名称 + 统一社会信用代码），备案信息上链存证，支持查看区块链存证证书与删除备案记录。

## 2. 功能清单

| 模块 | 说明 |
| --- | --- |
| 备案列表 | 展示序号、授权运营类型、领域名称、其他经营主体、统一社会信用代码、创建时间、操作 |
| 默认排序 | 列表按「创建时间」倒序排列，最新在前 |
| 新增备案 | 右上角蓝色按钮【+ 其他经营主体备案】，打开备案表单弹窗 |
| 查看存证 | 操作列【查看存证】，打开「区块链存证证书」证书式弹窗 |
| 删除 | 操作列【删除】，弹出删除提示框二次确认后删除该条备案 |
| 分页 | 共 X 条记录 + 上一页/页码/下一页 + 每页条数 + 跳页；默认 10 条/页、默认第 1 页 |

## 3. 角色与权限

- 页面归属后台「备案管理」菜单组，为二级子菜单，与「产品和服务清单备案」「运营协议备案」「实施方案联审」并列。
- 分配给「运营机构」角色，页面角色切换器固定显示运营机构。

## 4. 列表字段

| 字段 | 说明 |
| --- | --- |
| 序号 | 按当前分页连续编号 |
| 授权运营类型 | 整体授权运营 / 分领域授权运营 |
| 领域名称 | 备案所属领域（整体授权运营时为「整体」） |
| 其他经营主体 | 其他经营主体单位名称 |
| 统一社会信用代码 | 其他经营主体统一社会信用代码 |
| 创建时间 | 备案创建时间（yyyy-MM-dd HH:mm:ss），列表按此字段倒序 |
| 操作 | 【删除】【查看存证】，从左到右固定顺序 |

- 页面初始化加载全量数据；无数据时表格展示「暂无数据」。
- 右上角固定展示【+ 其他经营主体备案】主按钮。

## 5. 弹窗 1：其他经营主体备案（表单弹窗）

由右上角【+ 其他经营主体备案】打开。

| 字段 | 控件 | 必填 | 提示文字 |
| --- | --- | --- | --- |
| 其他经营主体名称 | 单行输入框 | 是（红色星号） | 请输入其他经营主体名称 |
| 统一社会信用代码 | 单行输入框 | 是（红色星号） | 请输入统一社会信用代码 |

- 警示提示（表单下方居中，红色小字约 12–13px）：
  「其他经营主体信息不匹配，将导致其他经营主体无法登录，请核对信息后确认是否提交。」
- 底部按钮（右对齐）：【取消】（次要按钮：白底、灰边框、灰字）、【确定】（主要按钮：蓝色填充、白字、圆角）。
- 必填校验：任一必填项为空时阻断提交，并在对应输入框红框 + 下方红字提示。
- 提交成功后将新记录追加到列表（创建时间为当前时间），并回到第 1 页按创建时间倒序展示。

## 6. 弹窗 2：区块链存证证书（证书查看弹窗）

由操作列【查看存证】打开。

### 6.1 容器

- 居中模态，整体为证书式卡片：白色底，四周蓝色防伪花纹边框（波浪纹边框），内部背景带浅蓝灰色放射状 / 同心圆防伪底纹；宽度约 600px，上下留白均匀。

### 6.2 头部

- 居中大标题（加粗、深灰/近黑）：「区块链存证证书」。
- 右上角：蓝色圆形下载按钮（白色向下箭头图标），点击下载证书（导出 PDF / 图片）。
- 弹窗右上角「×」关闭弹窗。

### 6.3 证书内容

- 两列表单式排版：左列字段名（右对齐、加粗），右列字段值（左对齐，长文本自动换行）。
- 自上而下共 10 个字段：

| 字段名 | 说明 |
| --- | --- |
| 电子证据 | 存证哈希（0x 开头 66 位十六进制，等宽字体展示） |
| 区块链ID | 区块链标识（0x 开头十六进制，等宽字体展示） |
| 存证时间 | 存证上链时间 |
| 存证描述 | 固定为「其他经营主体备案存证」 |
| 授权运营类型 | 备案记录的授权运营类型 |
| 领域名称 | 备案记录的领域名称 |
| 运营机构 | 当前运营机构（湖南数据产业集团有限公司） |
| 其他经营主体 | 备案记录的其他经营主体名称 |
| 统一社会信用代码 | 备案记录的统一社会信用代码 |
| 备案时间 | 备案创建时间 |

## 7. 弹窗 3：删除提示框

由操作列【删除】打开。

- 提示文案：确定要删除「{其他经营主体}」的备案信息吗？
- 底部按钮（右对齐）：【取消】【确定】。
- 点击【确定】删除该条备案记录并关闭弹窗，列表即时刷新；点击【取消】或「×」关闭弹窗，不删除。
